Traefik reads its routes from labels on the containers, so it fits when it already sits in front of your other Docker services. If it does not, [Caddy](/installation/domain-and-https#set-up-caddy) is less work for the same result.

Traefik reaches PostQueen over the Docker network, not through the host. It therefore talks to port **5000**, the port PostQueen listens on inside the container, and the `4007` mapping is no longer needed.

## Set it up

<Steps>
  <Step title="Add Traefik and the labels">
    Edit `docker-compose.yaml` from the [Compose repository](https://github.com/GkhanKINAY/postqueen-docker-compose). Add labels to the `postqueen` service, remove its `ports:` lines, and add a `traefik` service:

    ```yaml docker-compose.yaml
    services:
      postqueen:
        # ...everything else stays as shipped, minus the ports: lines
        labels:
          - "traefik.enable=true"
          - "traefik.http.routers.postqueen.rule=Host(`postqueen.example.com`)"
          - "traefik.http.routers.postqueen.entrypoints=websecure"
          - "traefik.http.routers.postqueen.tls.certresolver=letsencrypt"
          - "traefik.http.services.postqueen.loadbalancer.server.port=5000"

      traefik:
        image: traefik:v3
        container_name: traefik
        restart: always
        command:
          - "--providers.docker=true"
          - "--providers.docker.exposedbydefault=false"
          - "--providers.docker.network=postqueen-docker-compose_postqueen-network"
          - "--entrypoints.web.address=:80"
          - "--entrypoints.web.http.redirections.entrypoint.to=websecure"
          - "--entrypoints.websecure.address=:443"
          - "--entrypoints.websecure.transport.respondingTimeouts.readTimeout=600s"
          - "--certificatesresolvers.letsencrypt.acme.email=you@example.com"
          - "--certificatesresolvers.letsencrypt.acme.storage=/letsencrypt/acme.json"
          - "--certificatesresolvers.letsencrypt.acme.httpchallenge.entrypoint=web"
        ports:
          - "80:80"
          - "443:443"
        volumes:
          - "/var/run/docker.sock:/var/run/docker.sock:ro"
          - "traefik-letsencrypt:/letsencrypt"
        networks:
          - postqueen-network

    volumes:
      traefik-letsencrypt:
    ```

    Put your domain in the `Host` rule and your address in `acme.email`. Keep the existing `volumes:` entries and add `traefik-letsencrypt` to them.

    - `traefik.enable=true` is required, because `exposedbydefault=false` makes Traefik ignore every container without it.
    - Removing `ports:` from `postqueen` matters: left in place, PostQueen also answers on host port 4007 over plain HTTP, past Traefik.
    - `readTimeout` is raised because Traefik stops reading a request after 60 seconds by default, which cuts off a large upload on a slow connection. PostQueen accepts files up to 1 GB.
    - `providers.docker.network` tells Traefik which network to reach PostQueen on, since the `postqueen` container is on two. It takes the network's full name, which Compose prefixes with the project folder's name: `docker network ls` shows it.
  </Step>
  <Step title="Start it">
    ```bash
    docker compose up -d
    docker compose logs -f traefik
    ```

    Traefik requests the certificate on the first request for the domain. The domain has to resolve to this server and port 80 has to be open for the challenge.
  </Step>
  <Step title="Tell PostQueen its address">
    <ComposePublicUrls />

    <RestartService />
  </Step>
  <Step title="Check it">
    ```bash
    curl -I https://postqueen.example.com
    ```

    <Check>
    `HTTP/2 200` with a certificate from Let's Encrypt, and a sign-in that holds in the browser.
    </Check>
  </Step>
</Steps>

Traefik does not buffer responses and sets no body size limit by default, so streamed Copilot replies and large uploads pass as they are. Do not attach a `buffering` middleware to this router.

## If it does not work

<AccordionGroup>
  <Accordion title="404 page not found from Traefik">
    The router was not created. The usual cause is a missing `traefik.enable=true` label, or a `Host` rule that does not match the name you open.
  </Accordion>
  <Accordion title="The browser warns about the certificate">
    Traefik is serving its default self-signed certificate because the ACME request failed. `docker compose logs traefik` gives the reason, most often DNS that does not point here yet or port 80 blocked.
  </Accordion>
  <Accordion title="Gateway Timeout or Bad Gateway">
    Traefik cannot reach the container. Check that both services are on `postqueen-network`, that `providers.docker.network` names it as `docker network ls` shows it, and that the service label says port `5000`, not 4007.
  </Accordion>
</AccordionGroup>
