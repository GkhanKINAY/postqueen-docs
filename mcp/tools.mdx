These are the tool names your agent sees when it connects, so you can match them to what it shows in a session. You never call them yourself: you ask in plain words and the agent picks the tools.

| Address | Tools |
|---|---|
| `{{mcpKeyUrl}}` (key address) | {{mcpToolsKey}} |
| `{{mcpBearerUrl}}` with `Authorization: Bearer YOUR_API_KEY` (Bearer header) | {{mcpToolsKey}} |
| `https://api.postqueen.ai/sse/YOUR_API_KEY` (older SSE clients) | {{mcpToolsKey}} |
| `{{mcpOauthUrl}}` (sign-in address) | {{mcpToolsOauth}}: every tool except `ask_postqueen` |

How to connect: [MCP server](/mcp/introduction).

## The order an agent follows

<Steps>
  <Step title="Find the channel">
    `integrationList` gives the channel's `id` and its network (`platform`).
  </Step>
  <Step title="Read the network's rules">
    `integrationSchema` returns the rules, the character limit and the settings a post needs. If a setting needs a value only the network knows, such as a WordPress post type, `triggerTool` looks it up.
  </Step>
  <Step title="Bring in media, if the post has any">
    `uploadFromUrlTool`, the upload panel (`uploadWidgetTool`) or `generateImageTool` puts the file in your media library and returns its `path`.
  </Step>
  <Step title="Create the post">
    `integrationSchedulePostTool` saves a draft, schedules the post or publishes it now, and returns the new post's ID.
  </Step>
</Steps>

## Channels

### `integrationList`

Lists the channels the agent can post to. Channels that are turned off, need to be reconnected or were not finished connecting are left out.

| Input | Type | Required | What it is |
|---|---|---|---|
| `group` | string | No | A customer ID from `groupList`, to list only that customer's channels |

**Returns** `output`, a list of channels: `id`, `name`, `platform` (the network, such as `bluesky` or `x`), `picture`, `display` (the account handle), `type` and `customer` (`id` and `name`, when the channel belongs to one).

### `groupList`

Lists your customers, the groups your channels are sorted into. Takes no input.

**Returns** `output`, a list of `id` and `name`.

### `integrationSchema`

Returns a network's rules and the settings a post to it needs. The agent calls it before it writes a post for a network.

| Input | Type | Required | What it is |
|---|---|---|---|
| `platform` | string | Yes | The network, as `platform` in `integrationList` shows it |
| `isPremium` | boolean | Yes | Whether the X account has Premium, which allows longer posts. `false` for every other network |

**Returns** `output` with:

| Field | What it is |
|---|---|
| `rules` | The network's posting rules, in plain words |
| `maxLength` | The character limit of a post or comment |
| `settings` | The settings schema, or `No additional settings required` |
| `tools` | Helpers `triggerTool` can run for this network, each with a `methodName`, a `description` and the inputs it takes (`dataSchema`) |

### `triggerTool`

Runs one of a network's helpers to look up a value a setting needs, such as a list of WordPress post types or DEV tags.

| Input | Type | Required | What it is |
|---|---|---|---|
| `integrationId` | string | Yes | The channel's `id` |
| `methodName` | string | Yes | A `methodName` from the `tools` that `integrationSchema` returned |
| `dataSchema` | list | Yes | The helper's inputs as `key` and `value` pairs. An empty list when it takes none |

**Returns** `output`, whatever the network answered: usually a list of `id` and `name` pairs. If the channel's sign-in has expired, the tool tries to renew it. When that fails, the channel is marked to be reconnected and the tool says so.

## Posts

### `integrationSchedulePostTool`

Creates posts: a draft, a post scheduled for a time, or a post that goes out now. PostQueen checks each post the way the app does before it saves anything.

| Input | Type | Required | What it is |
|---|---|---|---|
| `socialPost` | list | Yes | One entry per post, each with the fields below |
| `integrationId` | string | Yes | The channel's `id` |
| `isPremium` | boolean | Yes | Whether the X account has Premium. `false` for other networks |
| `date` | string | Yes | When to publish, in UTC |
| `type` | string | Yes | `draft`, `schedule` or `now` |
| `shortLink` | boolean | Yes | Whether to shorten the links in the text |
| `postsAndComments` | list | Yes | The post, then its comments or thread items. Each has `content` (HTML: `p`, `h1` to `h3`, `strong`, `u`, `ul`, `li`), `attachments` (a list of media paths) and an optional `delay`, the minutes to wait after the item before it |
| `settings` | list | Yes | The network's settings as `key` and `value` pairs, from `integrationSchema`. An empty list when it needs none |

**Returns** `output`, a list of `postId` and `integration` for each post it created. When a post fails the checks, `output` is `errors` with the reason, and nothing is created. The agent fixes the post and calls the tool again.

- Settings and length are checked for scheduled posts and posts that go out now. Over MCP, a draft is saved even when a required setting is missing, so add it before the draft is scheduled. The CLI and the API check a draft's settings too.
- Attachments must be media paths that end in `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp` or `.mp4`. Bring a file in with an upload tool first.
- What extra items in `postsAndComments` become depends on the network: see [comments and threads](/using/comments-and-threads).

### `postsListTool`

Lists your posts between two dates, whatever their state.

| Input | Type | Required | What it is |
|---|---|---|---|
| `startDate` | string | Yes | Start of the window, in UTC |
| `endDate` | string | Yes | End of the window, in UTC |
| `customer` | string | No | A customer ID, to list only posts on that customer's channels |

**Returns** `output.posts`, each with `id`, `publishDate` (UTC), `state` (`QUEUE`, `DRAFT`, `PUBLISHED` or `ERROR`), `content`, `settings`, `group`, `integrationId`, `platform` and `integrationName`.

### `postReadTool`

Reads one post in full.

| Input | Type | Required | What it is |
|---|---|---|---|
| `id` | string | Yes | The post's `id` from `postsListTool` |

**Returns** `output` with the post's `id`, `group`, `integrationId`, `platform`, `integrationName`, `state`, `publishDate` and `settings`, and `posts`: the post and each comment or thread item, with its `id`, `content`, `delay` and `attachments`. An unknown ID returns `error`.

### `postSettingsTool`

Changes the network settings of a post that has not gone out. The text and the publish time stay as they are.

| Input | Type | Required | What it is |
|---|---|---|---|
| `id` | string | Yes | The post's `id`. Use the post itself, not one of its comments |
| `settings` | list | Yes | The settings to change, as `key` and `value` pairs. Settings you leave out keep their values |

**Returns** `output` with `postId` and `publishDate`, or `errors`. It works on drafts and on scheduled posts whose time has not passed.

## Analytics

The three analytics tools read your published posts on the networks that report numbers: X, Facebook Page, Instagram, LinkedIn Page, YouTube, Threads, Pinterest, TikTok and Google Business Profile. Only some of these can be connected today: see the status column on [CLI analytics](/cli/analytics#which-networks-report-numbers).

- The window (7, 30 or 90 days) picks which posts count, by publish date. The numbers are each post's totals so far, not only what happened inside the window.
- `null` means the network does not report that number. Facebook gives no comment counts, Pinterest gives impressions only, and Google Business Profile gives no numbers per post.
- `syncing` is `true` while PostQueen is still fetching the latest numbers.

### `analyticsSummaryTool`

Totals for the posts you published in the window.

| Input | Type | Required | What it is |
|---|---|---|---|
| `date` | number | No | `7`, `30` or `90` days. Default `30` |
| `integrationId` | string | No | One channel's `id` |
| `platform` | string | No | One network, such as `instagram` |

**Returns** `output` with `syncing`, `date`, `posts` (how many), `reactions`, `comments`, `impressions` and `notes`.

### `analyticsPostsTool`

Ranks your posts, or searches them, by how they did.

| Input | Type | Required | What it is |
|---|---|---|---|
| `date` | number | No | `7`, `30` or `90` days. Default `30` |
| `sort` | string | No | `reactions` (default), `comments`, `impressions`, `engagement` or `published` |
| `dir` | string | No | `desc` (default) or `asc` |
| `page` | number | No | The page, from `0` |
| `limit` | number | No | Posts per page, 1 to 20. Default `5` |
| `integrationId` | string | No | One channel's `id` |
| `platform` | string | No | One network |
| `q` | string | No | Search the text, the channel name, the network or the post ID |

**Returns** `output` with `total`, `page`, `limit`, `posts`, and `topReactions` and `topComments` (the five strongest in the window, whatever the sort). Each post has `id`, `content`, `publishDate`, `releaseURL`, `integrationId`, `platform`, `channelName`, `impressions`, `reactions`, `comments`, `shares` and `engagementRate`.

### `analyticsPostTool`

The numbers for one published post.

| Input | Type | Required | What it is |
|---|---|---|---|
| `postId` | string | Yes | A post ID from `postsListTool` or `analyticsPostsTool` |

**Returns** `output.post` with the same fields as a post in `analyticsPostsTool`, or `output.error`: `not_found`, `not_published`, `unsupported`, or `missing_release` when PostQueen does not know the post's ID on the network yet. Connect the post to its published copy in the app, or with [`postqueen posts:connect`](/cli/analytics#fix-a-missing-release-id).

## Uploads

A post takes media from your PostQueen media library. These tools put a file there and return its `path` for `attachments`.

### `uploadFromUrlTool`

Brings an image or video in from a public link.

| Input | Type | Required | What it is |
|---|---|---|---|
| `url` | string | Yes | A public link to the image or video |

**Returns** the file's `id`, `path` and `status`, or `error`. An image is ready at once. An MP4 comes back as `processing` while PostQueen prepares it, and its `path` can change when it is done. A MOV is converted to MP4 first, and the tool waits for that, up to about four minutes.

### `uploadWidgetTool`

Opens an **Upload Media** panel in the chat, where you add photos or videos from your device. It works in apps that can show MCP panels, such as Claude, Claude Cowork and ChatGPT. Elsewhere no panel appears: use `uploadFromUrlTool` with a public link instead. Takes no input.

**Returns** a `sessionId`. What you upload through the panel is reported in the chat, and `uploadWidgetStatusTool` lists it.

### `uploadWidgetTicketTool`

Used by the upload panel itself, not by your agent. It gets a short-lived upload ticket for the panel, so the credential never appears in the chat.

| Input | Type | Required | What it is |
|---|---|---|---|
| `sessionId` | string | Yes | The `sessionId` from `uploadWidgetTool` |

**Returns** a `ticket`, or `error`.

### `uploadWidgetStatusTool`

Lists what you uploaded through the panel.

| Input | Type | Required | What it is |
|---|---|---|---|
| `sessionId` | string | Yes | The `sessionId` from `uploadWidgetTool` |

**Returns** `media`, each with `id`, `path` and `status`. An empty list means nothing was uploaded yet. A file that is `processing` is still being prepared: the agent waits about 10 seconds and asks again. A `ready` file can go into a post.

## Images and video

Creating an image or a video uses your plan's monthly AI credits. The credits per plan are on [plans](/cloud/plans).

### `generateImageTool`

Creates an image and puts it in your media library. Uses one AI image credit.

| Input | Type | Required | What it is |
|---|---|---|---|
| `prompt` | string | Yes | What to draw, described as a scene rather than a caption |
| `style` | string | No | `Realistic` (default), `Cartoon`, `Anime`, `Minimalist`, `Sketch` or `Watercolor` |
| `orientation` | string | No | `square` (default), `portrait` or `landscape` |

**Returns** the image's `id`, `path`, `alt` and `thumbnail`, or `error`. With no credits left, the error is `No AI image credits are available on this account.`

### `generateVideoOptions`

Lists the video generators your workspace can use. The agent calls it before it starts a video. An empty list means none is available.

| Input | Type | Required | What it is |
|---|---|---|---|
| `reasoning` | string | No | A short note on why the agent is asking |

**Returns** `video`, each generator with its `identifier`, `title`, `description`, `trial` (whether it works during the free trial), `output`, `tools` and `customParams` (the inputs it needs).

### `videoFunctionTool`

Looks up a value a video generator needs, such as the list of voices, with one of the helpers `generateVideoOptions` listed under `tools`.

| Input | Type | Required | What it is |
|---|---|---|---|
| `identifier` | string | Yes | The generator's `identifier` |
| `functionName` | string | Yes | The helper's `functionName` |
| `params` | string | No | The helper's inputs, as a JSON string |

**Returns** the helper's answer.

### `generateVideoTool`

Starts a video. It takes minutes, so the tool returns a job ID at once. Uses one AI video credit.

| Input | Type | Required | What it is |
|---|---|---|---|
| `identifier` | string | Yes | The generator's `identifier` |
| `output` | string | Yes | `vertical` or `horizontal` |
| `customParams` | list | Yes | The generator's inputs as `key` and `value` pairs |

**Returns** a `jobId`, or `error`.

### `videoStatusTool`

Checks a video job.

| Input | Type | Required | What it is |
|---|---|---|---|
| `jobId` | string | Yes | The `jobId` from `generateVideoTool` |

**Returns** `status`: `pending` (the agent asks again in about 30 seconds), `completed` with the video's `url`, or `failed` with the `error`.

## Agent

### `ask_postqueen`

Sends a request in plain words to PostQueen's own agent, which picks and runs the other tools itself. Before it schedules a new post, it writes out the draft and waits for a yes. It is on the key address and the Bearer header only.

| Input | Type | Required | What it is |
|---|---|---|---|
| `message` | string | Yes | What you want done |

**Returns** the agent's answer.

## What the tools cannot do

| You want to | Do it here |
|---|---|
| Delete a post | The app, [`postqueen posts:delete`](/cli/managing-posts#delete-a-post) or [the API](/public-api/posts/delete) |
| Change a post's text or time | The app |
| Move a post between draft and scheduled | The app, [`postqueen posts:status`](/cli/managing-posts#change-a-post) or [the API](/public-api/posts/change-status) |
| Read channel numbers, such as followers | The app, [`postqueen analytics:platform`](/cli/analytics) or [the API](/public-api/analytics/platform) |
