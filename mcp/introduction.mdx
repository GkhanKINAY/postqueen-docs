PostQueen runs an MCP server at `api.postqueen.ai`. MCP, the Model Context Protocol, is how AI agents use outside tools. Give your agent one address and it can list your channels, schedule posts, add media and read how your posts did. There is nothing to install or run on your side.

## Pick an address

<McpAddresses />

<Tabs>
  <Tab title="Key address">
    The API key is part of the address, so there is nothing else to fill in. Most agents take this one. PostQueen tested it with Claude and ChatGPT.

    ```text
    https://api.postqueen.ai/mcp/YOUR_API_KEY
    ```
  </Tab>
  <Tab title="Bearer header">
    For agents with a header field. The key stays out of the address, which helps when the config file is shared or committed.

    ```text
    URL:           https://api.postqueen.ai/mcp
    Authorization: Bearer YOUR_API_KEY
    ```

    The header also takes an access token (it starts with `pos_`) from a [PostQueen OAuth app](/public-api/oauth).
  </Tab>
  <Tab title="Sign-in address">
    For agents that can sign in to an MCP server, such as Claude, Claude Cowork and ChatGPT. No key goes into the agent, and the agent gets every tool except `ask_postqueen`. How it works: [sign in instead of a key](#sign-in-instead-of-a-key).
  </Tab>
</Tabs>

Each agent's guide says which address to use and where it goes. The list is on [AI agents](/agents/overview).

## Where the key is

<ApiKeyLocation />

Anyone with the key can post to every channel in the workspace, so treat it like a password. If it leaks, an admin chooses **Rotate key** under **Connections > API Keys**. The old key stops working at once, in every agent that used it, so update each one with the new key.

## Sign in instead of a key

<Steps>
  <Step title="Add the sign-in address">
    Paste `{{mcpOauthUrl}}` into the agent, with no slash at the end. Leave any client ID and secret fields empty: the agent registers itself with PostQueen.
  </Step>
  <Step title="Sign in and approve">
    The agent opens PostQueen in your browser. Sign in and approve the access. Only a workspace Admin or Super Admin can approve it.
  </Step>
  <Step title="Use it">
    The access does not expire on its own. To end it, open **Connections > Approved Apps** in PostQueen and revoke it.
  </Step>
</Steps>

<Warning>
Gemini CLI, Grok, Grok Bot, Perplexity Computer and NanoClaw cannot sign in. Give them the API key, in the key address or the Bearer header.
</Warning>

## What the agent can do

The tools come in six groups. The agent picks the ones it needs from what you ask.

| Group | Tools | What they do |
|---|---|---|
| Channels | 4 | List your channels and customers, read each network's rules and settings, look up values a setting needs |
| Posts | 4 | Create a draft, a scheduled post or a post that goes out now; list posts; read one in full; change the settings of one that has not gone out |
| Analytics | 3 | Totals for your published posts over 7, 30 or 90 days, your best posts, and the numbers for one post |
| Uploads | 4 | Bring an image or video in from a link, or open an upload panel in Claude, Claude Cowork and ChatGPT |
| Images and video | 5 | Create an image for a post, or start a video job and follow it. Creating an image or a video uses your plan's monthly AI credits |
| Agent | 1 | `ask_postqueen`: hand over a request in plain words and let PostQueen's own agent run the other tools |

Every tool, with what it takes and what it returns: [MCP tools](/mcp/tools).

### What it cannot do yet

- Delete a post.
- Change a post's text or time, or move a draft to scheduled. It can change a post's settings.
- Read channel numbers such as follower counts.

Do those in the app, or with the [CLI](/cli/introduction) or the [API](/public-api/introduction).

## Check that it works

Ask your agent:

```text
List my PostQueen channels.
```

It calls `integrationList` and answers with the channels you connected. Channels that are turned off or need to be reconnected are left out. If the agent shows no PostQueen tools, or the connection fails, see [troubleshooting agents](/agents/troubleshooting).
