Point a client at `/mcp` and your agent gets **17 tools** to list channels, upload media, schedule posts and read analytics. Nothing to install. Directory OAuth paths expose fewer tools.

<Note>
**You do not have to run or install anything.** In the protocol's own words PostQueen is the "server" and your AI client is the "client", but she is already running at a URL. Setup is pasting that URL into your client.
</Note>

## Authentication

Two forms, same 17 tools on direct `/mcp`:

| Form | URL | Header |
|---|---|---|
| Key in the URL | `https://api.postqueen.ai/mcp/YOUR_API_KEY` | none |
| Bearer | `https://api.postqueen.ai/mcp` | `Authorization: Bearer YOUR_API_KEY` (or a `pos_` OAuth token) |

The URL form accepts API keys only. Get the key in **Settings → API Keys**. Building for other users: [OAuth2](/public-api/oauth). Directory OAuth uses `mcp:read` / `mcp:write` on `/mcp-oauth*`. Self-hosted: swap the host for your `NEXT_PUBLIC_BACKEND_URL`.

Tool names, parameters, and how many tools each path actually exposes: [Tools Reference](/mcp/tools#how-many-tools-you-actually-get).
