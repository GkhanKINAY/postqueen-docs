ChatGPT can talk to PostQueen through a custom MCP connector: once it is set up, you can ask ChatGPT to list your connected accounts, generate images and schedule posts. It calls her [14 MCP tools](/mcp/tools) behind the scenes.

  <img src="/images/brand/chat-chatgpt.svg" alt="ChatGPT with the PostQueen connector: it generates two post images and schedules them to Instagram and X" />
</Frame>

## Prerequisites

- **A paid ChatGPT plan, on the web.** Custom MCP apps require Developer mode. It is not on the Free plan and it is not in the ChatGPT mobile apps. Plus and Pro can usually turn it on; on Business, Enterprise and Edu an admin controls who gets it. Availability changes, so if you do not see the option, check OpenAI's [developer mode help article](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt).
- **Write tools are plan-gated.** OpenAI's Help Center currently says full MCP, including modify/write actions such as scheduling, is for Business and Enterprise/Edu. Pro (and Plus) can connect MCP with read/fetch. OpenAI's older developer-mode API guide still lists Plus/Pro with write. Treat connect as likely on Plus/Pro, and `schedulePostTool` as maybe blocked until your plan has write.
- **Your PostQueen API key.** In the PostQueen app at [app.postqueen.ai](https://app.postqueen.ai), open **Settings → API Keys** and click **Reveal**.

<Warning>
With this setup, your API key travels inside the connector URL, so the URL itself is a secret. Anyone who has it can post from your accounts. Do not share screenshots of the connector settings. If the key leaks, regenerate it in **Settings → API Keys** and update every client that uses it.
</Warning>

## Setup

<Steps>
  <Step title="Turn on developer mode">
    In ChatGPT on the web, open **Settings → Apps → Advanced settings** and turn on **Developer mode**. Older ChatGPT builds put this switch under **Settings → Security and login**. On Business, Enterprise and Edu workspaces an admin controls it, so ask them if you do not see it.
  </Step>
  <Step title="Create the app">
    Open **Settings → Apps → Create**. Workspace admins use **Workspace settings → Apps → Create**. Older builds still use **Settings → Plugins** or `chatgpt.com/plugins` and a **+** button. Fill in the form:

    - **Name:** `PostQueen`
    - **Description:** `Schedule and publish social media posts through PostQueen` (optional)
    - **MCP Server URL:**

      ```
      https://api.postqueen.ai/mcp/YOUR_API_KEY
      ```

    - **Authentication:** No authentication

    Replace `YOUR_API_KEY` with the key you revealed earlier. "No authentication" is correct here because the key is already embedded in the URL; there is nothing else to configure.

    Check the box confirming you trust the app, then save. It appears under **Settings → Apps** as a draft or with a **Dev** label. ChatGPT warns that custom apps are not verified by OpenAI; that warning is standard.
  </Step>
  <Step title="Enable it in a chat">
    A saved app is not active everywhere automatically. In a new conversation, open the **+** menu, choose **Developer mode** (or the tools menu), and include **PostQueen**.
  </Step>
</Steps>

## Self-Hosted

On a self-hosted instance, replace `https://api.postqueen.ai` with your `NEXT_PUBLIC_BACKEND_URL`:

```
https://postqueen.example.com/api/mcp/YOUR_API_KEY
```

Most self-hosted setups serve the backend under `/api`, so the MCP path sits at `/api/mcp`. Your reverse proxy has to forward the `/mcp` paths and stream the response rather than buffering it. The configuration, and the Nginx setting that silently breaks this, are on [MCP on a self-hosted install](/mcp/self-hosting).

## Verify

With the connector enabled in a chat, ask:

> "List my connected social media accounts"

Your channel names come back, because ChatGPT reached for her `integrationList` tool. If it fails, check that the API key was pasted in full inside the URL, that developer mode is on, and that the app is enabled in the current chat. If listing works but scheduling does not, your ChatGPT plan may only have read/fetch MCP — see the prerequisites above.
