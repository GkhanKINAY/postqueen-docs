Devin Desktop is Cognition's AI code editor, and Devin Local is its agent. Devin Local reads MCP servers from `~/.config/devin/mcp_config.json` (Windows: `%APPDATA%\devin\mcp_config.json`), and PostQueen connects with one URL.

<Note>
From Cognition's docs, not tested by PostQueen yet.
</Note>

<Info>
You need your PostQueen API key first. In [app.postqueen.ai](https://app.postqueen.ai), open **Connections > API Keys** and click **Reveal**. Only a workspace admin can reveal the key.
</Info>

## Option A: one command

```bash
devin mcp add -s user postqueen https://api.postqueen.ai/mcp/YOUR_API_KEY
```

`-s user` saves the server for every project. Without it, it is saved for the current project only.

## Option B: mcp_config.json

<Tabs>
  <Tab title="API key in URL">
    ```json ~/.config/devin/mcp_config.json
    {
      "mcpServers": {
        "postqueen": {
          "url": "https://api.postqueen.ai/mcp/YOUR_API_KEY"
        }
      }
    }
    ```
  </Tab>
  <Tab title="Bearer token">
    ```bash
    devin mcp add -s user postqueen https://api.postqueen.ai/mcp -H "Authorization: Bearer YOUR_API_KEY"
    ```
  </Tab>
</Tabs>

<Note>
Sign-in instead of a key is an option, not tested yet: add `https://api.postqueen.ai/mcp-oauth-dynamic` as the server URL, then run `devin mcp login postqueen` or press **Authenticate** in Devin Desktop. A workspace admin approves the connection.
</Note>

<Warning>
Your API key can post to every account you have connected. Keep `mcp_config.json` off shared screens. If the key leaks, an admin rotates it under **Connections > API Keys**; then update every client that uses it.
</Warning>

## Self-hosted

Swap the host for your `NEXT_PUBLIC_BACKEND_URL` and keep the `/mcp/YOUR_API_KEY` tail. Most self-hosted setups serve the backend under `/api`. The reverse proxy has to forward `/mcp` and stream the response: [MCP on a self-hosted install](/mcp/self-hosting).

## Verify

Open a new agent tab and ask:

> "List my connected social media accounts"

Your channel names come back when Devin Local calls `integrationList`. It asks before each tool call by default. On Enterprise, an admin must enable Devin Local first.
