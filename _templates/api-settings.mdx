Every post to NETWORK carries a `settings` object with `"__type": "TYPE"`. Read the live schema for your channel with [integration settings](/public-api/integrations/settings).

## Fields

<ResponseField name="__type" type="string" required>
  Always `"TYPE"`.
</ResponseField>

<ResponseField name="FIELD" type="TYPE" required>
  What it does. Allowed values: `VALUE`, `VALUE`. PostQueen refuses the post with "EXACT MESSAGE" when RULE.
</ResponseField>
