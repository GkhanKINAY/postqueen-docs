30+ networks, one calendar. She posts to all of them, and each one connects on its own terms: OAuth keys for most, a plain account login for Bluesky, the browser extension for Skool.

Nothing is connected by default. You put each provider's credentials in your `.env` file, or set them as environment variables, and you restart PostQueen whenever you change one, because the values are read at boot. Running docker compose? Run `docker compose down` and then `docker compose up` to rebuild the containers with the updated variables.
