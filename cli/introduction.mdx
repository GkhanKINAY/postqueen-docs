The PostQueen CLI puts her one command away in your terminal. Schedule a post, upload the image that goes with it or pull last week's numbers, from a shell script, a CI job or an AI agent. Underneath it is the same [Public API](/public-api/introduction) the SDK and the n8n node run on. The data commands print JSON.


## Installation

<Tabs>
  <Tab title="npm">
    ```bash
    npm install -g postqueen
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm install -g postqueen
    ```
  </Tab>
</Tabs>

```bash
postqueen --help
```

If an AI assistant will drive it, also install the skill playbook. It does **not** install the CLI:

```bash
npx skills add GkhanKINAY/postqueen-agent
```

## Authentication

In [app.postqueen.ai](https://app.postqueen.ai), open **Connections > API Keys** and click **Reveal** (only a workspace admin can reveal the key), then:

```bash
export POSTQUEEN_API_KEY=your_api_key_here
```

Self-hosted: set `POSTQUEEN_API_URL` to your `NEXT_PUBLIC_BACKEND_URL` (often `https://postqueen.example.com/api`). Device-flow OAuth is for people running their own auth server: [Authentication](/cli/introduction).

## Your first post

```bash
postqueen integrations:list

postqueen posts:create \
  -c "Hello from the PostQueen CLI!" \
  -s "2026-08-01T09:00:00Z" \
  -i "your-integration-id"

postqueen posts:list
```

Repeat `-c` for a thread. `-s` is required. Full flags: [Command Reference](/cli/command-reference).

The CLI reaches **14 of 23** Public API routes. The other nine, including connect, notifications and video generation, live on the API: [Limits](/agents/troubleshooting).
