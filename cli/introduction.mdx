`postqueen` is the command line for PostQueen. It creates, lists, changes and deletes posts, uploads images and videos, and reads analytics, from a terminal, a script, a scheduled job or an AI agent. It calls the PostQueen API with your API key, and every post it makes lands on the same calendar as the posts you write in the app.

These pages describe `postqueen` 2.0.23. Run `postqueen --version` to see yours.

## Before you start

- **Node.js 20.19 or newer.** On Node.js 22, use 22.12 or newer.
- **A PostQueen workspace on a trial or a paid plan**, with at least one connected channel.
- **The API key.** Only a workspace Admin or Super Admin can reveal it.

## Install and set the key

<Steps>
  <Step title="Install the CLI">
    <CodeGroup>

    ```bash npm
    npm install -g postqueen
    ```

    ```bash pnpm
    pnpm install -g postqueen
    ```

    </CodeGroup>
  </Step>
  <Step title="Set your key">
    ```bash
    export POSTQUEEN_API_KEY=your_api_key
    ```

    Add the line to your shell profile, such as `~/.zshrc` or `~/.bashrc`, so a new terminal has it too.
  </Step>
  <Step title="Check it">
    ```bash
    postqueen auth:status
    ```

    ```text
    🔑 Authentication method: API Key (environment variable)
    🔑 Key: a1b2c3d4...

    🔄 Verifying credentials...
    ✅ Credentials are valid. 3 integration(s) connected.
    ```
  </Step>
</Steps>

The CLI uses the API key only. There is no browser login: `postqueen auth:login` only prints how to set the key.

## Schedule a first post

<Steps>
  <Step title="Find the channel ID">
    ```bash
    postqueen integrations:list
    ```

    ```text
    🔌 Connected Integrations:
    [
      {
        "id": "cmf1abc2d0001",
        "name": "PostQueen Bakery",
        "identifier": "bluesky",
        "picture": "https://...",
        "disabled": false,
        "profile": "postqueenbakery.bsky.social"
      }
    ]
    ```

    `identifier` is the network. Copy the `id` of the channel you want.
  </Step>
  <Step title="Create the post">
    ```bash
    postqueen posts:create \
      -c "Our spring menu is live. Come by this weekend." \
      -s "2026-10-01T09:00:00Z" \
      -i "cmf1abc2d0001"
    ```

    ```text
    ✅ Post created successfully!
    [
      {
        "postId": "cmf1xyz9k0042",
        "integration": "cmf1abc2d0001"
      }
    ]
    ```

    `-s` is the publish time in ISO 8601 and is required. Add `-t draft` to save a draft instead.
  </Step>
  <Step title="See it on the calendar">
    The post is on your calendar in the app, and in `postqueen posts:list`.
  </Step>
</Steps>

Some networks need settings of their own before they accept a post. WordPress, for example, needs a `title` and a post `type`. `postqueen integrations:settings <id>` shows what a channel needs, and [examples by network](/cli/platform-examples) has a working command for each.

## Read the output

Most commands print one status line, then the result as JSON. Drop the first line before you parse it:

```bash
postqueen integrations:list | tail -n +2 | jq -r '.[] | "\(.identifier)\t\(.id)"'
```

`posts:missing` prints JSON only, and `posts:delete` prints only a confirmation line. When a command fails, the message goes to stderr and the command exits with code `1`.

## Use it from an AI agent

An agent that runs shell commands, such as Claude Code, Cursor, Gemini CLI, Grok Build, OpenClaw or Hermes Agent, can drive the CLI. Install [the postqueen skill](/agents/skill) so it knows the commands and the rules:

```bash
npx skills add GkhanKINAY/postqueen-agent
```

Set `POSTQUEEN_API_KEY` where the agent's commands run, which is not always your own terminal.

### CLI or MCP?

| Pick | When |
|---|---|
| [MCP](/mcp/introduction) | The agent supports MCP. Nothing to install. Codex should use MCP: its sandbox asks before every command that uses the network |
| CLI | The agent runs commands, or you are writing a script, a scheduled job or a CI step. The CLI can also delete posts, move them between draft and scheduled, and read channel numbers, which MCP cannot do yet, and it uploads files from disk in any agent |

The full comparison is on [AI agents](/agents/overview#three-ways-to-connect).
