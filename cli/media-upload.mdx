A post takes media only from your PostQueen media library. A file on your disk or a link to another site is refused, so every image and video goes through `postqueen upload` first. The upload returns a `path`, and that path is what `-m` takes.

## Upload a file

```bash
postqueen upload spring-menu.jpg
```

```text
✅ File uploaded successfully!
{
  "id": "cmf2med0a0007",
  "name": "a1b2c3d4e5.jpg",
  "originalName": null,
  "path": "https://.../a1b2c3d4e5.jpg",
  "thumbnail": null,
  "alt": null,
  "status": "ready",
  ...
}
```

The answer is the new media item. You need two fields: `path`, which goes into a post, and `id`, which you use to check a video. The file also appears in the app's media library.

## Attach it to a post

```bash
IMG=$(postqueen upload spring-menu.jpg | tail -n +2 | jq -r '.path')

postqueen posts:create \
  -c "Our spring menu is live." \
  -m "$IMG" \
  -s "2026-10-01T09:00:00Z" \
  -i "your-channel-id"
```

`tail -n +2` drops the status line so `jq` gets JSON. For several files, separate the paths with commas: `-m "$IMG1,$IMG2"`. In a `--json` file, each image is an object with the `id` and `path` from the upload.

## What you can upload

| What | Limit |
|---|---|
| Images | JPEG, PNG, GIF, WebP, AVIF, BMP, TIFF |
| Video | MP4, MOV (converted to MP4) |
| Size | Up to 1 GB per file |
| Attach to a post | Only `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp` and `.mp4` paths |

PostQueen reads the file's contents to tell its type, so renaming a file does not change what it is. AVIF, BMP and TIFF upload fine but a post refuses them with `File must have a valid extension: .png, .jpg, .jpeg, .gif, .webp, or .mp4`: convert them to JPEG or PNG before you upload. Each network also has its own, much smaller limits on what it publishes; `postqueen integrations:settings <channel-id>` lists them under `rules`.

## Wait for a video

An image is ready as soon as the upload returns. A video comes back with `"status": "processing"` while PostQueen checks it and, when needed, converts it into an MP4 the networks accept. That takes from a few seconds to a few minutes.

- **An MP4** can go into a post right away, with the `path` from the upload answer. When the post publishes, PostQueen uses the converted file.
- **A MOV** is converted to MP4 first, and a post takes no MOV, so wait until it is ready and use the new `path`.

The CLI has no command for the wait. Ask the API's [media status](/public-api/uploads/media-status) route until the status changes, then take the `path` from its answer:

```bash
VIDEO_ID=$(postqueen upload launch.mov | tail -n +2 | jq -r '.id')

STATUS=processing
while [ "$STATUS" = "processing" ]; do
  sleep 5
  MEDIA=$(curl -s "https://api.postqueen.ai/public/v1/media/$VIDEO_ID/status" \
    -H "Authorization: $POSTQUEEN_API_KEY")
  STATUS=$(echo "$MEDIA" | jq -r '.status')
done

if [ "$STATUS" != "ready" ]; then
  echo "$MEDIA" | jq -r '.processingError // .' >&2
  exit 1
fi

VIDEO=$(echo "$MEDIA" | jq -r '.path')
```

The API takes the key as it is in the `Authorization` header, with no `Bearer` in front. When the status is `failed`, `processingError` says why. A MOV that fails is removed from the library.

## Upload from a link

The CLI uploads files from your disk only. To bring in an image or video from a public link, call the API's [upload from URL](/public-api/uploads/upload-from-url) route, or ask an agent connected over [MCP](/mcp/tools#uploadfromurltool).

## Limits

Uploads count against an hourly allowance per workspace, separate from the one for creating posts. [Limits and errors](/public-api/limits-and-errors) has the details.

## If an upload fails

| Message | What to do |
|---|---|
| `Failed to upload file: ENOENT: no such file or directory` | The path is wrong, so nothing was sent. `upload` takes a file on your disk, not a link |
| `Upload failed (400): ... Unsupported file type.` | The file is not one of the types above. Convert it; renaming it does not help |
| `Upload failed (413): ... File too large` | The file is over 1 GB. Export a smaller version |
| `File must have a valid extension: .png, .jpg, .jpeg, .gif, .webp, or .mp4` (on `posts:create`) | The file uploaded, but posts do not take its type. Convert it and upload again |
| A video post fails, or its file is gone | The video was still processing when you posted its first `path`. Wait for `ready` and use the new `path` |
