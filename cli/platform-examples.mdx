Each network wants its own settings, and PostQueen refuses a post that is missing a required one. This page has a command for the networks people post to most, with the settings each one needs. Replace `bluesky-id` and the others with your channel IDs from `postqueen integrations:list`.

<Warning>
These commands schedule real posts. To try one safely, add `-t draft`: the post waits on your calendar until you schedule it. A draft gets the settings check, so a missing required setting is refused at once. The length and media rules wait until you schedule it, so an accepted draft can still be refused then.
</Warning>

When you post to a network for the first time, read its rules and settings:

```bash
postqueen integrations:settings <channel-id>
```

## Networks you connect with a key or a login

### Bluesky

No settings. A post has up to 300 characters, and extra `-c` items become a thread.

```bash
postqueen posts:create \
  -c "Our spring menu is live. Come by this weekend." \
  -c "Every dish now comes in a smaller size too." \
  -s "2026-10-01T09:00:00Z" \
  -i "bluesky-id"
```

### Nostr

No settings. Extra `-c` items become a thread of replies.

```bash
postqueen posts:create \
  -c "Open on Sunday this week." \
  -s "2026-10-01T09:00:00Z" \
  -i "nostr-id"
```

### WordPress

Needs a `title` and a `type`, the WordPress post type. Look the type up with `postTypes`, and categories and tags with `categoriesList` and `tagsList`: they go in as lists of numbers.

```bash
# Answers [{ "id": "posts", "name": "Posts" }, ...]
postqueen integrations:trigger wordpress-id postTypes
# Answers [{ "id": 4, "name": "News" }, ...]
postqueen integrations:trigger wordpress-id categoriesList

postqueen posts:create \
  -c "<h2>What is new</h2><p>Every dish now comes in a smaller size.</p>" \
  -s "2026-10-02T08:00:00Z" \
  --settings '{"title":"Our spring menu","type":"posts","categories":[4],"status":"publish"}' \
  -i "wordpress-id"
```

`status` is optional: `publish`, `draft`, `pending` or `private` on your WordPress site. `main_image` takes an uploaded image as `{"id":"...","path":"..."}`.

### DEV

Needs a `title` of 2 to 128 characters. `tags` takes up to four, as the `value` and `label` pairs the `tags` helper returns. `organization` (from `organizations`), `canonical` and `main_image` are optional.

```bash
# Answers [{ "value": 8, "label": "webdev" }, ...]
postqueen integrations:trigger devto-id tags

postqueen posts:create \
  -c "Version 2.4 adds offline mode and fixes the login loop." \
  -s "2026-10-01T15:00:00Z" \
  --settings '{"title":"Version 2.4 is out","tags":[{"value":8,"label":"webdev"}]}' \
  -i "devto-id"
```

Use the tag numbers `tags` returns for your account; the `8` here is an example.

### Hashnode

Needs a `title` of at least 6 characters, a `publication` ID from `publications`, and at least one tag. Each tag is a `value` and a `label`: the `objectID` and `name` of a tag from `tagsList`. The example uses the JavaScript tag.

```bash
# Answers [{ "id": "...", "name": "My blog" }]
postqueen integrations:trigger hashnode-id publications

postqueen posts:create \
  -c "Version 2.4 adds offline mode and fixes the login loop." \
  -s "2026-10-01T15:00:00Z" \
  --settings '{"title":"Version 2.4 is out","publication":"PUBLICATION_ID","tags":[{"value":"56744721958ef13879b94cad","label":"JavaScript"}]}' \
  -i "hashnode-id"
```

### Lemmy

Needs a `subreddit` list with at least one community. Each entry has the community's `subreddit` (its name), its `id` as a string, and a `title` of 3 to 200 characters; `url` is optional. Find communities with `subreddits`:

```bash
# Answers [{ "id": 123, "name": "Baking", ... }]
postqueen integrations:trigger lemmy-id subreddits -d '{"word":"baking"}'

postqueen posts:create \
  -c "Our sourdough starter guide, three weeks in." \
  -s "2026-10-01T09:00:00Z" \
  --settings '{"subreddit":[{"value":{"subreddit":"Baking","id":"123","title":"Sourdough starter, three weeks in"}}]}' \
  -i "lemmy-id"
```

### Listmonk

Needs a `subject`, a `preview` text and a `list` ID from `list`. `template` (from `templates`) is optional. Both IDs go in as strings.

```bash
# Answers [{ "id": 3, "name": "Newsletter" }]
postqueen integrations:trigger listmonk-id list

postqueen posts:create \
  -c "<p>This month: the spring menu, and a new Sunday brunch.</p>" \
  -s "2026-10-01T07:00:00Z" \
  --settings '{"subject":"Spring at the bakery","preview":"The spring menu is here","list":"3"}' \
  -i "listmonk-id"
```

### Moltbook

Needs a `submolt`, the name of the community to post in. `integrations:settings` reports no settings for Moltbook, but a post without `submolt` is refused.

```bash
postqueen posts:create \
  -c "Notes from our first week of letting an agent run our bakery's posts." \
  -s "2026-10-01T09:00:00Z" \
  --settings '{"submolt":"SUBMOLT_NAME"}' \
  -i "moltbook-id"
```

## Networks you connect by signing in

### X

Every regular post needs `who_can_reply_post`: `everyone`, `following`, `mentionedUsers`, `subscribers` or `verified`. There is no default, and a post without it is refused, drafts included.

```bash
postqueen posts:create \
  -c "Our spring menu is live." \
  -c "Every dish now comes in a smaller size too." \
  -d 2 \
  -s "2026-10-01T09:00:00Z" \
  --settings '{"who_can_reply_post":"everyone"}' \
  -i "x-id"
```

A post has up to 280 characters unless the account has X Premium. For a long-form article, set `post_type` to `article` with an `article_title` and an `article_status` (`draft` or `published`), and write the text as HTML; `who_can_reply_post` is not needed then. `community` (an `https://x.com/i/communities/...` address), `made_with_ai` and `paid_partnership` are optional.

### Instagram

Needs `post_type`: `post`, `reel` or `story`, and at least one uploaded image or video.

```bash
IMG=$(postqueen upload spring-menu.jpg | tail -n +2 | jq -r '.path')

postqueen posts:create \
  -c "Spring menu, out now." \
  -m "$IMG" \
  -s "2026-10-01T09:00:00Z" \
  --settings '{"post_type":"post"}' \
  -i "instagram-id"
```

`collaborators` (up to three) is optional. On an Instagram channel connected through Facebook, `audio` adds a track found with the `audioSearch` helper.

### Facebook

No required settings. `post_type` (`post` or `story`) and `url` are optional.

```bash
postqueen posts:create \
  -c "Open on Sunday this week." \
  -s "2026-10-01T09:00:00Z" \
  -i "facebook-id"
```

### Threads

No settings. Extra `-c` items become a thread.

```bash
postqueen posts:create \
  -c "Our spring menu is live." \
  -s "2026-10-01T09:00:00Z" \
  -i "threads-id"
```

### TikTok

Needs these eight settings, with no defaults:

| Setting | Values | Note |
|---|---|---|
| `content_posting_method` | `DIRECT_POST` or `UPLOAD` | `DIRECT_POST` publishes. `UPLOAD` only sends the video to the TikTok app's inbox, where you finish it within 24 hours, and TikTok then ignores the other settings |
| `privacy_level` | `PUBLIC_TO_EVERYONE`, `MUTUAL_FOLLOW_FRIENDS`, `FOLLOWER_OF_CREATOR` or `SELF_ONLY` | Pick one the account allows: the `creatorInfo` helper lists them |
| `duet` | `true` or `false` | Videos only |
| `stitch` | `true` or `false` | Videos only |
| `comment` | `true` or `false` | Whether people can comment |
| `autoAddMusic` | `yes` or `no` | Photo posts only |
| `brand_content_toggle` | `true` or `false` | The post promotes another brand |
| `brand_organic_toggle` | `true` or `false` | The post promotes your own brand |

`title` (up to 90 characters) and `video_made_with_ai` are optional.

Upload the video and use its `path` as `$VIDEO`. An MP4 can go in right away; a MOV has to [finish converting](/cli/media-upload#wait-for-a-video) first:

```bash
postqueen posts:create \
  -c "How we shape a sourdough loaf #baking" \
  -m "$VIDEO" \
  -s "2026-10-01T17:00:00Z" \
  --settings '{"privacy_level":"PUBLIC_TO_EVERYONE","duet":false,"stitch":false,"comment":true,"autoAddMusic":"no","brand_content_toggle":false,"brand_organic_toggle":false,"content_posting_method":"DIRECT_POST"}' \
  -i "tiktok-id"
```

### YouTube

Needs a `title` of 2 to 100 characters, without `<` or `>`, and a `type`: `public`, `private` or `unlisted`. `selfDeclaredMadeForKids` (`yes` or `no`), `thumbnail` and `tags` are optional; all tags together may have 500 characters. A post takes one video, and `-c` is its description.

```bash
postqueen posts:create \
  -c "Shaping a sourdough loaf, start to finish." \
  -m "$VIDEO" \
  -s "2026-10-01T17:00:00Z" \
  --settings '{"title":"How we shape sourdough","type":"public","selfDeclaredMadeForKids":"no"}' \
  -i "youtube-id"
```

## Several networks in one command

A `--json` file gives each channel its own text and settings:

```json campaign.json
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00Z",
  "shortLink": true,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "bluesky-id" },
      "value": [{ "content": "Our spring menu is live.", "image": [] }]
    },
    {
      "integration": { "id": "wordpress-id" },
      "value": [{ "content": "<p>Every dish now comes in a smaller size.</p>", "image": [] }],
      "settings": { "title": "Our spring menu", "type": "posts" }
    },
    {
      "integration": { "id": "devto-id" },
      "value": [{ "content": "The spring menu, and how we built its ordering page.", "image": [] }],
      "settings": { "title": "Building our spring menu page", "tags": [] }
    }
  ]
}
```

```bash
postqueen posts:create --json campaign.json
```

## A week of posts

A shell loop schedules one post a day on two channels:

```bash
DATES=("2026-10-05T09:00:00Z" "2026-10-06T09:00:00Z" "2026-10-07T09:00:00Z")
TEXTS=("Monday: fresh rye." "Tuesday: cinnamon rolls." "Wednesday: sourdough day.")

for i in "${!DATES[@]}"; do
  postqueen posts:create -c "${TEXTS[$i]}" -s "${DATES[$i]}" -i "bluesky-id,nostr-id"
done
```
