Two commands read analytics: `analytics:platform` for a channel, such as its followers and impressions over time, and `analytics:post` for one published post.

## Which networks report numbers

Nine networks send analytics to PostQueen. Every other channel answers with an empty list, `[]`.

| Network | Channel windows | One post's numbers | Followers | Status today |
|---|---|---|---|---|
| X | 7, 30, 90 days | Yes | No | [In review](/channels/x-twitter) |
| Facebook Page | 7, 30, 90 days | Yes | Yes | [In review](/channels/facebook) |
| Instagram | 7, 30 days | Yes | Yes | [In review](/channels/instagram) |
| Threads | 7, 30 days | Yes | No | [In review](/channels/threads) |
| TikTok | 7, 30 days | Yes | Yes | [In review](/channels/tiktok) |
| YouTube | 7, 30, 90 days | Yes | Yes | [In review](/channels/youtube) |
| LinkedIn Page | 7, 30, 90 days | Yes | Yes | [Soon](/channels/linkedin) |
| Pinterest | 7, 30, 90 days | Yes | No | [Soon](/channels/pinterest) |
| Google Business Profile | 7, 30, 90 days | No | No | [Soon](/channels/google-my-business) |

The networks you can connect without limits today, such as Bluesky, WordPress and DEV, report no analytics.

## A channel's numbers

```bash
postqueen analytics:platform <channel-id>          # the last 7 days
postqueen analytics:platform <channel-id> -d 30    # the last 30 days
```

`-d` is the number of days to look back, `7` by default. Use a window the table lists for that network. PostQueen passes any other number to the network unchanged, and the network may refuse it. The answer is a list of metrics, each with a value per day and the change over the window:

```text
📊 Analytics for integration: cmf1abc2d0003
[
  {
    "label": "Impressions",
    "data": [
      { "total": "5000", "date": "2026-09-01" },
      { "total": "5200", "date": "2026-09-02" }
    ],
    "percentageChange": 4
  }
]
```

The labels depend on the network. PostQueen keeps a channel's answer for an hour, so asking again within the hour returns the same numbers.

## One post's numbers

```bash
postqueen analytics:post <post-id>
postqueen analytics:post <post-id> -d 30
```

The answer has the same shape: a list of metrics such as likes, comments and impressions. It can also be:

- `[]`: the post has not been published yet, or its network gives no numbers per post.
- `{"missing": true}`: the post was published, but PostQueen does not know its ID on the network. Fix it below.

## Fix a missing release ID

When a network does not return the post's ID after publishing, PostQueen marks it as missing and cannot read its numbers. This happens with TikTok, which is also the only network that can list its recent posts for you to pick from.

<Steps>
  <Step title="List the channel's recent posts">
    ```bash
    postqueen posts:missing <post-id>
    ```

    ```json
    [
      { "id": "7321456789012345678", "url": "https://.../cover.jpeg" },
      { "id": "7321456789012345679", "url": "https://.../cover2.jpeg" }
    ]
    ```

    Each item is a post on the network, with its cover image. This command prints JSON with no status line. Every other network answers `[]`.
  </Step>
  <Step title="Connect the right one">
    ```bash
    postqueen posts:connect <post-id> --release-id "7321456789012345678"
    ```
  </Step>
  <Step title="Read the numbers">
    ```bash
    postqueen analytics:post <post-id>
    ```
  </Step>
</Steps>

## Totals and top posts

The CLI reads one channel or one post at a time. For totals across your published posts, or your best posts ranked, use the API's [analytics summary](/public-api/analytics/summary) and [post analytics](/public-api/analytics/posts) routes, or ask an agent over [MCP](/mcp/tools#analytics).

## Use the numbers in a script

Drop the status line with `tail -n +2`, then read the JSON with `jq`:

<CodeGroup>

```bash Change per metric
postqueen analytics:platform <channel-id> -d 30 | tail -n +2 | jq -r '.[] | "\(.label): \(.percentageChange)%"'
```

```bash Latest value of one metric
postqueen analytics:platform <channel-id> | tail -n +2 | jq -r '.[] | select(.label=="Impressions") | .data[-1].total'
```

```bash Latest value per post metric
postqueen analytics:post <post-id> | tail -n +2 | jq '.[] | {label, latest: .data[-1].total}'
```

</CodeGroup>
