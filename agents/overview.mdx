Any assistant that can run a command or call a tool can put posts on your calendar. OpenClaw and Hermes live on your machine. Grok Bot is the cloud agent. Claude, ChatGPT and the rest connect over MCP.

The calendar stays yours: everything is visible before it publishes. A draft is saved and never scheduled.

<Info>
**Anything that runs a shell command.** Install the CLI (`npm install -g postqueen`), optionally add the skill playbook, export your key, and it can schedule while you work. A cron job or a CI step qualifies on the same terms.
</Info>
