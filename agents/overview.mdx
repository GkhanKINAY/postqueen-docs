An AI agent can do in PostQueen much of what you do in the app: list your channels, write and schedule posts, add images and videos, and read how published posts did. Every post it makes lands on your calendar. A draft or a scheduled post waits there, so you can check it, change it or delete it before it goes out.

## Three ways to connect

<CardGroup cols={3}>
  <Card title="MCP server" icon="plug" href="/mcp/introduction">
    For chat assistants and most coding agents. Paste one address and the agent gets {{mcpToolsKey}} tools. Nothing to install.
  </Card>
  <Card title="CLI and skill" icon="terminal" href="/cli/introduction">
    For agents that run shell commands, and for your own scripts. The `postqueen` command, plus a skill that teaches it to the agent.
  </Card>
  <Card title="Public API" icon="code" href="/public-api/introduction">
    For your own apps and automations. REST calls with your API key.
  </Card>
</CardGroup>

Use MCP when your agent supports it: it finds the tools on its own. Use the CLI when the agent works in a terminal, or when you need something MCP cannot do yet.

| What the agent needs to do | MCP | CLI | API |
|---|---|---|---|
| Schedule a post or save a draft | Yes | Yes | Yes |
| Publish a post right away | Yes | With a `--json` file | Yes |
| List posts and read one in full | Yes | List | Yes |
| Change the settings of a post that has not gone out | Yes | Yes | Yes |
| Move a post between draft and scheduled | No | Yes | Yes |
| Delete a post | No | Yes | Yes |
| Add a file from your device | In Claude, Claude Cowork and ChatGPT | Yes | Yes |
| Add a file from a public link | Yes | No | Yes |
| Generate an image | Yes | No | No |
| Read how published posts did | Yes | One post at a time | Yes |
| Totals and top posts across the workspace | Yes | No | Yes |
| Read channel numbers, such as followers | No | Yes | Yes |

Connect channels and edit a post's text or time in the app.

## Before you start

- **A PostQueen workspace on a trial or a paid plan.** Agents post through your workspace, so its plan limits apply to them too.
- **A workspace admin.** Only an Admin or Super Admin can reveal the API key or approve a sign-in.
- **At least one connected channel.** An agent posts only to channels you connected in the app. See [connect a channel](/using/connect-a-channel).

## Every agent

**How it connects** is what you set up in the agent. **Sign-in or key** says whether the agent can sign in to PostQueen or takes your API key.

## You stay in charge

<CardGroup cols={2}>
  <Card title="Drafts wait for you" icon="notebook-pen">
    Ask for drafts and they stay on your calendar until you schedule them.
  </Card>
  <Card title="Every post on your calendar" icon="calendar-days">
    You see each post before it goes out, and you can edit or delete it until its time.
  </Card>
  <Card title="Access you can take back" icon="key-round">
    An admin rotates the API key under **Connections > API Keys**, which stops every agent that used it, or revokes one sign-in under **Connections > Approved Apps**.
  </Card>
  <Card title="No social passwords" icon="shield-check">
    The agent never sees the passwords of your social accounts. It works through PostQueen, which posts with each network's own API.
  </Card>
</CardGroup>
