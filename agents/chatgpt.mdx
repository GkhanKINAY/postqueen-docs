ChatGPT is OpenAI's AI assistant. You add PostQueen as a custom MCP server from the Plugins page on the web, and ChatGPT can then list your channels, write posts for PostQueen to schedule, add a file from your device, and tell you how your published posts did.

## Before you start

- **Plans:** Business, Enterprise and Edu, on the web. Pro can connect custom MCP servers with read and fetch tools only, so it cannot create posts. On Business only admins and owners can add it. On Enterprise and Edu, admins and owners can add it, and other members need an admin to grant them **Create plugins with MCPs**. See [OpenAI's help page](https://help.openai.com/en/articles/12584461).
- **Platforms:** ChatGPT on the web only, not the mobile apps.
- **A PostQueen API key.** A workspace admin copies it, or the ready-made address, from **Connections**.

## Connect ChatGPT

These steps use the key address with **No authentication**. To sign in instead of using a key, see [Other ways to connect](#other-ways-to-connect).

<Steps>
  <Step title="Add a custom MCP server">
    Go to [chatgpt.com/plugins](https://chatgpt.com/plugins) (**Plugins**), select **+**, then **Add custom MCP server**.
  </Step>
  <Step title="Fill in the server">
    Enter the name `PostQueen`; the description is optional. Under **Connection**, paste your key address into **Server URL**:

    ```text wrap
    https://api.postqueen.ai/mcp/YOUR_API_KEY
    ```
  </Step>
  <Step title="Choose No authentication">
    Set **Authentication** to **No authentication**, since the key is part of the address. Tick **I understand and want to continue**.
  </Step>
  <Step title="Create the plugin and install it">
    Select **Create as a plugin**, then install it.
  </Step>
  <Step title="Pick it in a chat">
    In a new chat, type **@** and pick PostQueen.
  </Step>
</Steps>

## Check that it works

Ask ChatGPT: "List my PostQueen channels." It answers with the channels you connected in PostQueen. By default, ChatGPT asks you to confirm each action that changes something, such as scheduling a post; review what it will send, then confirm.

## Good to know

- **ChatGPT cannot add PostQueen for you.** It works with the tools once you add the plugin yourself.
- **The address carries your API key.** Keep it private. If it leaks, a workspace admin rotates the key under **Connections > API key**, and you update the plugin.
- **Upload from your device.** PostQueen's upload widget opens an **Upload Media** panel in ChatGPT, where you add a photo or video from your device.
- **The ChatGPT desktop app's MCP servers setting belongs to Codex,** not to the web chat. Add PostQueen on the web.
- **ChatGPT cannot run the PostQueen CLI.** Use the MCP address.
- **Ask for drafts when you want to check first.** A draft waits on your PostQueen calendar, and nothing publishes until you schedule it.
- **What it cannot do over MCP:** delete a post, or change a post's text or time. Do that on the calendar in the app. [The MCP tools](/mcp/tools) lists what it can do.

<Accordion title="Sign in with PostQueen instead" icon="log-in">
  With the sign-in, no key is copied or stored in ChatGPT. Only a workspace admin can approve it.

  <Steps>
    <Step title="Add the server with the sign-in address">
      At [chatgpt.com/plugins](https://chatgpt.com/plugins), select **+**, then **Add custom MCP server**. Enter the name `PostQueen`, and under **Connection** paste `https://api.postqueen.ai/mcp-oauth-dynamic` into **Server URL**.
    </Step>

      Set **Authentication** to **OAuth** and tick **I understand and want to continue**. Select **Create as a plugin**, install it, then sign in to PostQueen and approve.
    </Step>
    <Step title="Pick it in a chat">
      In a new chat, type **@** and pick PostQueen.
    </Step>
  </Steps>

  The access does not expire on its own. Revoke it in PostQueen under **Connections > Approved Apps**.
</Accordion>

## Try this first

```text wrap
List my PostQueen channels. Then write a short Bluesky post about our weekend sale and save it as a draft for Friday at 6pm.
```

The draft appears on your PostQueen calendar, ready for you to check and schedule. [Prompts to try](/mcp/examples) has more.

## Troubleshooting

| Symptom | Fix |
|---|---|
| A guide says to turn on **Developer mode** | You no longer need Developer mode. Add PostQueen at chatgpt.com/plugins. |
| You cannot add a custom MCP server | On Business, only admins and owners can add one. On Enterprise and Edu, admins and owners can add one, and other members need an admin to grant them **Create plugins with MCPs**. |
| PostQueen is not in the chat | In a new chat, type **@** and pick PostQueen. |
| The desktop app's MCP servers setting does not show in ChatGPT on the web | That setting belongs to Codex. Add PostQueen to ChatGPT on the web. |
| ChatGPT can read but not create posts | On Pro, a custom MCP server gets read and fetch tools only. Creating posts needs Business, Enterprise or Edu. |
| The key is refused | Copy the address again from the ChatGPT card on **Connections**. Only a workspace Admin or Super Admin can reveal the key. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).

## Is it the same as Codex?

No. OpenAI's coding agent, Codex, has its own setup:

| Product | What it is | How it connects |
|---|---|---|
| **ChatGPT** (this page) | OpenAI's assistant on the web | A custom MCP server, created as a plugin at chatgpt.com/plugins |
| [Codex](/agents/codex) | OpenAI's coding agent: CLI, IDE extension and the ChatGPT desktop app | One `codex mcp add` command |

ChatGPT on the web does not read Codex's config, so a server you add to Codex does not reach the web chat.
