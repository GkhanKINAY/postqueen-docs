ChatGPT is OpenAI's AI assistant. You add PostQueen as a developer mode app from the Plugins page on the web, and ChatGPT can then list your channels, write and schedule posts, add a file from your device, and tell you how your published posts did.

## Before you start

- **Plans:** Plus, Pro, Business, Enterprise and Education, on the web. Not Free. OpenAI's pages disagree on which plans can make changes such as scheduling a post, so check yours on [OpenAI's developer mode help page](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt).
- **Platforms:** ChatGPT on the web only.
- **A PostQueen API key.** A workspace admin copies it, or the ready-made address, from **Connections**.

## Connect ChatGPT

These steps use the key address with **No Authentication**. To sign in instead of using a key, see [Other ways to connect](#other-ways-to-connect).

<Steps>
  <Step title="Turn on developer mode">
    In ChatGPT on the web, open **Settings > Security and login** and turn on **Developer mode**. On Business, Enterprise and Education, an admin first allows it under **Workspace settings > Permissions & roles**.
  </Step>
  <Step title="Create the app">
    Go to [chatgpt.com/plugins](https://chatgpt.com/plugins) and press **+**. Enter the name `PostQueen` and a short description, and under **Connection** enter your key address:

    ```text wrap
    https://api.postqueen.ai/mcp/YOUR_API_KEY
    ```
  </Step>
  <Step title="Choose No Authentication">
    Set **Authentication** to **No Authentication**, since the key is part of the address, and create the app. It appears under **Drafts**.
  </Step>
  <Step title="Select it in a chat">
    In a chat, open the **+** menu, choose **Developer mode** and select PostQueen.
  </Step>
</Steps>

## Check that it works

Ask ChatGPT: "List my PostQueen channels." It answers with the channels you connected in PostQueen. ChatGPT asks you to confirm each action that changes something, such as scheduling a post; review what it will send, then confirm.

## Good to know

- **The Plugins page is the current path.** Guides that say **Settings > Apps > Advanced settings** describe the older menus.
- **ChatGPT cannot add PostQueen for you.** It works with the tools once you add the app yourself.
- **The address carries your API key.** Keep it private. If it leaks, a workspace admin rotates the key under **Connections > API Keys**, and you update the app.
- **Upload from your device.** PostQueen's upload widget opens an **Upload Media** panel in ChatGPT, where you add a photo or video from your device.
- **The ChatGPT desktop app's MCP servers setting belongs to Codex,** not to the web chat. Add PostQueen on the web.
- **ChatGPT cannot run the PostQueen CLI.** Use the MCP address.
- **Ask for drafts when you want to check first.** A draft waits on your PostQueen calendar, and nothing publishes until you schedule it.
- **What it cannot do over MCP:** delete a post, or change a post's text or time. Do that on the calendar in the app. [The MCP tools](/mcp/tools) lists what it can do.

<Accordion title="Sign in with PostQueen instead" icon="log-in">
  With the sign-in, no key is copied or stored in ChatGPT. Only a workspace admin can approve it.

  <Steps>
    <Step title="Create the app with the sign-in address">
      At [chatgpt.com/plugins](https://chatgpt.com/plugins), press **+**, enter the name `PostQueen` and a description, and under **Connection** enter `https://api.postqueen.ai/mcp-oauth-dynamic`.

    </Step>
  </Steps>

  The access does not expire on its own. Revoke it in PostQueen under **Connections > Approved Apps**.
</Accordion>

## Try this first

```text wrap
List my PostQueen channels. Then write a short Bluesky post about our weekend sale and save it as a draft for Friday at 6pm.
```

The draft appears on your PostQueen calendar, ready for you to check and schedule. [Prompts to try](/mcp/examples) has more.

## Troubleshooting

| Symptom | Fix |
|---|---|
| There is no **Developer mode** option | Turn it on under **Settings > Security and login**. On Business, Enterprise and Education, an admin allows it first under **Workspace settings > Permissions & roles**. |
| A guide says **Settings > Apps > Advanced settings** | That is the older path. Add PostQueen at chatgpt.com/plugins. |
| PostQueen is not in the chat | Open the **+** menu, choose **Developer mode** and select PostQueen. |
| The desktop app's MCP servers setting does nothing in chat | That setting belongs to Codex. Add PostQueen to ChatGPT on the web. |
| ChatGPT can read but not schedule | Your plan may have read access only in developer mode. Check [OpenAI's help page](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt). |
| The key is refused | Copy the address again from the ChatGPT card on **Connections**. Only a workspace Admin or Super Admin can reveal the key. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).

## Is it the same as Codex?

No. OpenAI's coding agent, Codex, has its own setup:

| Product | What it is | How it connects |
|---|---|---|
| **ChatGPT** (this page) | OpenAI's assistant on the web | A developer mode app at chatgpt.com/plugins |
| [Codex](/agents/codex) | OpenAI's coding agent: CLI, IDE extension and the ChatGPT desktop app | One `codex mcp add` command |

ChatGPT on the web does not read Codex's config, so a server you add to Codex does not reach the web chat.
