Hermes Agent is Nous Research's open-source agent with persistent memory, skills, scheduled jobs and gateways to Telegram, Discord, Slack, WhatsApp, Signal, email and more. You run it on your own computer or a server, or hosted in Hermes Cloud. Add PostQueen as an MCP server and Hermes can plan your posts, schedule them and report how they did, in a chat or on a schedule.

## Before you start

- **Plans:** Hermes Agent is free and open source (MIT). Nous Research also offers the Nous Portal subscription and hosted instances in Hermes Cloud.
- **Platforms:** wherever you run Hermes: macOS (Apple Silicon), Windows 10 and 11, Linux and WSL2, or Docker. The installer brings Python 3.11 and Node.
- **A PostQueen API key.** A workspace admin copies it, or the ready-made address, from **Connections**.

## Connect Hermes Agent

<Steps>
  <Step title="Add PostQueen to the config">
    Add this block to `~/.hermes/config.yaml`, with your key in place of `YOUR_API_KEY`:

    ```yaml ~/.hermes/config.yaml
    mcp_servers:
      postqueen:
        url: "https://api.postqueen.ai/mcp/YOUR_API_KEY"
    ```
  </Step>
  <Step title="Load the tools">
    Start a new `hermes chat`, or type `/reload-mcp` in a running session.
  </Step>
  <Step title="Test the connection">
    ```bash
    hermes mcp test postqueen
    ```
  </Step>
</Steps>

## Check that it works

Ask Hermes: "List my PostQueen channels." It calls PostQueen and answers with the channels you connected.

## Good to know

- **PostQueen is not in `hermes mcp catalog`.** The catalog, and the setup card you get by asking in chat, cover only servers Nous has approved. Add PostQueen in `config.yaml` or with `hermes mcp add`.
- **Hermes can edit the config for you** if you allow it, then run `/reload-mcp`.
- **Recurring jobs live in `hermes cron`,** not in `config.yaml`. See [Run it on a schedule](#run-it-on-a-schedule).
- **Ask for drafts when you want to check first.** A draft waits on your PostQueen calendar, and nothing publishes until you schedule it.
- **What it cannot do over MCP:** delete a post, or change a post's text or time. Do that on the calendar in the app. [The MCP tools](/mcp/tools) lists what it can do.

| Way | Address | Status |
|---|---|---|
| The key in the address | `{{mcpKeyUrl}}` | From Nous Research's docs. The route above |
| The Bearer header | `{{mcpBearerUrl}}` | From Nous Research's docs |

<Tabs>
  <Tab title="Bearer header">
    To keep the key out of `config.yaml`, add the server with a command and paste the key when Hermes asks:

    ```bash
    hermes mcp add postqueen --url https://api.postqueen.ai/mcp --auth header
    ```

    Hermes keeps the key in its own secrets file as `MCP_POSTQUEEN_API_KEY` and sends it as a Bearer token.
  </Tab>
  <Tab title="Sign in (not tested yet)">
    Set `auth: oauth` on the server, with the address `https://api.postqueen.ai/mcp-oauth-dynamic`. Hermes registers itself, opens the PostQueen sign-in in your browser and keeps the token on your machine. A workspace admin approves.

    The sign-in address has {{mcpToolsOauth}} tools, all but `ask_postqueen`. Revoke access in PostQueen under **Connections > Approved Apps**.
  </Tab>
</Tabs>

## Try this first

```text wrap
List my PostQueen channels. Then plan three short Bluesky posts about this week's news and save them in PostQueen as drafts, one a day at 9am from tomorrow.
```

The drafts appear on your PostQueen calendar, ready for you to check and schedule. [Prompts to try](/mcp/examples) has more.

## Run it on a schedule

Ask Hermes in chat, or run `hermes cron create`. Each job runs in a fresh session and can send its result to Telegram, Discord, Slack or email.

```bash
hermes cron create "weekdays at 9am" \
  "Save one post idea from my notes as a PostQueen draft"
```

Source: [Nous Research, scheduled tasks](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron).

## Troubleshooting

| Symptom | Fix |
|---|---|
| PostQueen is not in `hermes mcp catalog` | The catalog lists only servers Nous has approved. Add PostQueen with `hermes mcp add` or in `config.yaml`. |
| The tools do not show in a running chat | Type `/reload-mcp`, or start a new `hermes chat`. |
| You are not sure it connected | Run `hermes mcp test postqueen`. |
| The key is refused | Copy it again from **Connections > API Keys**. Only a workspace Admin or Super Admin can reveal it. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting). To message Hermes from WhatsApp, Telegram, Slack or Discord, see [Chat channels](/agents/chat-channels).
