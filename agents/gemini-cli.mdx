Gemini CLI is Google's AI agent for the terminal. Add PostQueen with one command and Gemini CLI can turn release notes into posts, schedule them and report how your published posts did.

## Before you start

- **Plans:** free with a personal Google account, up to 60 requests a minute and 1,000 a day.
- **Platforms:** the terminal on macOS 15+, Windows 11 24H2+ and Ubuntu 20.04+, with Node 20 or later.
- **A PostQueen API key.** A workspace admin copies it, or the ready-made address, from **Connections**.

## Connect Gemini CLI

<Steps>
  <Step title="Add PostQueen">
    Run this in your terminal, with your key in place of `YOUR_API_KEY`:

    ```bash
    gemini mcp add --transport http --scope user \
      postqueen https://api.postqueen.ai/mcp/YOUR_API_KEY
    ```

    `--scope user` writes `~/.gemini/settings.json`, so every folder can use PostQueen.
  </Step>
  <Step title="Check the tools">
    Start Gemini CLI and type `/mcp`. PostQueen is listed with its tools.
  </Step>
</Steps>

## Check that it works

Ask Gemini CLI: "List my PostQueen channels." It calls PostQueen and answers with the channels you connected.

## Good to know

- **Use the key address, not the sign-in.** Since v0.60.0, Gemini CLI refuses PostQueen's sign-in, so the sign-in address does not work here.
- **Without `--scope user`,** the command writes `.gemini/settings.json` in the current project only.
- **The command writes `"url"` with `"type": "http"`,** which works. `httpUrl` is the older key; a guide that calls `url` wrong is out of date.
- **Gemini CLI can run the command for you** if you allow it.
- **Ask for drafts when you want to check first.** A draft waits on your PostQueen calendar, and nothing publishes until you schedule it.
- **What it cannot do over MCP:** delete a post, or change a post's text or time. Do that on the calendar in the app. [The MCP tools](/mcp/tools) lists what it can do.

## Other ways to connect

| Way | Address | Status |
|---|---|---|
| The key in the address | `{{mcpKeyUrl}}` | From Google's docs. The route above |
| The Bearer header | `{{mcpBearerUrl}}` | From Google's docs |
| Sign in with PostQueen | Not offered | Does not work with Gemini CLI. Use the key |

To keep the key out of the address, send it as a header:

```bash
gemini mcp add --transport http --scope user \
  --header "Authorization: Bearer YOUR_API_KEY" \
  postqueen https://api.postqueen.ai/mcp
```

## Try this first

```text wrap
List my PostQueen channels. Then split our release notes into a short Bluesky thread and save it as a draft for tonight at 8pm.
```

The draft appears on your PostQueen calendar, ready for you to check and schedule. [Prompts to try](/mcp/examples) has more.

## Troubleshooting

| Symptom | Fix |
|---|---|
| The sign-in address fails | Gemini CLI refuses PostQueen's sign-in. Use the key address. |
| PostQueen is missing in another folder | The default scope is project. Add it again with `--scope user`. |
| A guide says your `url` setting is wrong | `url` with `"type": "http"` works. `httpUrl` is the older key. |
| The key is refused | Copy it again from **Connections > API Keys**. Only a workspace Admin or Super Admin can reveal it. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).
