Claude Code is Anthropic's coding agent for the terminal and IDEs. Add PostQueen with one command and Claude Code can turn a changelog into posts, schedule them and report how your published posts did, from the terminal you already have open.

## Before you start

- **Plans:** Pro, Max, Team, Enterprise or a Console (API) account. The free Claude plan does not include Claude Code.
- **Platforms:** the terminal on macOS, Linux and Windows, plus IDE integrations.
- **A PostQueen API key.** A workspace admin copies it, or the ready-made address, from **Connections**.

## Connect Claude Code

<Steps>
  <Step title="Add PostQueen">
    Run this in your terminal, with your key in place of `YOUR_API_KEY`:

    ```bash
    claude mcp add --transport http postqueen \
      https://api.postqueen.ai/mcp/YOUR_API_KEY
    ```

    Add `--scope user` to use PostQueen in every project. Without it, the server is saved for the current project only.
  </Step>
  <Step title="Check the server">
    Run `claude mcp list`. PostQueen is listed with its address.
  </Step>
  <Step title="Start a new session">
    Start a new Claude Code session so the PostQueen tools load.
  </Step>
</Steps>

## Check that it works

In the new session, ask: "List my PostQueen channels." Claude Code calls PostQueen and answers with the channels you connected. Type `/mcp` to see the server and its tools.

## Good to know

- **Scopes:** the default is local, this project only, stored in `~/.claude.json`. `--scope user` covers every project, and `--scope project` writes a shared `.mcp.json` into the project.
- **Keep the key out of a shared file.** `.mcp.json` expands `${VAR}` in the address and headers, so a committed file can read the key from your environment. Or use the header form below.
- **Claude Code can run the command for you** if you allow it, since it runs shell commands. The tools still load only in a new session.
- **A connector you added in Claude** on claude.ai also shows up in Claude Code when you log in with a claude.ai subscription.
- **Ask for drafts when you want to check first.** A draft waits on your PostQueen calendar, and nothing publishes until you schedule it.
- **What it cannot do over MCP:** delete a post, or change a post's text or time. Do that on the calendar in the app, or with the [PostQueen CLI](/cli/introduction). [The MCP tools](/mcp/tools) lists what it can do.

## Try this first

```text wrap
Read CHANGELOG.md and write a short Bluesky post about the latest release. Save it in PostQueen as a draft for tomorrow at 9am.
```

The draft appears on your PostQueen calendar, ready for you to check and schedule. [Prompts to try](/mcp/examples) has more.

## Run it on a schedule

Claude Code runs without a chat with `-p`, from cron or a CI job, and a `-p` run connects the same MCP servers as a normal session. It cannot stop to ask you for approval, so allow the PostQueen tools up front with `--allowedTools`:

```bash
claude -p "Turn CHANGELOG.md into three PostQueen drafts for Bluesky" \
  --allowedTools "mcp__postqueen"
```

`mcp__postqueen` allows every tool of the `postqueen` server and nothing else. Source: [Anthropic, run Claude Code programmatically](https://code.claude.com/docs/en/headless).

## Troubleshooting

| Symptom | Fix |
|---|---|
| PostQueen is missing from a session | Run `claude mcp list`, then start a new session so the tools load. |
| It works in one project only | The default scope is local. Add it again with `--scope user`. |
| The key is refused | Copy it again from **Connections > API Keys**. Only a workspace Admin or Super Admin can reveal it. |
| A `-p` run stops at a permission prompt | Add `--allowedTools "mcp__postqueen"` to the command. |
| You meant the Claude app | Claude and Claude Cowork use a connector instead. See [Claude](/agents/claude). |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).

## Is it the same as Claude?

No. Claude Code is Anthropic's coding agent, with its own command. Claude and Claude Cowork share a connector instead:

| Product | What it is | How it connects |
|---|---|---|
| **Claude Code** (this page) | Anthropic's coding agent for the terminal and IDEs | One `claude mcp add` command |
| [Claude](/agents/claude) | Anthropic's assistant on the web, desktop and mobile | A custom connector |
| [Claude Cowork](/agents/claude-cowork) | Claude's agent mode for everyday work | The Claude connector, switched on in a Cowork session |
