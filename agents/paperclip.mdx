Paperclip is an open-source app for running a team of AI agents, such as Claude Code, Codex, OpenClaw and Cursor, as a company: you set goals, hire agents, set budgets and approve their work from one dashboard. Connect PostQueen in its Connectors page and your agents can plan and draft posts for PostQueen to schedule. You choose which PostQueen tools they may use, and which ones ask you first.

## Before you start

- **Plans:** Paperclip is free and open source (MIT). You host it yourself, and no Paperclip account is needed.
- **Platforms:** your own macOS, Linux or WSL2 machine with Node 24.11 or later, or Docker. PostQueen's tools reach Paperclip's Claude Code and Codex agents, and agents on Paperclip's ACP engine.
- **A PostQueen API key.** A workspace admin copies it from **Connections**.

## Connect Paperclip

<Steps>
  <Step title="Add your own MCP server">
    In Paperclip, open **Connectors**, choose **Connect** on **Connect your own tool**, then **Connect your own MCP server**. Paste this address and choose **Continue**:

    ```text wrap
    https://api.postqueen.ai/mcp
    ```
  </Step>
  <Step title="Enter the key">
    Under **Advanced authentication**, choose **Key or token**, paste your PostQueen API key into **App key** on its own, without the word `Bearer`, and press **Check link**. Paperclip saves it as an encrypted secret.
  </Step>
  <Step title="Review the tools">
    Paperclip turns on every PostQueen tool as **Allowed**, including scheduling. To approve each post first, open PostQueen's **Permissions** and choose **Set all: Ask first** on the **Write** group.
  </Step>
  <Step title="Choose the agents">
    Choose which agents can use PostQueen: **Any agent**, or **Just agents I pick**.
  </Step>
</Steps>

## Check that it works

Assign a Claude Code or Codex agent a task: "List my PostQueen channels." The agent answers with the channels you connected in PostQueen.

## Good to know

- **Paperclip hands PostQueen's tools straight to its Claude Code and Codex agents, and to agents on its ACP engine.** For other agent types, the PostQueen CLI is the surer route.
- **Every value you enter becomes an encrypted Paperclip secret** and is never shown again.
- **A Claude Code agent managed by Paperclip ignores** servers added on the same machine with `claude mcp add`. Give it access in **Connectors** instead.
- **There is no `paperclipai` command for MCP connections yet.** Use the **Connectors** page.
- **Every tool starts as Allowed,** scheduling included. Set the **Write** group to **Ask first** in PostQueen's **Permissions** to approve each call, or to **Off** to keep agents to reading.
- **What it cannot do over MCP:** delete a post, or change a post's text or time. Do that on the calendar in the app. [The MCP tools](/mcp/tools) lists what it can do.

    The sign-in address has {{mcpToolsOauth}} tools, all but `ask_postqueen`. Revoke access in PostQueen under **Connections > Approved Apps**.

## Try this first

Assign this to a Claude Code or Codex agent:

```text wrap
List my PostQueen channels. Then plan next week's launch posts for Bluesky and save four of them in PostQueen as drafts, Monday to Thursday at 10am.
```

If you set the **Write** group to **Ask first**, approve the save when Paperclip asks. The drafts appear on your PostQueen calendar, ready for you to check and schedule. [Prompts to try](/mcp/examples) has more.

## Run it on a schedule

Add a routine with a cron schedule, such as `0 9 * * 1` for Mondays at 9am. Each run opens an issue for the routine's agent, which picks it up on its next heartbeat.

```text wrap
Save next week's Bluesky posts in PostQueen as drafts.
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| A Claude Code agent does not see PostQueen | Give that agent access to PostQueen in **Connectors**. Servers added with `claude mcp add` are ignored while Paperclip manages MCP. |
| Scheduling a post does nothing | Open PostQueen's **Permissions** in **Connectors**. The scheduling tool must be **Allowed** or **Ask first**, not **Off**. With **Ask first**, approve the call when Paperclip asks. |
| The key is refused | Paste the key on its own, without the word `Bearer`, copied from **Connections > API key**. Only a workspace Admin or Super Admin can reveal it. |
| Another agent type cannot use PostQueen | Claude Code and Codex agents, and agents on Paperclip's ACP engine, get the tools directly. Give other agents the PostQueen CLI instead. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).
