Muse is Meta's personal agent in the Muse app, on muse.ai and in WhatsApp. It launched in the US on September 8, 2026, and works on its own cloud computer at Meta, the Muse Secure VM. Connect PostQueen and Muse can write your posts from a chat, and PostQueen schedules them.

## Before you start

- **Plans:** Muse is free with a usage limit. Power costs \$20 a month and Maximum \$100 a month. Meta does not tie connectors to a plan.
- **Platforms:** the Muse app on iOS and Android, muse.ai on the web, WhatsApp and Mac. Muse is available in the US and Canada, and not in every location yet.
- **A PostQueen API key.** A workspace admin copies it from **Connections**.

## How Muse connects

Through a custom connector that Muse builds with you in chat. Meta also reviews connectors for its directory, and PostQueen is not listed there yet.

| Route | What Meta documents | For PostQueen |
|---|---|---|
| **A custom connector** | You ask Muse in chat to build one, from the service's API information | The steps below |
| **A listed connector** | Connectors Meta has reviewed, added under **Settings > Connectors** | Not listed yet |

## Connect with a custom connector

These are the steps Meta documents for a service that is not in the Connector list.

<Steps>
  <Step title="Copy your PostQueen API key">
    In PostQueen, open **Connections > API key** and copy the key. Only a workspace admin can reveal it.
  </Step>
  <Step title="Ask Muse to create a custom connector">
    In a Muse chat, ask Muse to create a custom connector for PostQueen. Muse guides you through it and may look up PostQueen's API information.
  </Step>
  <Step title="Keep the key in the Secure Credentials Store">
    Muse keeps your API key in its **Secure Credentials Store**, away from the model. Give Muse the key only when it asks to store it there, never in a chat message.
  </Step>
  <Step title="Choose what Muse may do">
    Muse asks before a connector acts. Choose **Allow once**, **Allow for this task** or **Always allow**, and change it later under **Settings > Permissions**.
  </Step>
</Steps>

<Warning>
Meta does not review custom connectors or how they use your information. A PostQueen API key gives full access to the workspace, so grant access with care.
</Warning>

## Good to know

- **Settings > Connectors lists only connectors Meta has reviewed.** Pasting PostQueen's address there does not work the way it does in Claude. Ask Muse in chat instead.
- **Only a workspace admin can connect PostQueen.** The API key is shown to admins only, and it gives full access to the workspace.

## Try this first

The first message to send is the one that starts the custom connector:

```text wrap
Create a custom connector for PostQueen, so you can write my social media posts for PostQueen to schedule. Ask me for my API key to keep in your Secure Credentials Store, not in this chat.
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| PostQueen is not under **Settings > Connectors** | It is not in Meta's reviewed directory yet. Ask Muse in chat to create a custom connector instead. |
| Muse asks for the key in the chat | Do not paste it there; ask Muse to store it in its Secure Credentials Store. If the key was sent in a chat, a workspace admin rotates it under **Connections > API key**. |
| You wanted Meta's terminal agent | That is Muse Code. Follow [the Muse Code page](/agents/muse-code). |
| Muse is not available to you | Muse is available in the US and Canada, and not in every location yet. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).

## Is it the same as Muse Code?

No. Meta ships two agents with the Muse name, and they connect to PostQueen in different ways:

| Product | What it is | How it connects |
|---|---|---|
| **Muse** (this page) | Meta's personal agent in the Muse app, on muse.ai and in WhatsApp | A custom connector it builds with you in chat |
| [Muse Code](/agents/muse-code) | Meta's coding agent for the terminal and CI, built on Muse Spark | PostQueen's MCP address in its settings file |
