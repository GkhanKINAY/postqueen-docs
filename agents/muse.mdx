Meta ships two different agents with the Muse name, and they connect to PostQueen in different ways.

- **Muse Code** is Meta's coding agent for the terminal and CI. It reads PostQueen's MCP address from its settings file. [Set it up](#muse-code).
- **Muse** is Meta's personal agent in the Muse app, on muse.ai and in WhatsApp. Meta does not document a place to paste an MCP address in it. [How it connects](#muse-the-personal-agent).

## Muse Code

<Note>
From Meta's docs, not tested by PostQueen yet.
</Note>

Your key lives in the app at [app.postqueen.ai](https://app.postqueen.ai): open **Connections > API Keys** and click **Reveal**. Only a workspace admin can reveal the key. Then add PostQueen to `~/.config/muse/settings.json`:

```json
{
  "schema_version": 1,
  "mcp_servers": {
    "postqueen": {
      "transport": "streamable_http",
      "url": "https://api.postqueen.ai/mcp/YOUR_API_KEY",
      "mode": "optional"
    }
  }
}
```

Restart Muse Code after saving, then type `/mcp` to see PostQueen's [21 MCP tools](/mcp/tools). Ask it to list your connected social media accounts.

## Muse, the personal agent

<Note>
Not tested by PostQueen yet.
</Note>

PostQueen is not in Muse's connector list, and Meta does not document pasting an MCP address into Muse. Meta's route for a service that is not listed is a custom connector that Muse builds with you in the chat:

<Steps>
  <Step title="Get your key">
    In PostQueen, open **Connections > API Keys** and copy the key. Only a workspace admin can reveal it.
  </Step>
  <Step title="Ask Muse to create a custom connector">
    In a Muse chat, ask Muse to create a custom connector for PostQueen. Muse guides you through it.
  </Step>
  <Step title="Enter the key only in the secure prompt">
    When Muse asks for your API key, enter it only in the secure prompt Muse shows, never in the chat.
  </Step>
  <Step title="Choose what Muse may do">
    Muse asks your permission before a connector acts. You can change that later under **Settings > Permissions** in Muse.
  </Step>
</Steps>

<Warning>
The API key gives full access to your PostQueen workspace, and Meta does not review custom connectors. Grant access with care. Muse is rolling out in the US and is not available everywhere yet.
</Warning>
