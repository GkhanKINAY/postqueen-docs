Muse is Meta's personal agent in the Muse app, on muse.ai and in WhatsApp. It launched in the US on September 8, 2026, and works on its own cloud computer at Meta, the Muse Secure VM. This page shows what Meta documents for adding a service to Muse, and what PostQueen has and has not checked.

## Before you start

- **Plans:** Muse is free with a usage limit. Power costs \$20 a month and Maximum \$100 a month. Meta does not tie connectors to a plan.
- **Platforms:** the Muse app on iOS and Android, muse.ai on the web, WhatsApp and Mac. Muse is rolling out in the US and is not available in every location yet.
- **A PostQueen API key**, if you try the custom connector below. A workspace admin copies it from **Connections**.

## Can I connect PostQueen to Muse today?

Not by address. Meta documents two ways for Muse to reach a service, and neither takes an MCP address from you today:

| Route | What Meta documents | Where PostQueen stands |
|---|---|---|
| **A listed connector** | Connectors Meta has reviewed, added under **Settings > Connectors** | PostQueen is not listed yet |
| **A custom connector** | You ask Muse in chat to build one, from the service's API information | Not tested with PostQueen yet |

## Try a custom connector (not tested yet)

These are the steps Meta documents for a service that is not in the Connector list. Nobody has built a PostQueen connector this way yet, so PostQueen cannot promise it works.

<Steps>
  <Step title="Copy your PostQueen API key">
    In PostQueen, open **Connections > API Keys** and copy the key. Only a workspace admin can reveal it.
  </Step>
  <Step title="Ask Muse to create a custom connector">
    In a Muse chat, ask Muse to create a custom connector for PostQueen. Muse guides you through it and may look up PostQueen's API information.
  </Step>
  <Step title="Enter the key only in the secure prompt">
    When Muse asks for your API key, enter it only in the secure prompt Muse shows, never in the chat. Muse keeps it in its Secure Credentials Store, away from the model.
  </Step>
  <Step title="Choose what Muse may do">
    Muse asks before a connector acts. Choose **Allow once**, **Allow for this task** or **Always allow**, and change it later under **Settings > Permissions**.
  </Step>
</Steps>

<Warning>
Meta does not review custom connectors or how they use your information. A PostQueen API key gives full access to the workspace, so grant access with care.
</Warning>

## Good to know

- **Meta does not say that Muse accepts an MCP address.** Pasting PostQueen's address into **Settings > Connectors** does not work the way it does in Claude: that screen lists only connectors Meta has reviewed.
- **Only a workspace admin can connect PostQueen.** The API key is shown to admins only, and it gives full access to the workspace.
- **If you get it working,** tell [support@postqueen.ai](mailto:support@postqueen.ai) what Muse asked for. It helps PostQueen test this route and update this page.

## Try this first

The first message to send is the one that starts the custom connector:

```text wrap
Create a custom connector for PostQueen, so you can schedule my social media posts. Ask me for my API key in a secure prompt, not in this chat.
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| PostQueen is not under **Settings > Connectors** | It is not in Meta's reviewed directory yet. Ask Muse in chat to create a custom connector instead. |
| Muse asks for the key in the chat | Do not paste it there; ask for the secure prompt. If the key was sent in a chat, a workspace admin rotates it under **Connections > API Keys**. |
| You wanted Meta's terminal agent | That is Muse Code. Follow [the Muse Code page](/agents/muse-code). |
| Muse is not available to you | Muse is rolling out in the US and is not in every location yet. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).

## Is it the same as Muse Code?

No. Meta ships two agents with the Muse name, and they connect to PostQueen in different ways:

| Product | What it is | How it connects |
|---|---|---|
| **Muse** (this page) | Meta's personal agent in the Muse app, on muse.ai and in WhatsApp | Not by address yet |
| [Muse Code](/agents/muse-code) | Meta's coding agent for the terminal and CI, built on Muse Spark | PostQueen's MCP address in its settings file |
