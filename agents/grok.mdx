Grok is xAI's AI assistant at grok.com and in its mobile apps. Add PostQueen as a custom connector and Grok can list your channels, write and schedule posts, and tell you how your published posts did.

## Before you start

- **Plans:** connectors are available to all Grok users. On Grok Business and Enterprise, an admin adds the connector first.
- **Platforms:** you add the connector on the web, at grok.com. xAI says connectors also work in the Grok iOS and Android apps, but documents adding a custom one only on the web.
- **A PostQueen API key.** A workspace admin copies it, or the ready-made address, from **Connections**.

## Connect Grok

<Steps>
  <Step title="Copy your MCP address">
    In PostQueen, open **Connections** and copy the address from the Grok card, or build it from your key:

    ```text wrap
    https://api.postqueen.ai/mcp/YOUR_API_KEY
    ```
  </Step>
  <Step title="Add a custom connector">
    Go to [grok.com/connectors](https://grok.com/connectors), choose **New Connector**, then **Custom**.
  </Step>
  <Step title="Paste the address and save">
    Paste the address as the MCP server URL and save. The key is part of the address, so there is no extra sign-in.
  </Step>
</Steps>

<Note>
**On Grok Business and Enterprise,** an admin first adds PostQueen at [console.x.ai](https://console.x.ai): choose the team, then **Grok Business > Connectors > + Add Connector > Other**, and enter the address. Members then connect it at grok.com/connectors.
</Note>

## Check that it works

In a new Grok chat, ask: "List my PostQueen channels." Grok answers with the channels you connected in PostQueen. If it does not use PostQueen, open grok.com/connectors and check that the PostQueen connector is there and connected.

## Good to know

- **The address carries your API key.** Keep it private, like a password. If it leaks, a workspace admin rotates the key under **Connections > API Keys**, and you update the connector with the new address.
- **Grok on grok.com is separate from Grok Bot and Grok Build.** Each one is set up on its own; see the last section.
- **Ask for drafts when you want to check first.** A draft waits on your PostQueen calendar, and nothing publishes until you schedule it.
- **What it cannot do over MCP:** delete a post, or change a post's text or time. Do that on the calendar in the app. [The MCP tools](/mcp/tools) lists what it can do.

## Try this first

```text wrap
List my PostQueen channels. Then write a short Bluesky post about our weekend opening hours and save it as a draft for Saturday at 10am.
```

The draft appears on your PostQueen calendar, ready for you to check and schedule. [Prompts to try](/mcp/examples) has more.

## Troubleshooting

| Symptom | Fix |
|---|---|
| Grok does not use PostQueen | Check at grok.com/connectors that the PostQueen connector is there, then start a new chat. |
| The key is refused | Copy the address again from the Grok card on **Connections**, or the key from **Connections > API Keys**. Only a workspace Admin or Super Admin can reveal it. |
| The address with your key leaked | A workspace admin rotates the key under **Connections > API Keys**. Then update the connector. |
| On Business or Enterprise, you cannot add it | An admin adds it first at console.x.ai under **Grok Business > Connectors**. |
| You set it up in Grok, but Grok Bot or Grok Build does not see it | Each product is set up on its own. Open its page below. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).

## Is it the same as Grok Bot or Grok Build?

No. xAI has three products with Grok in the name, and each one connects to PostQueen on its own:

| Product | What it is | How it connects |
|---|---|---|
| **Grok** (this page) | xAI's assistant at grok.com and in its mobile apps | A custom connector at grok.com/connectors |
| [Grok Bot](/agents/grok-bot) | An always-on AI teammate with its own cloud computer | Ask in chat, key in the secure prompt |
| [Grok Build](/agents/grok-build) | xAI's coding agent for the terminal | One `grok mcp add` command |
