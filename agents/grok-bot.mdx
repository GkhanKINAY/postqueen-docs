Grok Bot is xAI's always-on AI teammate. Each Bot works on its own cloud computer, and you sign in with a Cursor account. Connect PostQueen once and the Bot can list your channels, write and schedule posts, and report how your published posts did, from the desktop app or your phone.

## Before you start

- **Plans:** included with Cursor Pro, Pro+, Ultra and Teams. An individual SuperGrok, SuperGrok Plus, SuperGrok Heavy or X Premium+ subscription can be linked instead. Not Hobby or SuperGrok Lite. On Enterprise, an admin turns Grok Bot on in the Cursor dashboard.
- **Platforms:** the desktop app on macOS, Windows and Linux, and the mobile app on iPhone, iPad and Android.
- **A PostQueen API key.** A workspace admin copies it from **Connections**.

## Connect Grok Bot

You add PostQueen from inside a Grok Bot chat. There is no settings form to fill in.

<Steps>
  <Step title="Ask the Bot to connect PostQueen">
    In a Grok Bot chat, send this message. The address has no key in it.

    ```text wrap
    Connect PostQueen as an MCP server at https://api.postqueen.ai/mcp
    ```

    PostQueen is not in the Bot's catalog, so the Bot offers to add it as a custom MCP server and shows a card with **Connect** and **Not now**.
  </Step>
  <Step title="Enter the key in the secure prompt">
    Choose **Connect**, then paste your PostQueen API key into the secure prompt the Bot opens. Never paste it into the chat itself: the secure prompt keeps the key out of the chat history.
  </Step>
  <Step title="Check the tools">
    Ask the Bot to list your connected PostQueen channels. The next section shows what a working connection looks like.
  </Step>
</Steps>

## Check that it works

Ask Grok Bot: "List my PostQueen channels." It answers with the channels you connected in PostQueen, by name and network. If it says it has no PostQueen tools, open **Plugins > Yours** and make sure the PostQueen server is on.

## Good to know

- **The key stays out of the chat.** If a key ever lands in a chat message, a workspace admin rotates it under **Connections > API Keys**, and you connect again with the new key.
- **Servers you add from chat live under Plugins > Yours.** Turn PostQueen off or on there.
- **The address must be public HTTPS.** Grok Bot runs in the cloud, so it cannot reach a server on your own computer. `api.postqueen.ai` is public.
- **On Enterprise,** PostQueen's address must be on your team's MCP allowlist. A connector the team blocks shows as **Disabled by team admin**.
- **Adding a server by chat** is described by Cursor staff on Cursor's forum, not in xAI's docs. It works with PostQueen.
- **Ask for drafts when you want to check first.** A draft waits on your PostQueen calendar, and nothing publishes until you schedule it.
- **What it cannot do over MCP:** delete a post, or change a post's text or time. Do that on the calendar in the app. [The MCP tools](/mcp/tools) lists what it can do.

## Other ways to connect

Use the route above. The other PostQueen addresses do not suit Grok Bot:

| Way | Address | Notes |
|---|---|---|
| The address, with the key in the secure prompt | `{{mcpBearerUrl}}` | The route above |
| The key in the address | `{{mcpKeyUrl}}` | Do not use: you would have to paste the key into the chat |
| Sign in with PostQueen | Not offered | Cursor staff acknowledged an open problem with MCP sign-in redirects in Grok Bot on 2026-09-14 |

## Try this first

```text wrap
List my PostQueen channels, then write a short Bluesky post about our new opening hours and save it as a draft for tomorrow at 9am.
```

The draft appears on your PostQueen calendar, ready for you to check and schedule. [Prompts to try](/mcp/examples) has more.

## Run it on a schedule

Grok Bot runs routines: a routine tells a Bot when to run a workflow. Create one by asking in chat, or open the Bot, choose **View conversation details**, then **Routines**. Background routines run while your laptop is closed and can use the Bot's connected tools, PostQueen included. A Bot can own up to 50 routines.

```text wrap
Every Friday at 4pm, write our week in review as a Bluesky post and save it as a PostQueen draft.
```

<Tip>
xAI recommends approval for anything that publishes. Saving drafts keeps you in the loop: the routine writes, and you schedule. Source: [xAI, skills, routines and automations](https://docs.x.ai/grok-bot/skills-routines-and-automations).
</Tip>

## Troubleshooting

| Symptom | Fix |
|---|---|
| The Bot says it has no PostQueen tools | Open **Plugins > Yours** and make sure the PostQueen server is on. |
| You pasted the key into the chat | Ask a workspace admin to rotate it under **Connections > API Keys**, then connect again and use the secure prompt on the **Connect** card. |
| The key is refused | Copy it again from **Connections > API Keys**. Only a workspace Admin or Super Admin can reveal it. |
| On Enterprise, the connection is blocked | Ask your admin to add PostQueen's address to the team's MCP allowlist. |
| A sign-in page fails | Use `{{mcpBearerUrl}}` with the key in the secure prompt. |
| You added PostQueen at grok.com, but the Bot does not see it | Grok Bot is set up in the Bot itself. Follow the steps on this page. |

More fixes are on [Troubleshooting agents](/agents/troubleshooting).

## Is it the same as Grok or Grok Build?

No. xAI has three products with Grok in the name, and each one connects to PostQueen on its own:

| Product | What it is | How it connects |
|---|---|---|
| **Grok Bot** (this page) | An always-on AI teammate with its own cloud computer | Ask in chat, key in the secure prompt |
| [Grok](/agents/grok) | xAI's assistant at grok.com and in its mobile apps | A custom connector at grok.com/connectors |
| [Grok Build](/agents/grok-build) | xAI's coding agent for the terminal | One `grok mcp add` command |

A connector you add at grok.com, or a server in Grok Build's config, does not reach Grok Bot. Grok Bot runs on Cursor's cloud, but Cursor's own `mcp.json` does not reach it either.
