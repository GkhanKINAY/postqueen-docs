You can ask for a post from the chat app you already have open: WhatsApp or Telegram on your phone, Slack or Discord with your team. PostQueen does not join those apps itself. An agent you run on your own computer or server sits in between: it reads your message, uses PostQueen, and answers in the same chat.

## How it works

```text wrap
your chat app  ->  OpenClaw, Hermes Agent or NanoClaw  ->  PostQueen  ->  your calendar
```

- **The agent has to be running.** Each of these agents runs a background process that stays connected to your chat apps. If the machine sleeps, nobody is listening.
- **Chat credentials never reach PostQueen.** Bot tokens, QR pairings and Slack app tokens stay in the agent's own config on your machine. PostQueen sees only the API key the agent uses.
- **Every post lands on your PostQueen calendar,** like a post you made in the app. You can check, edit or delete it there before it goes out.

<Note>
This page is about talking **to** an agent from a chat app. Posting **into** Telegram, Slack or Discord as a PostQueen channel is a separate thing, and those networks are **Soon**: see [Telegram](/channels/telegram), [Slack](/channels/slack) and [Discord](/channels/discord).
</Note>

## Pick an agent

| Agent | Chat apps it connects to | How it reaches PostQueen |
|---|---|---|
| [OpenClaw](/agents/openclaw) | WhatsApp, Telegram, Slack, Discord and more | The PostQueen CLI and skill |
| [Hermes Agent](/agents/hermes) | Telegram, Discord, Slack, WhatsApp, Signal, email and more | PostQueen's MCP server |
| [NanoClaw](/agents/nanoclaw) | Slack, Telegram, Discord, WhatsApp, iMessage and more | PostQueen's MCP server, with the key in its vault |

All three are free and open source; the outside cost is the model provider you run them with.

## Before your first message

<Steps>
  <Step title="Connect PostQueen to the agent">
    Follow the agent's page: [OpenClaw](/agents/openclaw), [Hermes Agent](/agents/hermes) or [NanoClaw](/agents/nanoclaw). You need a PostQueen API key, which a workspace admin copies from **Connections > API Keys**.
  </Step>
  <Step title="Check it before you add a chat app">
    Ask the agent, in its own chat: "List my PostQueen channels." When it answers with your channels, the PostQueen half is ready.
  </Step>
  <Step title="Link the chat app">
    Pick the app below. Each one is set up in the agent, with an account or bot you create.
  </Step>
</Steps>

## WhatsApp

**On your side:** a WhatsApp account and a phone that can scan a QR code. OpenClaw recommends a separate WhatsApp number, though a personal number works too.

With OpenClaw, log in by QR code, start the gateway and approve the first person who messages it:

```bash
openclaw channels add --channel whatsapp
openclaw channels login --channel whatsapp
openclaw gateway
openclaw pairing list whatsapp
openclaw pairing approve whatsapp <CODE>
```

Full steps: [OpenClaw, WhatsApp](https://docs.openclaw.ai/channels/whatsapp). With Hermes Agent, `hermes gateway setup` walks you through it.

## Telegram

**On your side:** a Telegram bot. Message `@BotFather` in Telegram, run `/newbot` and save the token it gives you.

With OpenClaw, add the token, start the gateway and approve your first message:

```bash
openclaw channels add --channel telegram --token <BOT_TOKEN>
openclaw gateway
openclaw pairing approve telegram <CODE>
```

Full steps: [OpenClaw, Telegram](https://docs.openclaw.ai/channels/telegram). With Hermes Agent, `hermes gateway setup` walks you through it.

## Slack

**On your side:** a Slack app in your workspace. With Socket Mode, OpenClaw's default, you need two tokens from the same app: a bot token and an app-level token with the `connections:write` scope.

This is the one for a team: anyone the bot accepts messages from can ask for a post, and everything they schedule lands on the same PostQueen calendar.

Full steps: [OpenClaw, Slack](https://docs.openclaw.ai/channels/slack). With Hermes Agent, `hermes gateway setup` walks you through it.

## Discord

**On your side:** a Discord application with a bot, made in the Discord Developer Portal.

1. Create the application and its bot, and copy the bot token. Keep it out of any chat.
2. Turn on **Message Content Intent** in the bot settings, so the bot can read messages.
3. Invite the bot to your server, give the token to OpenClaw, and approve your first DM when it asks for pairing.

Full steps: [OpenClaw, Discord](https://docs.openclaw.ai/channels/discord). With Hermes Agent, `hermes gateway setup` walks you through it.

## NanoClaw and the other apps

NanoClaw pairs chat apps during its setup, and supports Slack, Telegram, Discord, WhatsApp, iMessage and more: see [NanoClaw's docs](https://docs.nanoclaw.dev/installation). Hermes Agent connects to more than 30 messaging services from one gateway, listed in [its messaging guide](https://hermes-agent.nousresearch.com/docs/user-guide/messaging).

## After you send a message

The agent writes the post, uses PostQueen to schedule it with a real time, and answers in the chat. What is scheduled goes out when the time comes, without another message from you.

Want to check first? Ask for a draft. A draft waits on your PostQueen calendar, and nothing publishes until you schedule it.

## FAQ

<AccordionGroup>
  <Accordion title="Does PostQueen read my WhatsApp messages?">
    No. PostQueen has no connection to your chat apps. The agent runs on your own machine, connects to the chat app with an account or bot you created, and uses PostQueen with your API key. PostQueen sees only those requests.
  </Accordion>
  <Accordion title="Does my computer have to stay on?">
    The agent's background process has to stay running, so the machine it runs on has to stay awake. A small always-on computer or a server is the usual answer if you want it reachable around the clock.
  </Accordion>
  <Accordion title="Can my whole team ask for posts in Slack or Discord?">
    Yes. Anyone the bot accepts messages from in your workspace or server can ask for a post, and everything lands on the same PostQueen calendar. The agent's pairing and allowlist settings decide who that is.
  </Accordion>
  <Accordion title="Which agent should I pick?">
    They all reach the four apps on this page. OpenClaw uses the PostQueen CLI, which can also delete posts. Hermes Agent uses PostQueen's MCP server and keeps a persistent memory. NanoClaw runs each agent in its own container and keeps your key in a vault, away from the agent.
