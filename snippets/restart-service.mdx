Restart PostQueen so the new variables are read. A plain `docker restart` or `docker compose restart`
reuses the old container and its old environment.

Recreate only the app service (the name in your compose file is usually `postqueen` or `backend`):

```bash
docker compose up -d --no-deps --force-recreate SERVICE
```

`docker compose down` then `up -d` also works on a machine that runs nothing else. On a shared host it
stops every Compose service in the project. Do not use it there.
