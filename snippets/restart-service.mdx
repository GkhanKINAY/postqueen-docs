Recreate the app container so it reads the new values. A plain `docker restart` or
`docker compose restart` keeps the old container and its old environment.

In the folder that holds `docker-compose.yaml`, recreate only the `postqueen` service:

```bash
docker compose up -d --no-deps --force-recreate postqueen
```

The database, Redis and Temporal keep running. Avoid `docker compose down` for a settings change: on
a host that runs other Compose services in the same project, it stops them too. On Kubernetes, see
[Kubernetes with Helm](/installation/kubernetes-helm#apply-a-change).
