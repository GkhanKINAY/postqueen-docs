Put her public address in a `.env` file next to `docker-compose.yaml`. The shipped Compose file
loads that file (`env_file`) and interpolates `${VAR:-default}` in `environment:`, so the
values reach the container without editing the YAML:

```env
MAIN_URL=https://postqueen.example.com
FRONTEND_URL=https://postqueen.example.com
NEXT_PUBLIC_BACKEND_URL=https://postqueen.example.com/api
```

Keep `/api` on the last one, and leave no trailing slashes. Leave `BACKEND_INTERNAL_URL` alone:
it stays `http://localhost:3000` inside the container.
