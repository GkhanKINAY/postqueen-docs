Put the public address in the `.env` file next to `docker-compose.yaml`. The shipped Compose file
reads that file and fills these three values into the `postqueen` service, so there is no YAML to
edit:

```env
MAIN_URL=https://postqueen.example.com
FRONTEND_URL=https://postqueen.example.com
NEXT_PUBLIC_BACKEND_URL=https://postqueen.example.com/api
```

Keep `/api` on the last one, and leave off trailing slashes. Leave `BACKEND_INTERNAL_URL` as it
ships, `http://localhost:3000`: it is the path from the web app to the API inside the container,
not a public address.
