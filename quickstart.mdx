Your first post can go out today. You pick where she lives, hand her a key and tell her what to say. The cloud and your own server run the same code, so the choice is about who keeps the machine running, not about what she can do.

## Talk to her instead

Now that a channel is connected, you can stop opening the app for this. PostQueen answers any
agent that can run a skill or call an MCP tool.

<img src="/images/brand/chat-agent.svg" alt="Just talk to her: one voice note and PostQueen generates the visual and schedules the posts" />

You need an API key first: in the app, open **Settings > Developers > Public API** and click
**Reveal**. Then install the skill and hand your agent the key:

```bash
npx skills add GkhanKINAY/postqueen-agent
export POSTQUEEN_API_KEY="your-api-key"
```

Or connect Claude Code straight to her over MCP:

```bash
claude mcp add --transport http postqueen https://api.postqueen.ai/mcp/YOUR_API_KEY
```

Check it worked by asking your agent to list your connected channels. The channel you added
above comes back.

That URL contains your API key, so treat it like a password. Prefer the key out of the URL? There
is a header form: [MCP setup](/mcp/setup). OpenClaw, Hermes and self-hosted endpoints:
[agents overview](/agents/overview).

## If something is not right

<AccordionGroup>
  <Accordion title="The network I want is not in Add Channel">
    On a self-hosted install, a network only appears once its OAuth app keys are in your
    environment and she has been restarted. [Providers](/providers/overview) has the setup for
    each one. On the cloud, everything she supports is already there.
  </Accordion>

  <Accordion title="The post went to Drafts instead of being scheduled">
    A draft is a post state rather than a queue position: it sits on the calendar at the date you
    gave it and is never handed to the scheduler. Open it and publish it, or switch it with
    `postqueen posts:status <id> --status schedule`.
  </Accordion>

  <Accordion title="Reveal shows nothing under Developers">
    The Developers tab needs you to be an organization admin, and on the cloud a plan that
    includes the public API. Self-hosted installs with billing off have it on by default.
  </Accordion>

  <Accordion title="My agent connected but cannot see any channels">
    Almost always the key. Check it was pasted in full, and if you are self-hosting, that
    `POSTQUEEN_API_URL` points at your backend including the `/api` suffix most single-domain
    installs use. [CLI authentication](/cli/authentication) has the exact shape.
  </Accordion>
</AccordionGroup>
