## Talk to her

PostQueen answers any agent that can run a skill or call an MCP tool. First you need an API key, which takes a minute. Your workspace lives at [app.postqueen.ai](https://app.postqueen.ai). Open **Settings > Developers > Public API** and click **Reveal**.

<img src="/images/brand/chat-agent.svg" alt="Just talk to her: one voice note and PostQueen generates the visual and schedules the posts" />

Install the skill and hand your agent the key:

```bash
npx skills add GkhanKINAY/postqueen-agent
export POSTQUEEN_API_KEY="your-api-key"
```

Or connect Claude Code straight to her MCP server:

```bash
claude mcp add --transport http postqueen https://api.postqueen.ai/mcp/YOUR_API_KEY
```

That URL contains your API key, so treat it like a password. Prefer the key out of the URL? There is a header form: [MCP setup](/mcp/setup).

That is the whole setup. OpenClaw, Hermes and self-host endpoints: [agents overview](/agents/overview).

  <Step title="Ask her for a post">
    From any connected agent, ask in plain language: "Write a launch post for tomorrow at 9am." Or write it yourself in the editor. Either way, the post lands on the schedule.

  <Step title="Review it on the calendar">
    Open the calendar to see what is planned. Edit or delete anything before it goes out. Prefer to stage a post first? Ask her for drafts: a draft is saved to the calendar at the date you gave it, and it is simply never handed to the scheduler, so it sits there until you publish it.

  <Step title="It goes out on time">
    No extra confirmation, no reminder to click. She posts it at the time you set, whether your laptop is open or not.

    That is the autopilot half. She runs on your terms: everything is visible on the calendar before it publishes, so you can edit or delete it, and a draft stays unscheduled until you publish it.
