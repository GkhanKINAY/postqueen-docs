Five routes put PostQueen inside the tool you already run. All five speak to the same [Public API](/public-api/introduction). One key from **Connections > API Keys** (only a workspace admin can reveal it), sent as `Authorization: YOUR_API_KEY` with no `Bearer` prefix.

n8n, Zapier and Make call her. Webhooks go the other way. RSS AutoPost moves on her own.

<Warning>
The create-post endpoint allows **30 requests per hour** on Cloud and the shipped Compose files. A chatty trigger reaches that faster than you would expect.
</Warning>
