PostQueen's design editor is built on the [Polotno SDK](https://polotno.com/). It lets people design an image from templates, text and shapes, or edit an attached image, without leaving the post. It works on images only; video is not edited. The editor needs a Polotno API key, which you buy from Polotno.

## Turn it on

<Steps>
  <Step title="Get a Polotno API key">
    Create an account at [polotno.com](https://polotno.com/) and create a key in its [dashboard](https://polotno.com/cabinet/). Polotno sets its own terms, and a production key is paid.
  </Step>
  <Step title="Set the variable">
    ```env
    NEXT_PUBLIC_POLOTNO=your-polotno-api-key
    ```

    The web app reads it on every page load, so no rebuild is needed.
  </Step>
  <Step title="Recreate the container">
    <RestartService />

    <Check>
    In the post composer, **Design Media** opens the editor.
    </Check>
  </Step>
</Steps>

## Where it appears

- **Design Media**, beside **Insert Media** under a post, starts a new design and attaches the result.
- Selecting an image already attached to a post opens it in the editor. Videos cannot be edited.

Without the key, **Design Media** still shows on a self-hosted install. Choosing it explains the setup instead of opening the editor: an admin sees *Design Media is not set up on this installation. Add NEXT_PUBLIC_POLOTNO to the server environment and restart PostQueen.* with a link to this page, and other members are asked to contact an admin.
