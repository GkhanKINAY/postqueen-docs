When a post contains a link, PostQueen can replace it with a short link from a link shortener, which counts the clicks. The option exists only when a shortener is configured. Without one, links go out as written, PostQueen never asks, and the app hides the **Shortlink Settings** card and each post's **Short Links Statistics** table.

Four services are supported. You choose one by setting its key.

<Warning>
**Set only one.** PostQueen picks the first configured service in this order, reads it once at start, and ignores the rest without a warning: `DUB_TOKEN`, then `SHORT_IO_SECRET_KEY`, then `KUTT_API_KEY`, then `LINK_DRIP_API_KEY`.
</Warning>

## Set it up

<Steps>
  <Step title="Set the service's variables">
    <Tabs>
      <Tab title="Dub">
        ```env
        DUB_TOKEN=your-api-key
        DUB_API_ENDPOINT=https://api.dub.co
        DUB_SHORT_LINK_DOMAIN=dub.sh
        ```

        Only the token is required; the other two show their defaults. Set `DUB_SHORT_LINK_DOMAIN` to a domain you added in Dub to get links on your own name.
      </Tab>
      <Tab title="Short.io">
        ```env
        SHORT_IO_SECRET_KEY=your-secret-key
        ```

        One variable, with no endpoint or domain to set.
      </Tab>
      <Tab title="Kutt">
        ```env
        KUTT_API_KEY=your-api-key
        KUTT_API_ENDPOINT=https://kutt.it/api/v2
        KUTT_SHORT_LINK_DOMAIN=kutt.it
        ```

        Point the endpoint and the domain at your own Kutt server to keep the links on it.
      </Tab>
      <Tab title="LinkDrip">
        ```env
        LINK_DRIP_API_KEY=your-api-key
        LINK_DRIP_API_ENDPOINT=https://api.linkdrip.com/v1/
        LINK_DRIP_SHORT_LINK_DOMAIN=dripl.ink
        ```

        Set the domain to one you configured in LinkDrip to get links on your own name.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Recreate the container">
    <RestartService />
  </Step>
  <Step title="Try it">
    Write a post with a link and schedule it. PostQueen asks "Do you want to shortlink the URLs? it will let you get statistics over clicks". Choose **Yes, shortlink it!** and the published post carries the short domain.
  </Step>
</Steps>

A workspace admin chooses how links are handled in **Settings > Global Settings > Shortlink Settings**: **Ask every time**, **Always shortlink** or **Never shortlink**. With `STRIP_LINKS_FROM_X_POSTS` set, X posts lose their links anyway, so their text is not checked for links to shorten.

If PostQueen never asks, the key is not reaching the backend: check the variable name, and that the container was recreated rather than restarted.
