## Set environment variables

She reads everything she needs from environment variables, and there are a lot of them, so a `.env` file beats a long `docker run` line you have to maintain.

Her containers look for that file in `/config`. Docker creates it for you on a docker volume the first time you start her up.

The default .env file can be found here; [example .env file](https://raw.githubusercontent.com/GkhanKINAY/postqueen-app/main/.env.example)

## Create the container

One command creates the container. Replace `./config` with the path to your config directory, and have Postgres and Redis running first.

```bash
docker create --name postqueen -v postqueen-uploads:/uploads/ -v postqueen-config:/config/ -p 5000:5000 ghcr.io/gkhankinay/postqueen-app:latest
```
