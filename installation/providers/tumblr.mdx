On a self-hosted PostQueen the Tumblr app is yours. You register it on Tumblr, add PostQueen's address as its OAuth2 redirect URL, and give PostQueen the app's consumer key and secret. Tumblr does not review apps.

## Before you start

| | |
|---|---|
| Developer portal | [Tumblr applications](https://www.tumblr.com/oauth/apps), signed in to a Tumblr account |
| Variables | `TUMBLR_CLIENT_ID`, `TUMBLR_CLIENT_SECRET` |
| Redirect URI | `FRONTEND_URL` + `/integrations/social/tumblr` |
| Scopes | `write`, `offline_access` |
| Review | None |

Tumblr has no scope settings on the app. PostQueen asks for the two scopes when a channel connects, and refuses the connect if Tumblr grants fewer. `offline_access` is what gives PostQueen a refresh token, so the channel keeps working after the first token expires.

## Create the app

<Steps>
  <Step title="Register the application">
    Go to [tumblr.com/oauth/apps](https://www.tumblr.com/oauth/apps) and choose **Register application**. Fill in the name, website, description and contact email. The callback fields are the ones that matter.
  </Step>
  <Step title="Add the OAuth2 redirect URL">
    PostQueen signs in with OAuth 2, and Tumblr turns OAuth 2 on for an app only once it has a valid OAuth2 redirect URL. Enter the address that matches how you run PostQueen in the OAuth2 redirect URL field:

    <CodeGroup>

    ```text Your domain
    https://postqueen.example.com/integrations/social/tumblr
    ```

    ```text Local development
    http://localhost:4200/integrations/social/tumblr
    ```

    ```text Docker on your machine
    http://localhost:4007/integrations/social/tumblr
    ```

    </CodeGroup>

    The form also asks for a default callback URL, which is an OAuth 1 setting. The same address works there.

    <OAuthRedirect />
  </Step>
  <Step title="Copy the consumer key and secret">
    The app now shows its **OAuth consumer key** and its secret key. The consumer key is the OAuth 2 client ID, and the secret key is the client secret. Copy both, and keep the secret private.
  </Step>
</Steps>

## Set the variables

Add the two keys to your environment:

```env
TUMBLR_CLIENT_ID="your OAuth consumer key"
TUMBLR_CLIENT_SECRET="your secret key"
```

<RestartAndAddChannel />

Pick **Tumblr**, sign in and approve access. Tumblr then lists the blogs on your account, with the primary one marked. Pick the blog this channel posts to. One channel is one blog, so connect again to add another.

## Rate limits

- **Your app.** 1,000 requests an hour and 5,000 a day for each consumer key, shared by every Tumblr channel on your install.
- **Each Tumblr account.** 250 posts, 250 image uploads, 20 video uploads and 60 minutes of video a day. When one is reached, the post fails with a message that names it, such as “Tumblr daily posting limit reached.”

See [Tumblr's API docs](https://github.com/tumblr/docs/blob/master/api.md) for the current figures.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Not enough scopes, when choosing a provider, please add all the scopes">
    Tumblr returned a token without both scopes. Connect again and approve access on Tumblr's screen.
  </Accordion>
  <Accordion title="Tumblr says the redirect URI does not match, or OAuth 2 is not available">
    The OAuth2 redirect URL is missing from the app, or is not exactly your `FRONTEND_URL` followed by `/integrations/social/tumblr`. Edit the app and fix it.
  </Accordion>
  <Accordion title="Please re-authenticate your Tumblr account.">
    Tumblr refused the stored token and the refresh failed. Choose **Reconnect channel** in the channel's menu and approve access again.
  </Accordion>
</AccordionGroup>
