On a self-hosted PostQueen the Dribbble app is yours. You register it on Dribbble with PostQueen's callback URL and give PostQueen its client ID and secret. Dribbble does not review apps, but only accounts that are allowed to upload shots can post.

## Before you start

| | |
|---|---|
| Developer portal | [Dribbble applications](https://dribbble.com/account/applications/new), signed in to Dribbble |
| Variables | `DRIBBBLE_CLIENT_ID`, `DRIBBBLE_CLIENT_SECRET` |
| Redirect URI | `FRONTEND_URL` + `/integrations/social/dribbble` |
| Scopes | `public`, `upload` |
| You also need | A Dribbble account that can upload shots: a player or a team |
| Review | None |

PostQueen asks for both scopes when a channel connects, and refuses the connect if Dribbble grants fewer. `upload` is the one that lets it create shots.

## Create the app

<Steps>
  <Step title="Register the application">
    Open [Register a new application](https://dribbble.com/account/applications/new) on Dribbble. Enter a name, a description and your website. Dribbble's terms do not allow the word "dribbble" in the name.
  </Step>
  <Step title="Set the callback URL">
    Enter the address that matches how you run PostQueen as the **Callback URL**:

    <CodeGroup>

    ```text Your domain
    https://postqueen.example.com/integrations/social/dribbble
    ```

    ```text Local development
    http://localhost:4200/integrations/social/dribbble
    ```

    ```text Docker on your machine
    http://localhost:4007/integrations/social/dribbble
    ```

    </CodeGroup>

    Dribbble checks that the address PostQueen sends has the same host and port as the callback URL, and the same path.

    <OAuthRedirect />

    Then register the application.
  </Step>
  <Step title="Copy the client ID and secret">
    The application page shows the **Client ID** and the **Client Secret** at the bottom. Copy both, and keep the secret private.
  </Step>
</Steps>

## Set the variables

Add the two keys to your environment:

```env
DRIBBBLE_CLIENT_ID="your client id"
DRIBBBLE_CLIENT_SECRET="your client secret"
```

<RestartAndAddChannel />

Pick **Dribbble**, sign in, and approve access. A Dribbble connection does not expire: PostQueen gets no refresh token and needs none.

## Dribbble's limits

- **Who can post.** Dribbble's API creates shots only for players and teams.
- **The image.** Exactly 400 × 300 or 800 × 600 pixels, GIF, JPG or PNG, up to 8 MB. PostQueen checks the size in pixels before scheduling. Video is not supported.
- **Rate.** 60 requests a minute and 1,440 a day for each signed-in user.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Not enough scopes, when choosing a provider, please add all the scopes">
    Dribbble returned a token without both scopes. Connect again and approve access on Dribbble's screen.
  </Accordion>
  <Accordion title="Dribbble says the redirect URI is not valid">
    The address PostQueen sent does not match the app's **Callback URL**. It is exactly your `FRONTEND_URL` followed by `/integrations/social/dribbble`.
  </Accordion>
  <Accordion title="The shot is refused when it is published">
    The account is not allowed to upload shots, or the file breaks Dribbble's rules on format or size. Check the account type and the file.
  </Accordion>
</AccordionGroup>
