On a self-hosted PostQueen the Google Cloud project is yours. You create one **Web application** OAuth client, turn on two YouTube APIs, and give PostQueen the client ID and secret. The same client also runs **Continue with Google** on the sign-in page, and Google Business Profile can share it.

## Before you start

| | |
|---|---|
| Developer console | [Google Cloud console](https://console.cloud.google.com/), with a Google account |
| Variables | `YOUTUBE_CLIENT_ID`, `YOUTUBE_CLIENT_SECRET` |
| Redirect URI | `FRONTEND_URL` + `/integrations/social/youtube`, shared by the YouTube connect and **Continue with Google**. Add `FRONTEND_URL` + `/integrations/social/gmb` if Google Business Profile uses this client too |
| APIs | **YouTube Data API v3** and **YouTube Analytics API** |
| Scopes | `userinfo.profile`, `userinfo.email`, `youtube`, `youtube.force-ssl`, `youtube.readonly`, `youtube.upload`, `youtubepartner`, `yt-analytics.readonly` |
| Review | Google's verification of the sensitive scopes, and YouTube's API audit before uploads can be public |

PostQueen checks all eight scopes when a channel connects. A missing one stops the connect.

<Warning>
**This client is also Google sign-in.** When `IS_GENERAL` is set, **Continue with Google** on the sign-in page uses `YOUTUBE_CLIENT_ID` and `YOUTUBE_CLIENT_SECRET` and asks only for `userinfo.profile` and `userinfo.email`. Do not create a second client for sign-in: both come back to the same redirect URI.
</Warning>

## Create the client

<Steps>
  <Step title="Create or pick a project">
    In the [Google Cloud console](https://console.cloud.google.com/), create a project for PostQueen or select the one you use.
  </Step>
  <Step title="Turn on the YouTube APIs">
    Open **APIs and services > Enabled APIs and services** and choose **Enable APIs and services**. Search for and enable **YouTube Data API v3** (uploads, thumbnails, channel details) and **YouTube Analytics API** (the numbers on the Analytics page). PostQueen does not use the YouTube Reporting API.

    <Frame>
      <img src="/images/providers/youtube/Enable-APIs-and-Services.png" alt="The APIs and services page in Google Cloud console, with the Enable APIs and services button" />
    </Frame>
  </Step>
  <Step title="Set up Branding and Audience">
    Open [Google Auth Platform](https://console.cloud.google.com/auth/overview). In **Branding**, enter the app name, a support email, your home page, privacy policy and terms links, and your domain under **Authorized domains**. In **Audience**, choose **External**, unless everyone who will sign in belongs to your Google Workspace, where **Internal** skips verification.

    While the app is in **Testing**, only the accounts under **Test users** can sign in or connect a channel. Add your own Google account there with **Add users**.
  </Step>
  <Step title="Add the scopes">
    In **Data access**, choose **Add or remove scopes** and add all eight, then save:

    ```text
    https://www.googleapis.com/auth/userinfo.profile
    https://www.googleapis.com/auth/userinfo.email
    https://www.googleapis.com/auth/youtube
    https://www.googleapis.com/auth/youtube.force-ssl
    https://www.googleapis.com/auth/youtube.readonly
    https://www.googleapis.com/auth/youtube.upload
    https://www.googleapis.com/auth/youtubepartner
    https://www.googleapis.com/auth/yt-analytics.readonly
    ```
  </Step>
  <Step title="Create a Web application client">
    In **Clients**, choose **Create client** and pick **Web application** as the application type.

    <OAuthRedirect />

    Under **Authorized JavaScript origins**, add your `FRONTEND_URL` with no path. Under **Authorized redirect URIs**, add:

    <CodeGroup>

    ```text Your domain
    https://postqueen.example.com/integrations/social/youtube
    ```

    ```text Local development
    http://localhost:4200/integrations/social/youtube
    ```

    ```text Docker on your machine
    http://localhost:4007/integrations/social/youtube
    ```

    </CodeGroup>

    Google accepts only `https`, except for `localhost`. If this client also serves Google Business Profile, add the same addresses ending in `/integrations/social/gmb`: see [Google My Business setup](/installation/providers/google-my-business).
  </Step>
  <Step title="Copy the client ID and secret">
    Choose **Create** and copy the **Client ID** and **Client secret** from the dialog. Google shows the secret only now: afterwards the console keeps just its last four characters. If you lose it, add a new secret to the same client rather than creating another client.
  </Step>
</Steps>

## Set the variables

Add the two keys to your environment:

```env
YOUTUBE_CLIENT_ID="your client id"
YOUTUBE_CLIENT_SECRET="your client secret"
```

<RestartAndAddChannel />

Pick **YouTube**, sign in with Google, approve every permission, then choose the channel in **Select YouTube Channel**.

## App review

Two Google processes stand between a new client and everyone's public uploads:

<Steps>
  <Step title="Publish the app and verify the scopes">
    In **Audience**, choose **Publish app** to leave **Testing**. **Continue with Google** then works for any Google account, because it asks only for the basic profile scopes. The YouTube scopes are sensitive: until Google verifies them in the **Verification Center** (a justification for each scope and a demo video), people who connect a channel see Google's unverified-app screen, and at most 100 accounts can use them.
  </Step>
  <Step title="Pass the YouTube API audit">
    YouTube keeps every video uploaded through an unverified API project created after July 28, 2020 private, whatever visibility the post asks for. A project can also upload only 100 videos a day by default, shared by every channel on your install. Request the audit and more quota with the [YouTube API Services Audit and Quota Extension Form](https://support.google.com/youtube/contact/yt_api_form).
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="redirect_uri_mismatch on Google's screen">
    The redirect URI PostQueen sent is not in **Authorized redirect URIs**. Add it exactly as in step 5, with the scheme and port your `FRONTEND_URL` uses and no trailing slash.
  </Accordion>
  <Accordion title="Not enough scopes, when choosing a provider, please add all the scopes">
    A scope is missing from **Data access**, or was declined on the consent screen. Add all eight, then connect again and approve everything.
  </Accordion>
  <Accordion title="Access blocked or access denied on Google's screen">
    The app is in **Testing** and the account is not a test user. Add it under **Audience > Test users**, or publish the app.
  </Accordion>
  <Accordion title="The sign-in page keeps loading after Google's consent screen">
    The client secret in your environment is wrong: Google shows the consent screen with the client ID alone, then refuses the token exchange with `invalid_client`. Add a new secret to the client, put it in `YOUTUBE_CLIENT_SECRET` and restart PostQueen.
  </Accordion>
  <Accordion title="A Google Workspace account cannot connect">
    Your Workspace admin restricts third-party apps. In the Google Admin console, open **Security > Access and data control > API controls > Manage App Access**, choose **Configure new app**, find the app by its client ID and set it to **Trusted**. Google says the change can take up to 24 hours.
  </Accordion>
  <Accordion title="Every upload is private">
    Your project has not passed the YouTube API audit. Request it with the form in step 2 of App review.
  </Accordion>
</AccordionGroup>
