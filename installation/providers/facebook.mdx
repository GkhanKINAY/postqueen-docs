On your own instance the Meta app is yours: create it in Meta for Developers, then put its App ID and App Secret in your environment.

<Warning>
**NOTE:** Please be advised that Instagram (Facebook Business) and Facebook can use the same app (no need to create two separate apps). Request the **union** of both providers' permissions on that shared app. That shared app is **Path A** on the [Instagram setup](/installation/providers/instagram) page. Instagram Standalone is **Path B** there: a separate Meta app — do not add Facebook Login for Business on it. Threads is a third app.
</Warning>

<Steps>
  <Step title="Create a new app">
    Select a business portfolio, then create a [new app in Facebook developers](https://developers.facebook.com/apps/creation/).
    
    Please be advised that for public applications, you will need to verify your business.

    <Frame>
      <img src="/images/providers/facebook/Business-Portfolio.png" alt="Business Portfolio" />
    </Frame>

    <Frame>
      <img src="/images/providers/facebook/Create-an-app.png" alt="Create app" />
    </Frame>
  </Step>

  <Step title="Show all use cases">
    On the **Add use cases** screen, pick the **All** filter on the left.

    <Frame>
      <img src="/images/providers/facebook/All-use-cases.png" alt="Add use cases screen with the All filter selected" />
    </Frame>
  </Step>

  <Step title="Select app type">
    Do not pick any of the use cases. Scroll to the bottom and, under **Looking for something else?**, select **Other** and click next.

    <Warning>
    An app created through a use case such as Facebook Login cannot request the permissions PostQueen needs, and adding the use case later does not rescue it. The consent screen then fails straight away with **Invalid Scopes** for every scope. If that is what you see, create a new app through **Other**.
    </Warning>

    <Frame>
      <img src="/images/providers/facebook/Other-app-use-cases.png" alt="Other app use cases" />
    </Frame>
  </Step>

  <Step title="Select business">
    Then select business

    <Frame>
      <img src="/images/providers/facebook/facebook-select-business.png" alt="Business" />
    </Frame>
  </Step>

  <Step title="Add details and create app">
    Add all your details and click Create App

    <Frame>
      <img src="/images/providers/facebook/facebook-create-app-details.png" alt="Create app details" />
    </Frame>
  </Step>

  <Step title="Set up Login with Facebook">
    <Frame>
      <img src="/images/providers/facebook/facebook-setup-login.png" alt="Setup Login with Facebook" />
    </Frame>

    Set up login for business
  </Step>

  <Step title="Configure redirect URI">
    Set up a redirect URI back to the application
    
    <Frame>
      <img src="/images/providers/facebook/facebook-redirect-uri.png" alt="Redirect URI" />
    </Frame>

    <Snippet file="oauth2redirect.mdx" />

    **Your Facebook OAuth2 Redirect URI:**
    - Production: `https://postqueen.example.com/integrations/social/facebook`
    - Local development: `http://localhost:4200/integrations/social/facebook`
    - Docker: `http://localhost:4007/integrations/social/facebook`
  </Step>

  <Step title="Request advanced permissions">
    <Frame>
      <img src="/images/providers/facebook/facebook-advanced-permissions.png" alt="Advanced permissions" />
    </Frame>

    Facebook Page and Instagram (Facebook Business) share this app. Request the **union** of both providers in one pass (11 unique), not only the Facebook list. Skip a Facebook scope and Facebook connect fails; skip an Instagram (Facebook Business) scope and Instagram connect fails — both with `Not enough scopes, when choosing a provider, please add all the scopes`.

    Go to advanced permission and request access for the following scopes:
    - `pages_show_list`
    - `business_management`
    - `pages_manage_posts`
    - `pages_manage_engagement`
    - `pages_read_engagement`
    - `pages_read_user_content`
    - `read_insights`
    - `instagram_basic`
    - `instagram_content_publish`
    - `instagram_manage_comments`
    - `instagram_manage_insights`

    Do not add Instagram Standalone (`instagram_business_*`) or Threads (`threads_*`) scopes on this app. Those belong on separate Meta apps.

    <Note>
    If your PostQueen install is for personal use only these advanced permissions are not required for PostQueen to function.
    </Note>

    <Note>
    `pages_read_user_content` is required by Meta together with `pages_manage_engagement`, which PostQueen uses to publish follow-up comments under Facebook Page posts. PostQueen requests it when connecting a Facebook Page and does not read other people's comments or posts. Do not request `pages_messaging`, `instagram_manage_messages`, `pages_manage_metadata`, or ads permissions.
    </Note>
  </Step>

  <Step title="Set app mode to Live">
    Change the App Mode from 'Development' to 'Live'. If you do not do this then posts made via the API will display for yourself but will not be visible for other users.
  </Step>

  <Step title="Copy your credentials">
    <Frame>
      <img src="/images/providers/facebook/facebook-app-keys.png" alt="Keys" />
    </Frame>

    Go to basic permissions copy your App ID and App Secret and paste them in your `.env` file

```env
FACEBOOK_APP_ID="app id"
FACEBOOK_APP_SECRET="app secret"
```

    Facebook should now be working!
  </Step>
  <Step title="Restart and add the Facebook channel">

</Steps>

## Troubleshooting

### Image is missing from the published post

Check the **App Mode** of your Facebook app. In **Development** mode, posts with media are only visible to app developers/testers. Everyone else sees the post without the image. Switch the app to **Live** mode to make the image visible to all users.

### Facebook posts work for you but not for other users

Same root cause as above: the app is in Development mode. Only roles you have explicitly added (developers, testers, admins) can see content published via the API. Set the app to Live.
