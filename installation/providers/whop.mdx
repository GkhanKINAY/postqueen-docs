On a self-hosted PostQueen the Whop app is yours. PostQueen signs in to Whop with OAuth and PKCE, so it needs only the app's client ID: there is no client secret to set.

## Before you start

| | |
|---|---|
| Developer dashboard | [Whop developer dashboard](https://whop.com/dashboard/developer), with a Whop account |
| Variable | `WHOP_CLIENT_ID` |
| Redirect URI | `FRONTEND_URL` + `/integrations/social/whop` |
| Scopes | `openid`, `profile`, `email`, `forum:post:create`, `forum:read`, `company:basic:read` |
| You also need | Access to a Whop company that has a forum, for each account you connect |
| Review | None in Whop's OAuth guide |

<Warning>
PostQueen does not check the granted Whop scopes when an account connects. With one missing, the channel connects and looks healthy, and the first post fails and asks for a reconnect. Select all six scopes before anyone connects.
</Warning>

## Create the app

<Steps>
  <Step title="Create the app">
    Open the [Whop developer dashboard](https://whop.com/dashboard/developer) and create an app.
  </Step>
  <Step title="Add the redirect URI">
    In the app's **OAuth** section, add the redirect URI. Whop compares it exactly, scheme, port and path included:

    <CodeGroup>

    ```text Your domain
    https://postqueen.example.com/integrations/social/whop
    ```

    ```text Local development
    http://localhost:4200/integrations/social/whop
    ```

    ```text Docker on your machine
    http://localhost:4007/integrations/social/whop
    ```

    </CodeGroup>

    <OAuthRedirect />
  </Step>
  <Step title="Select the scopes">
    Choose **View available scopes** and select the six from the table above. PostQueen asks for exactly these: the three sign-in scopes, `forum:post:create` to post, `forum:read` to list forums and `company:basic:read` to list companies.
  </Step>
  <Step title="Copy the client ID">
    Copy the app's client ID, which looks like `app_xxxxx`. You do not need the client secret.
  </Step>
</Steps>

## Set the variable

Add the client ID to your environment:

```env
WHOP_CLIENT_ID="app_xxxxx"
```

<RestartAndAddChannel />

Each post then picks a company and one of its forums.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Insufficient permissions, please re-authenticate with required scopes">
    The app is missing a scope, or the account did not grant it. Select all six scopes on the app, then reconnect the channel.
  </Accordion>
  <Accordion title="Invalid token, please re-authenticate">
    Whop no longer accepts the channel's token. Reconnect the channel.
  </Accordion>
  <Accordion title="Whop shows an error about the redirect URI">
    The address PostQueen sent is not in the app's **OAuth** section. It is exactly your `FRONTEND_URL` followed by `/integrations/social/whop`, with no trailing slash.
  </Accordion>
  <Accordion title="The company or forum list is empty">
    The account has no company with a forum, or the app lacks `company:basic:read` or `forum:read`. Add a forum to the company in Whop, or add the scopes and reconnect.
  </Accordion>
</AccordionGroup>
