On a self-hosted PostQueen the Farcaster connection is yours. PostQueen reaches Farcaster through [Neynar](https://neynar.com), so the keys are Neynar's, plus a Farcaster account that represents your instance.

A channel connects through a Neynar **managed signer**. PostQueen asks Neynar for a signer, signs the key request with your app account, and shows the approval link as a QR code. The person connecting scans it, or opens the link on their phone, and approves in the Farcaster app. There is no OAuth callback, so there is no redirect URI to register.

## Before you start

| | |
|---|---|
| Developer portal | [Neynar developer portal](https://dev.neynar.com), with a Neynar account |
| Required variables | `NEYNAR_SECRET_KEY`, `NEYNAR_APP_FID`, `NEYNAR_APP_MNEMONIC` |
| Optional variables | `NEYNAR_SPONSOR_SIGNERS`, `NEYNAR_CLIENT_ID` |
| Redirect URI | None |
| You also need | A Farcaster account for your instance, and its recovery phrase |
| Review | None |

| Variable | What it is |
|---|---|
| `NEYNAR_SECRET_KEY` | Your Neynar API key. Every call to Neynar uses it: creating and checking signers, searching channels and publishing casts. |
| `NEYNAR_APP_FID` | The Farcaster id (FID, a number) of the account that represents your instance. People see this account on the approval screen. |
| `NEYNAR_APP_MNEMONIC` | The recovery phrase of that account's custody wallet. PostQueen uses it only to sign the key request for each new signer. |
| `NEYNAR_SPONSOR_SIGNERS` | `"true"` asks Neynar to pay the on-chain fee for each new signer and bill it to your Neynar credits. Any other value leaves the fee to the person approving, in the Farcaster app. |
| `NEYNAR_CLIENT_ID` | Your Neynar app's client ID. It only turns on **Continue with Farcaster** on the sign-in page. Connecting a Farcaster channel does not use it. |

<Warning>
`NEYNAR_APP_MNEMONIC` controls the app account. Use a Farcaster account created for your instance rather than a personal one, keep the phrase only in the server's environment, and never commit it.
</Warning>

## Get the keys

<Steps>
  <Step title="Create a Neynar app">
    Sign in to the [Neynar developer portal](https://dev.neynar.com) and create an app. Copy its **API key**, and its **client ID** if you want the Farcaster sign-in option.
  </Step>
  <Step title="Pick the app account">
    Choose the Farcaster account that will represent your instance, ideally one made for it. You need two things from it:

    - **Its FID.** Look the username up with Neynar's user lookup, or read it from the account's profile.
    - **Its recovery phrase.** In the Farcaster app, open **Settings**, then **Advanced**, then **Reveal recovery phrase**.
  </Step>
</Steps>

## Set the variables

```env
NEYNAR_SECRET_KEY="your-neynar-api-key"
NEYNAR_APP_FID="123456"
NEYNAR_APP_MNEMONIC="word1 word2 ... word24"
NEYNAR_SPONSOR_SIGNERS="false"
# Optional: the Continue with Farcaster sign-in option
NEYNAR_CLIENT_ID="your-neynar-client-id"
```

## Connect a Farcaster account

<Steps>
  <Step title="Open Add Channel">
    Open **Channels**, choose **Add Channel**, then **Farcaster**. A window opens with a QR code and a **Copy Farcaster link** button.
  </Step>
  <Step title="Approve on the phone">
    Scan the code with the phone that has the Farcaster app, or open the copied link there, and approve PostQueen. Without sponsorship, the Farcaster app may ask for a small fee first.
  </Step>
  <Step title="Check that it connected">
    The window shows "Waiting for your approval..." and checks every 2 seconds. It closes by itself once the approval arrives, and the account appears in the **Channels** list. It gives up after 10 minutes, or at once if the request is revoked.
  </Step>
</Steps>

<Note>
The two public routes behind this window are rate limited per client address: 30 new approval requests and 1,000 status checks an hour. The address is the **last** `X-Forwarded-For` entry, the one your reverse proxy appends, or the connection's own address without a proxy. Behind a CDN that last entry is the CDN's address, so everyone arriving through it shares one limit.
</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Farcaster is not configured: set NEYNAR_APP_FID and NEYNAR_APP_MNEMONIC">
    One of the two variables is empty. Set both and recreate the container.
  </Accordion>
  <Accordion title="The window closes with another error message">
    Neynar did not create the signer, and the message is Neynar's answer. Check `NEYNAR_SECRET_KEY`, and check that `NEYNAR_APP_FID` is the FID of the account whose recovery phrase is in `NEYNAR_APP_MNEMONIC`.
  </Accordion>
  <Accordion title="Failed to start the Farcaster connection">
    The request for a signer did not get an answer from PostQueen, or more than 30 came from one address within an hour. Behind a CDN, see the note above.
  </Accordion>
  <Accordion title="Farcaster approval timed out, please try again">
    Nobody approved within 10 minutes. Open **Add Channel** again for a new code.
  </Accordion>
  <Accordion title="The Farcaster approval was revoked, please try again">
    The request was rejected in the Farcaster app. Start again and approve it.
  </Accordion>
</AccordionGroup>
