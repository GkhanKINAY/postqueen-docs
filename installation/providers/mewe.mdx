On a self-hosted PostQueen the MeWe app is yours. MeWe gives API access only to apps in its developer program, so you apply first. Once you are in, you create a **Standalone** app and give PostQueen its app ID and API key.

## Before you start

| | |
|---|---|
| Developer portal | [MeWe for developers](https://developer.mewe.com/), with a MeWe account |
| Variables | `MEWE_APP_ID`, `MEWE_API_KEY`, and optionally `MEWE_HOST` |
| Redirect URI | `FRONTEND_URL` + `/integrations/social/mewe`, sent with each sign-in |
| Scopes | None. The app's permissions are set when you create it |
| Review | Acceptance into MeWe's developer program, a beta with limited spots |

## Create the app

<Steps>
  <Step title="Apply to the developer program">
    Sign in at [developer.mewe.com](https://developer.mewe.com/) and choose **Sign Up for early access**. MeWe reviews applications and grants access to the participants it selects.
  </Step>
  <Step title="Create a Standalone app">
    Once you are accepted, choose **Add Application**, then **Create New Application**:

    - **Application Type**: **Standalone**. PostQueen runs outside MeWe, and the type cannot be changed later.
    - **Application Name**, **Description** and **App Icon**: all required.
    - **Webhook URL**: leave it empty. PostQueen does not use it.
    - **Permissions**: allow posting to your timeline and to groups, and reading your groups. They cannot be changed after the app is created.
  </Step>
  <Step title="Copy the app ID and API key">
    Under your applications, copy the **App ID** and the **API Key** (choose **Show API Key** first). Keep the key private: every request PostQueen sends to MeWe carries it.
  </Step>
</Steps>

The MeWe app has no redirect URI field. PostQueen sends people to MeWe's login with the address to come back to:

<CodeGroup>

```text Your domain
https://postqueen.example.com/integrations/social/mewe
```

```text Local development
http://localhost:4200/integrations/social/mewe
```

```text Docker on your machine
http://localhost:4007/integrations/social/mewe
```

</CodeGroup>

MeWe recommends `https` for it, so serve PostQueen over HTTPS before real users connect.

## Set the variables

Add the app ID and the API key to your environment:

```env
MEWE_APP_ID="your app id"
MEWE_API_KEY="your api key"
```

`MEWE_HOST` is where PostQueen sends the login and the API calls. It defaults to `https://mewe.com`, so leave it out unless MeWe gives you another host.

<RestartAndAddChannel />

Pick **MeWe** and approve PostQueen on MeWe when it asks. Each post then goes to your timeline, or to a group you pick in its settings.

## Staying connected

MeWe gives no refresh token. A connection lasts until the expiry MeWe sets, or 30 days when MeWe sets none. After that the channel asks to be reconnected.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Login request is still pending. Please approve on MeWe and try again.">
    PostQueen came back before you approved it on MeWe. Approve the request on MeWe, then connect again.
  </Accordion>
  <Accordion title="Failed to exchange token. Please try again.">
    MeWe refused the app ID or the API key. Check `MEWE_APP_ID` and `MEWE_API_KEY`, and that the app is a **Standalone** app.
  </Accordion>
  <Accordion title="Access token expired, please re-authenticate">
    The MeWe sign-in expired. Choose **Reconnect channel** in the channel's menu.
  </Accordion>
  <Accordion title="Insufficient permissions for this action">
    The app does not have the permission for that post, such as posting to groups. Permissions cannot be changed on an existing app, so create a new app with them.
  </Accordion>
</AccordionGroup>
