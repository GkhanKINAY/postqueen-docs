Every post to YouTube carries a `settings` object with `"__type": "youtube"`. The post text in `value[0].content` is the video's description. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"youtube"`. PostQueen sets it from the channel you post to, so it can be left out. |
| `title` | string | Yes | The video title, 2 to 100 characters, with no `<` or `>`. |
| `type` | string | Yes | Who can watch: `public`, `private` or `unlisted`. |
| `selfDeclaredMadeForKids` | string | No | `yes` or `no`. Left out, the video is declared not made for kids. |
| `tags` | array of objects | No | Video tags, each `{ "value": "tag", "label": "tag" }`. The `label` is sent. 500 characters in total, and a tag with a space counts 2 extra because YouTube wraps it in quotes. The composer stops at 3 tags; the API does not. |
| `thumbnail` | object | No | Your own thumbnail, `{ "id": "...", "path": "..." }` from [upload a file](/public-api/uploads/upload-file). JPEG or PNG, set right after the upload, and only on a verified YouTube channel. |

Your subscribers are always notified of the upload.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| Exactly one video | “You need one media” |
| The file is an MP4 | “Item must be a video” |
| No `<` or `>` in the title | “YouTube titles cannot contain < or >” |
| No `<` or `>` in the description | “YouTube descriptions cannot contain < or >” |
| Description up to 5,000 bytes | “YouTube descriptions can be at most 5,000 bytes, and accented letters, emoji and non-Latin scripts take 2 to 4 bytes each” |
| Tags up to 500 characters in total | “The maximum allowed is 500 characters in total for all tags.” |
| `title` 2 to 100 characters, `type` one of the three values | A validation error naming the field |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "youtube",
  "name": "Your channel name",
  "message": "Item must be a video"
}
```

YouTube's own rules are not checked first: videos up to 15 minutes on an unverified channel and up to 12 hours on a verified one, and custom thumbnails only on verified channels. A thumbnail problem is reported after the video is already up. When the 100 uploads a day shared by every PostQueen customer run out, the post fails with "You have reached your daily upload limit, please try again tomorrow."

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Video with tags and thumbnail
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "How we plan a month of posts in one afternoon. Chapters:\n0:00 Intro\n1:20 The calendar\n6:45 Scheduling",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/video.mp4" }]
        }
      ],
      "settings": {
        "__type": "youtube",
        "title": "Plan a month of posts in one afternoon",
        "type": "public",
        "selfDeclaredMadeForKids": "no",
        "tags": [
          { "value": "content planning", "label": "content planning" },
          { "value": "social media", "label": "social media" }
        ],
        "thumbnail": { "id": "THUMBNAIL_ID", "path": "https://uploads.postqueen.ai/thumbnail.jpg" }
      }
    }
  ]
}
```

```json Unlisted video
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Walkthrough for the team.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/video.mp4" }]
        }
      ],
      "settings": {
        "__type": "youtube",
        "title": "Team walkthrough",
        "type": "unlisted"
      }
    }
  ]
}
```

```json Made for kids
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Count to ten with us.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/video.mp4" }]
        }
      ],
      "settings": {
        "__type": "youtube",
        "title": "Counting song",
        "type": "public",
        "selfDeclaredMadeForKids": "yes"
      }
    }
  ]
}
```

</CodeGroup>
