Pinterest cannot be connected on PostQueen yet, so a post to it has no channel to go to. The settings below are the ones a Pinterest channel will take.

Every post to Pinterest carries a `settings` object with `"__type": "pinterest"`. Read the live schema for your channel with [integration settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | Yes | Always `"pinterest"`. PostQueen sets it from the channel you post to. |
| `board` | string | Yes | The id of the board the Pin is saved to. See below. |
| `title` | string | No | The Pin title, up to 100 characters. |
| `link` | string | No | Where the Pin sends people who click it. Must be a valid URL. |
| `dominant_color` | string | No | A background color Pinterest shows while the Pin loads, such as `#E8B4B8`. |

The text of the post, the `content` of the first entry in `value`, becomes the Pin description.

### `board`

Find your board ids with the `boards` tool through [trigger a provider tool](/public-api/integrations/trigger). It takes no input and lists up to 250 boards:

```bash
curl -X POST "{{apiBase}}/integration-trigger/YOUR_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "methodName": "boards", "data": {} }'
```

The response is `{ "output": [ { "name", "id" } ] }`. Put the chosen `id` in `settings.board`.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| At least one image or video | “Requires at least one media” |
| At most 5 media items | “You can only have up to 5 media items” |
| A video comes with a cover image as the second item | “If posting a video you have to also include a cover image as second media” |
| A video Pin carries only the video and its cover | “If posting a video you can only have two media items” |
| The images in a multi-image Pin all have the same width and height | “Requires all images to have the same width and height” |
| Description up to 800 characters | “post is too long, please fix it” |
| `board` set, `title` up to 100 characters, `link` a valid URL | A validation error naming the field |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "pinterest",
  "name": "Your channel name",
  "message": "Requires at least one media"
}
```

Pinterest's own rules are not checked first: video Pins of 4 seconds to 5 minutes, and images in BMP, JPEG, PNG, TIFF or WEBP of up to 20 MB. A video Pin is created once Pinterest has processed the video, and PostQueen waits up to about 30 minutes for that.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), `BOARD_ID` with an id from the `boards` tool, and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Image Pin
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "A calm, bright living room in three steps: light walls, one bold rug, plants at eye level.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/living-room.jpg" }]
        }
      ],
      "settings": {
        "__type": "pinterest",
        "board": "BOARD_ID",
        "title": "Living room ideas",
        "link": "https://example.com/living-room-ideas"
      }
    }
  ]
}
```

```json Multi-image Pin
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Summer pasta, step by step.",
          "image": [
            { "id": "MEDIA_ID_1", "path": "https://uploads.postqueen.ai/pasta-1.jpg" },
            { "id": "MEDIA_ID_2", "path": "https://uploads.postqueen.ai/pasta-2.jpg" },
            { "id": "MEDIA_ID_3", "path": "https://uploads.postqueen.ai/pasta-3.jpg" }
          ]
        }
      ],
      "settings": {
        "__type": "pinterest",
        "board": "BOARD_ID",
        "title": "Easy summer pasta",
        "dominant_color": "#E8B4B8"
      }
    }
  ]
}
```

```json Video Pin
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Fold a fitted sheet in thirty seconds.",
          "image": [
            { "id": "MEDIA_ID_1", "path": "https://uploads.postqueen.ai/fold.mp4" },
            { "id": "MEDIA_ID_2", "path": "https://uploads.postqueen.ai/fold-cover.jpg" }
          ]
        }
      ],
      "settings": { "__type": "pinterest", "board": "BOARD_ID" }
    }
  ]
}
```

</CodeGroup>

In the multi-image example, the three images must have the same width and height. Only the first entry in `value` is published: Pinterest takes no comments, and a later entry is marked as failed with “This channel cannot post comments”.
