Every post to X carries a `settings` object with `"__type": "x"`. Read the live schema for your channel with [integration settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | Yes | Always `"x"`. PostQueen sets it from the channel you post to. |
| `who_can_reply_post` | string | Yes, except on an Article | Who can reply: `everyone`, `following`, `mentionedUsers`, `subscribers` or `verified`. The last two need X Premium. |
| `community` | string | No | An X Community link, `https://x.com/i/communities/<id>`, or an empty string. The post goes into that Community and is also shown to your followers. |
| `post_type` | string | No | `post` (the default) or `article`, a long-form X Article. Articles need X Premium. |
| `article_title` | string | When `post_type` is `article` | The Article's title, at least 1 character. |
| `article_status` | string | When `post_type` is `article` | `draft` saves the Article to your X drafts, `published` publishes it. |
| `article_cover` | object | No | A cover image for an Article, `{ "id": "...", "path": "..." }` as [upload a file](/public-api/uploads/upload-file) returns it. |
| `made_with_ai` | boolean | No | `true` labels the post as made with AI. |
| `paid_partnership` | boolean | No | `true` labels the post as a paid partnership. |

<Warning>
`subscribers`, `verified` and `post_type: "article"` need an X Premium subscription on the connected account. The composer hides them when X reports that the account has none, but the API accepts them, and X may then refuse the post when it is published.
</Warning>

### The text limit

A post takes 280 characters, or 4,000 when the channel is marked Verified. The Verified mark is read from X when the channel is connected and is changed in the app, not per post. An Article takes up to 100,000. Length is counted the way X counts it: a link is 23 characters, and most emoji and CJK characters are 2.

### Thread replies

Each extra entry in `value` is posted as a reply to the entry before it, after its `delay` in minutes. Every entry is held to the same media rule as the first. A draft Article cannot have replies.

### Articles

With `post_type: "article"`, `content` is HTML. X keeps these tags: `h1` and `h2` headings (an `h3` is sent as `h2`), `ul` and `li` bullet lists, `strong` for bold, and `a` links. Every other tag becomes a plain paragraph. The images attached to the entry are placed at the end of the Article. Video is not allowed.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| At most 4 pictures in each entry | “X allows up to 4 pictures per post” |
| A GIF or a video goes alone in its entry | “X allows one video or one GIF per post, without other media” |
| Each entry within 280, 4,000 on a Verified channel, or 100,000 in an Article | “post is too long, please fix it” |
| `community` empty or in the right format | “Invalid X community URL. It should be in the format: https://x.com/i/communities/1493446837214187523” |
| `article_title` set on an Article | “Article title is required” |
| An Article takes images only | “X articles only support images” |
| A draft Article has no thread replies | “A draft article cannot have thread replies, remove them or publish the article” |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "x",
  "name": "Your channel name",
  "message": "X allows one video or one GIF per post, without other media"
}
```

X's own rules are not checked first: video length and size, 1 cashtag per post, and 50 posts and 200 replies a day for unverified accounts. Every picture is resized to 1,000 px wide and re-encoded as a GIF before upload.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Text post
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        { "content": "We just shipped dark mode. Try it and tell us what you think.", "image": [] }
      ],
      "settings": { "__type": "x", "who_can_reply_post": "everyone" }
    }
  ]
}
```

```json Thread
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Three things we learned shipping our first release. A thread.",
          "image": [
            { "id": "MEDIA_ID_1", "path": "https://uploads.postqueen.ai/chart-1.png" },
            { "id": "MEDIA_ID_2", "path": "https://uploads.postqueen.ai/chart-2.png" }
          ]
        },
        {
          "content": "1. Ship small. Every release we cut in half went out on time.",
          "image": [],
          "delay": 2
        },
        {
          "content": "2. Show the work. This is what the team looked like on launch day.",
          "image": [{ "id": "MEDIA_ID_3", "path": "https://uploads.postqueen.ai/launch.gif" }],
          "delay": 2
        }
      ],
      "settings": { "__type": "x", "who_can_reply_post": "everyone" }
    }
  ]
}
```

```json Video in a Community
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "A 60-second tour of the new editor.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/tour.mp4" }]
        }
      ],
      "settings": {
        "__type": "x",
        "who_can_reply_post": "following",
        "community": "https://x.com/i/communities/1493446837214187523",
        "made_with_ai": false,
        "paid_partnership": true
      }
    }
  ]
}
```

```json Article
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "<h2>Why we rebuilt the scheduler</h2><p>The old one could not keep up.</p><ul><li>Posts now go out on time</li><li>Retries are safe</li></ul><p>Read the <a href=\"https://example.com/changelog\">changelog</a>.</p>",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/diagram.png" }]
        }
      ],
      "settings": {
        "__type": "x",
        "post_type": "article",
        "article_title": "Why we rebuilt the scheduler",
        "article_status": "published",
        "article_cover": { "id": "COVER_MEDIA_ID", "path": "https://uploads.postqueen.ai/cover.jpg" }
      }
    }
  ]
}
```

</CodeGroup>

The Article example needs X Premium on the connected account. With `"article_status": "draft"` instead, it lands in your X drafts.
