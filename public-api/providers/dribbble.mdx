Every post to Dribbble carries a `settings` object with `"__type": "dribbble"`. A post is a shot: one image, a title, and the post text as its description. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"dribbble"`. PostQueen sets it from the channel you post to, so it can be left out. |
| `title` | string | Yes | The shot title, at least 1 character. |
| `team` | string | No | The numeric id of one of your teams, as a string, to post the shot for that team. Anything that is not a number, a team URL included, is ignored and the shot goes on your own profile. |

### `team`

Find your team ids with the `teams` tool through [trigger a provider tool](/public-api/integrations/trigger). It takes no input:

```bash
curl -X POST "{{apiBase}}/integration-trigger/YOUR_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "methodName": "teams", "data": {} }'
```

The response is `{ "output": [ { "id", "name" } ] }`, where `id` is a number. Put it in `settings.team` as a string, such as `"1234567"`.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| Exactly one file | “Requires one item” |
| The file is not an MP4 | “Does not support mp4 files” |
| The image is exactly 400 × 300 or 800 × 600 pixels | “Invalid image size. Requires 400x300 or 800x600 px images.” |
| Description up to 40,000 characters | “post is too long, please fix it” |
| `title` set | A validation error that says “Title is required” |
| `team` a string | A validation error naming the field |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "dribbble",
  "name": "Your channel name",
  "message": "Invalid image size. Requires 400x300 or 800x600 px images."
}
```

Dribbble's own rules are not checked first: GIF, JPG or PNG files of up to 8 MB, and an account that is allowed to upload shots.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), `TEAM_ID` with an id from the `teams` tool, and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Shot
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Onboarding screens for a budgeting app: three steps, one thumb.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/onboarding-800x600.png" }]
        }
      ],
      "settings": { "__type": "dribbble", "title": "Budget app onboarding" }
    }
  ]
}
```

```json Team shot
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "A new icon set for our weather app, drawn on a 24 px grid.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/icons-400x300.png" }]
        }
      ],
      "settings": { "__type": "dribbble", "title": "Weather icons", "team": "TEAM_ID" }
    }
  ]
}
```

</CodeGroup>

Only the first entry in `value` is published: Dribbble takes no comments, and a later entry is marked as failed with “This channel cannot post comments”.
