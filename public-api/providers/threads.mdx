Every post to Threads carries a `settings` object with `"__type": "threads"`. Threads has no other settings. Read the live schema for your channel with [integration settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | Yes | Always `"threads"`. PostQueen sets it from the channel you post to. |

### Thread replies

Each extra entry in `value` is posted as a reply to the entry before it, after its `delay` in minutes. Every entry can carry text, one image or video, or a carousel of up to 20 items, and is checked on its own.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| At most 20 items in each entry | “Threads carousels can have up to 20 items” |
| JPEG or PNG images only (GIF, WebP, AVIF, BMP and TIFF are refused) | “Threads accepts JPEG or PNG images only” |
| At most 5 different links in each entry | “Threads allows up to 5 links per post” |
| Each entry within 500 UTF-8 bytes | “post is too long, please fix it” |

The 500 limit is counted in UTF-8 bytes for the whole text: plain ASCII letters count 1 and every other character 2 to 4, so text with accents or emoji fits fewer than 500 characters.

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "threads",
  "name": "Your channel name",
  "message": "Threads accepts JPEG or PNG images only"
}
```

Threads' own rules are not checked first: images up to 8 MB, videos up to 5 minutes and 1 GB, and 250 posts and 1,000 replies in any 24 hours.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Text post
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        { "content": "What is one tool you could not work without this year?", "image": [] }
      ],
      "settings": { "__type": "threads" }
    }
  ]
}
```

```json Carousel
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "The new office, room by room.",
          "image": [
            { "id": "MEDIA_ID_1", "path": "https://uploads.postqueen.ai/office-1.jpg" },
            { "id": "MEDIA_ID_2", "path": "https://uploads.postqueen.ai/office-2.png" },
            { "id": "MEDIA_ID_3", "path": "https://uploads.postqueen.ai/office-tour.mp4" }
          ]
        }
      ],
      "settings": { "__type": "threads" }
    }
  ]
}
```

```json Thread
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "How we plan a week of posts in 20 minutes. 1/3",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/calendar.png" }]
        },
        { "content": "Monday: pick three topics and one question to ask. 2/3", "image": [], "delay": 1 },
        { "content": "Then write every post in one sitting and schedule them. 3/3", "image": [], "delay": 1 }
      ],
      "settings": { "__type": "threads" }
    }
  ]
}
```

</CodeGroup>
