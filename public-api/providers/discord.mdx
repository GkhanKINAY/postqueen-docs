Every post to Discord carries a `settings` object with `"__type": "discord"`. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"discord"`. PostQueen sets it from the channel you post to, so it can be left out. |
| `channel` | string | Yes | The id of the Discord channel to post in: a text or announcement channel of the connected server. A forum channel does not take plain messages, so a post to one fails. |

One PostQueen channel is one Discord server. To post in two channels of the same server, send two posts.

The text is sent as it is, so Discord markdown such as `**bold**` or `> quote` works. Each extra entry in `value` is a follow-up, posted after its `delay` in minutes: the first starts a thread on the message, and later ones go into the same thread.

### Find the channel id

The `channels` tool lists the server's text and announcement channels. Call it through [trigger a provider tool](/public-api/integrations/trigger):

```bash
curl -X POST "{{apiBase}}/integration-trigger/YOUR_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "methodName": "channels", "data": {} }'
```

The response is `{ "output": [ { "id", "name" } ] }`. Put the chosen `id` in `settings.channel`.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| Each entry up to 1,980 characters | “post is too long, please fix it” |
| `channel` is set and not empty | A validation error naming the field, such as “posts.0.settings.channel should not be null or undefined” |

The error body for a too-long entry names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "discord",
  "name": "Your channel name",
  "message": "post is too long, please fix it"
}
```

A missing or empty field fails the request validation instead, and the body lists every problem under `message`.

Discord's own rules are not checked first: 20 MiB per file by default, and the bot's permissions in the channel. When Discord refuses a post, it fails with "Bot doesn't have access to this channel", "Bot lacks permission to send messages in this channel", "Channel no longer exists" or "Attachment exceeds Discord's size limit".

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), the Discord `channel` with an id from the `channels` tool, and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Message with a thread
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "**Version 2.4 is out.** Faster exports and a new dark theme.",
          "image": []
        },
        {
          "content": "Questions about the update? Ask them in this thread.",
          "image": [],
          "delay": 5
        }
      ],
      "settings": { "__type": "discord", "channel": "DISCORD_CHANNEL_ID" }
    }
  ]
}
```

```json Message with an image
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "A first look at the new dashboard.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/dashboard.png" }]
        }
      ],
      "settings": { "__type": "discord", "channel": "DISCORD_CHANNEL_ID" }
    }
  ]
}
```

</CodeGroup>

In the first example, the second entry in `value` is posted 5 minutes after the message, in a thread started on it.
