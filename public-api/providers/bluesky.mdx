Every post to Bluesky carries a `settings` object with `"__type": "bluesky"`. Bluesky has no other settings. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

A Bluesky channel connects with a handle and an app password, which only the app's connect form takes. [Connect it in the app](/channels/bluesky) first, then post to it here.

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"bluesky"`. PostQueen sets it from the channel you post to, so it can be left out. |

### Thread replies

Each extra entry in `value` is posted as a reply under the entry before it, after its `delay` in minutes. Every entry can carry up to 4 images or one video, and is checked on its own. An image's `alt` is sent as its alt text.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| At most 4 images in each entry | “There can be maximum 4 pictures in a post.” |
| A video goes alone in its entry | “You can only upload one video per post.” |
| Each entry within 300 characters | “post is too long, please fix it” |

Length is counted in UTF-16 units, so an emoji can count as 2 or more of the 300.

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "bluesky",
  "name": "Your channel name",
  "message": "There can be maximum 4 pictures in a post."
}
```

Bluesky's own rules are not checked first: an MP4 of up to 300 MB and 10 minutes, and 25 videos or 10 GB a day from an account with a verified email address. Large images are scaled down to fit Bluesky's file size limit before upload.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Text post
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        { "content": "We just shipped dark mode. Try it and tell us what you think.", "image": [] }
      ],
      "settings": { "__type": "bluesky" }
    }
  ]
}
```

```json Images with alt text
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Before and after the redesign.",
          "image": [
            { "id": "MEDIA_ID_1", "path": "https://uploads.postqueen.ai/before.png", "alt": "The old settings screen" },
            { "id": "MEDIA_ID_2", "path": "https://uploads.postqueen.ai/after.png", "alt": "The new settings screen" }
          ]
        }
      ],
      "settings": { "__type": "bluesky" }
    }
  ]
}
```

```json Thread
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        { "content": "Three things we learned moving our blog to a static site. 1/3", "image": [] },
        { "content": "Builds went from minutes to seconds. 2/3", "image": [], "delay": 1 },
        {
          "content": "And the hosting bill dropped to almost nothing. 3/3",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/bill.mp4" }],
          "delay": 1
        }
      ],
      "settings": { "__type": "bluesky" }
    }
  ]
}
```

</CodeGroup>
