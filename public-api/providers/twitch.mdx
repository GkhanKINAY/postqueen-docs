Every post to Twitch carries a `settings` object with `"__type": "twitch"`. A post is a message in the chat of the channel that connected. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"twitch"`. PostQueen sets it from the channel you post to, so it can be left out. |
| `messageType` | string | No | `message` for a chat message, `announcement` for a highlighted announcement. Left out, it is a chat message. |
| `announcementColor` | string | No | The color of an announcement: `primary`, `blue`, `green`, `orange` or `purple`. Left out, it is `primary`. |

Chat is text only: media on the post is not sent.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| Each entry up to 500 characters | “post is too long, please fix it” |
| `messageType` and `announcementColor` from the lists above | A validation error naming the field |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "twitch",
  "name": "Your channel name",
  "message": "post is too long, please fix it"
}
```

Twitch's own chat rate limits are not checked first. PostQueen does not read Twitch's answer to an announcement, so it is recorded as posted even when Twitch refused it.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list).

<CodeGroup>

```json Chat message with a reply
{
  "type": "schedule",
  "date": "2026-10-01T18:55:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Going live in 5 minutes with the season finale. Grab a drink and settle in.",
          "image": []
        },
        {
          "content": "We are live. Say hi in chat.",
          "image": [],
          "delay": 5
        }
      ],
      "settings": { "__type": "twitch", "messageType": "message" }
    }
  ]
}
```

```json Announcement
{
  "type": "schedule",
  "date": "2026-10-01T18:55:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Giveaway tonight at 21:00. Follow the channel to take part.",
          "image": []
        }
      ],
      "settings": {
        "__type": "twitch",
        "messageType": "announcement",
        "announcementColor": "purple"
      }
    }
  ]
}
```

</CodeGroup>

In the first example, the second entry in `value` replies to the first message 5 minutes later. Each follow-up replies to the message before it. On an announcement, the follow-ups are announcements too.
