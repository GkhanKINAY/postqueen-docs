Every post to a Facebook Page carries a `settings` object with `"__type": "facebook"`. Every other field is optional: a plain text post needs nothing more. Read the live schema for your channel with [integration settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | Yes | Always `"facebook"`. PostQueen sets it from the channel you post to. |
| `post_type` | string | No | `post` (the default) or `story`. A story needs at least one photo or video, and each item goes out as its own story. |
| `url` | string | No | A link attached to the post. It must be a valid URL. Not used on stories. |
| `text_format_preset_id` | string | No | A background preset id from the list below, for a text-only post. |

### `text_format_preset_id`

A background shows only when both of these hold. When either fails, the post still publishes, as plain text:

- **Text only.** A post with a photo or a video ignores the preset.
- **130 characters at most.** Longer text drops the background.

Facebook has no API that lists its presets, so PostQueen carries a fixed list, the same one the composer offers. The field is not checked against the list. If Facebook refuses an id, the post is published again without the background.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| A story has at least one photo or video | “Story should have at least one media” |
| Text up to 63,206 characters | “post is too long, please fix it” |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "facebook",
  "name": "Your Page name",
  "message": "Story should have at least one media"
}
```

Facebook's own rules are not checked first: photos in JPEG, PNG, GIF, BMP or TIFF up to 10 MB, and story videos up to 60 seconds. When the first item is an MP4, only that video is published and the other items are ignored. When a photo comes first, every item is sent as a photo.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the Page's id from [list channels](/public-api/integrations/list), and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Link post
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        { "content": "Our autumn guide is out. Five walks within an hour of the city.", "image": [] }
      ],
      "settings": {
        "__type": "facebook",
        "post_type": "post",
        "url": "https://example.com/autumn-walks"
      }
    }
  ]
}
```

```json Photos with a comment
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Opening night, in pictures.",
          "image": [
            { "id": "MEDIA_ID_1", "path": "https://uploads.postqueen.ai/night-1.jpg" },
            { "id": "MEDIA_ID_2", "path": "https://uploads.postqueen.ai/night-2.jpg" }
          ]
        },
        {
          "content": "Thanks to everyone who came.",
          "image": [{ "id": "MEDIA_ID_3", "path": "https://uploads.postqueen.ai/crowd.jpg" }],
          "delay": 10
        }
      ],
      "settings": { "__type": "facebook", "post_type": "post" }
    }
  ]
}
```

```json Video
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Two minutes with our head baker.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/baker.mp4" }]
        }
      ],
      "settings": { "__type": "facebook", "post_type": "post" }
    }
  ]
}
```

```json Background text
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [{ "content": "We are open all weekend!", "image": [] }],
      "settings": {
        "__type": "facebook",
        "post_type": "post",
        "text_format_preset_id": "106018623298955"
      }
    }
  ]
}
```

```json Story
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "",
          "image": [
            { "id": "MEDIA_ID_1", "path": "https://uploads.postqueen.ai/story-1.jpg" },
            { "id": "MEDIA_ID_2", "path": "https://uploads.postqueen.ai/story-2.mp4" }
          ]
        }
      ],
      "settings": { "__type": "facebook", "post_type": "story" }
    }
  ]
}
```

</CodeGroup>

In the photos example, the second entry in `value` is a follow-up comment, posted 10 minutes after the post. Each comment replies to the one before it and can carry one image. Only the first attached item is sent, and Facebook takes images on comments, not video.
