## Overview

Facebook integration allows you to post to Facebook pages. You can optionally include a link URL, publish a story instead of a feed post, or put a short text post on a background.

## Settings Schema

```json
{
  "__type": "facebook",
  "url": "https://example.com/my-article",
  "post_type": "post"
}
```

## Properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `__type` | string | ✅ | Must be `"facebook"` |
| `url` | string | ❌ | Optional link URL to include in the post |
| `post_type` | string | ❌ | `post` (the default) or `story` |
| `text_format_preset_id` | string | ❌ | Background preset for a short text-only post |

### `post_type`

| Value | Description |
|-------|-------------|
| `post` | A normal Page post. The default |
| `story` | A Facebook story. Needs at least one photo or video, and **each attachment goes out as its own story** |

A story with no media is refused with *Story should have at least one media*.

### `text_format_preset_id`

A short text-only post can sit on a coloured or illustrated background. Pass the preset id to use one. Two conditions decide whether it shows, and when either fails the post still publishes, as plain text:

- **Text only.** A post with a photo ignores the preset.
- **130 characters at most.** Longer text drops the background.

Facebook has no API for listing its presets, so PostQueen carries a fixed catalogue: the composer's background picker offers that set, and the ids themselves are listed in [`facebook.dto.ts`](https://github.com/GkhanKINAY/postqueen-app/blob/main/libraries/nestjs-libraries/src/dtos/posts/providers-settings/facebook.dto.ts).

## Examples

### Simple text post

```json
{
  "type": "now",
  "date": "2024-12-14T10:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": {
        "id": "your-facebook-integration-id"
      },
      "value": [
        {
          "content": "Check out our latest updates! 🎉",
          "image": []
        }
      ],
      "settings": {
        "__type": "facebook"
      }
    }
  ]
}
```

### Post with link

```json
{
  "type": "schedule",
  "date": "2024-12-14T10:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": {
        "id": "your-facebook-integration-id"
      },
      "value": [
        {
          "content": "We just published a new blog post about social media automation!",
          "image": []
        }
      ],
      "settings": {
        "__type": "facebook",
        "url": "https://example.com/blog/social-media-automation"
      }
    }
  ]
}
```

### Post with image

```json
{
  "type": "schedule",
  "date": "2024-12-14T10:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": {
        "id": "your-facebook-integration-id"
      },
      "value": [
        {
          "content": "Beautiful sunset from our office! 🌅",
          "image": [
            {
              "id": "img-123",
              "path": "https://uploads.postqueen.ai/sunset.jpg"
            }
          ]
        }
      ],
      "settings": {
        "__type": "facebook"
      }
    }
  ]
}
```

### Story

```json
{
  "type": "schedule",
  "date": "2024-12-14T10:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": {
        "id": "your-facebook-integration-id"
      },
      "value": [
        {
          "content": "",
          "image": [
            {
              "id": "img-123",
              "path": "https://uploads.postqueen.ai/story.jpg"
            }
          ]
        }
      ],
      "settings": {
        "__type": "facebook",
        "post_type": "story"
      }
    }
  ]
}
```

## Notes

- The `url` field is optional and creates a link preview in the post
- If posting with images, Facebook will display them as attachments
- Video uploads are also supported
