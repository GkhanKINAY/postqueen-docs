Every post to Google Business Profile carries a `settings` object with `"__type": "gmb"`. In **Add Channel** the tile is named **Google My Business**, and each channel is one location. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"gmb"`. PostQueen sets it from the channel you post to, so it can be left out. |
| `topicType` | string | No | `STANDARD` (an update), `EVENT` or `OFFER`. Left out, the post is an update. |
| `callToActionType` | string | No | The button on an update or an event: `NONE`, `BOOK`, `ORDER`, `SHOP`, `LEARN_MORE`, `SIGN_UP` or `CALL`. Left out, there is no button. Not sent on an offer, where Google shows its own. |
| `callToActionUrl` | string | No | Where the button goes. A button other than `CALL` is sent only when this is set. `CALL` takes no link: it dials the phone number verified on the profile. |
| `eventTitle` | string | For events and offers | The title of the event or the offer. |
| `eventStartDate`, `eventEndDate` | string | For events and offers | The first and last day, as `YYYY-MM-DD`. |
| `eventStartTime`, `eventEndTime` | string | No | Start and end times of an event or an offer, as `HH:MM` in 24-hour time. |
| `offerCouponCode` | string | No | A coupon code shown on the offer. |
| `offerRedeemUrl` | string | No | Where the offer is redeemed online. Must be a valid URL. |
| `offerTerms` | string | No | The offer's terms and conditions. |

`GET_OFFER` is still accepted so that posts saved with it keep working, and it is sent as `LEARN_MORE`. Use `LEARN_MORE` in new posts.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| At most one photo | “Google My Business posts can only have one image” |
| No video | “Google My Business posts do not support video attachments” |
| An event has `eventTitle` | “Event posts require an event title” |
| An event has `eventStartDate` and `eventEndDate` | “Event posts require a start and an end date” |
| An offer has `eventTitle` | “Offer posts require an offer title” |
| An offer has `eventStartDate` and `eventEndDate` | “Offer posts require a start and an end date” |
| Text up to 1,500 characters | “post is too long, please fix it” |
| `topicType` and `callToActionType` from the lists above, `callToActionUrl` and `offerRedeemUrl` valid URLs | A validation error naming the field |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "gmb",
  "name": "Your channel name",
  "message": "Event posts require a start and an end date"
}
```

Google's own rules are not checked first: photos in JPG or PNG of 10 KB to 5 MB. An event or an offer sent without `eventStartTime` and `eventEndTime` goes out without times, and Google may refuse it. Every post is sent with its language set to English.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Update with a button
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Our autumn menu is here, with three new soups and a pumpkin tart. Book a table for this weekend.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/autumn-menu.jpg" }]
        }
      ],
      "settings": {
        "__type": "gmb",
        "topicType": "STANDARD",
        "callToActionType": "BOOK",
        "callToActionUrl": "https://example.com/book"
      }
    }
  ]
}
```

```json Update with a Call button
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "We are open late on Fridays until 10 pm. Call ahead for large groups.",
          "image": []
        }
      ],
      "settings": { "__type": "gmb", "topicType": "STANDARD", "callToActionType": "CALL" }
    }
  ]
}
```

```json Event
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Join our tasting evening: five local wines, small plates and live music.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/tasting.jpg" }]
        }
      ],
      "settings": {
        "__type": "gmb",
        "topicType": "EVENT",
        "eventTitle": "Wine tasting evening",
        "eventStartDate": "2026-10-17",
        "eventEndDate": "2026-10-17",
        "eventStartTime": "18:00",
        "eventEndTime": "22:00",
        "callToActionType": "SIGN_UP",
        "callToActionUrl": "https://example.com/tasting"
      }
    }
  ]
}
```

```json Offer
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "20% off every coffee bag this week.",
          "image": []
        }
      ],
      "settings": {
        "__type": "gmb",
        "topicType": "OFFER",
        "eventTitle": "20% off coffee bags",
        "eventStartDate": "2026-10-01",
        "eventEndDate": "2026-10-07",
        "offerCouponCode": "BEANS20",
        "offerRedeemUrl": "https://example.com/shop",
        "offerTerms": "One use per customer."
      }
    }
  ]
}
```

</CodeGroup>

Only the first entry in `value` is published: Google Business Profile takes no comments, and a later entry is marked as failed with “This channel cannot post comments”.
