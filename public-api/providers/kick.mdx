Every post to Kick carries a `settings` object with `"__type": "kick"`, and nothing else: Kick has no settings of its own. A post is a message in the chat of the channel that connected. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"kick"`. PostQueen sets it from the channel you post to, so it can be left out. |

Chat is text only: media on the post is not sent.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| Each entry up to 500 characters | “post is too long, please fix it” |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "kick",
  "name": "Your channel name",
  "message": "post is too long, please fix it"
}
```

Kick's own rules are not checked first: a message is also capped at 2,048 bytes, so a message heavy in emoji holds fewer than 500 characters.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list).

<CodeGroup>

```json Chat message
{
  "type": "schedule",
  "date": "2026-10-01T18:55:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Stream starts in 5 minutes: ranked games until midnight.",
          "image": []
        }
      ],
      "settings": { "__type": "kick" }
    }
  ]
}
```

```json Message with replies
{
  "type": "schedule",
  "date": "2026-10-01T18:55:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Going live in 5 minutes.",
          "image": []
        },
        {
          "content": "We are live.",
          "image": [],
          "delay": 5
        },
        {
          "content": "Raffle opens in ten minutes. Stay in chat.",
          "image": [],
          "delay": 20
        }
      ],
      "settings": { "__type": "kick" }
    }
  ]
}
```

</CodeGroup>

In the second example, each entry after the first replies to the message before it: 5 minutes after the first message, then 20 minutes after that.
