Every post to TikTok carries a `settings` object with `"__type": "tiktok"`. Most of its fields are required, even the ones TikTok ignores in Upload mode, so send them all. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

<Warning>
Until TikTok audits PostQueen's app, send `"privacy_level": "SELF_ONLY"`. TikTok refuses every other level at publish time, after the post was accepted and scheduled. The `creatorInfo` [tool](/public-api/integrations/provider-tools#tiktok) returns the levels this account accepts right now.
</Warning>

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"tiktok"`. PostQueen sets it from the channel you post to, so it can be left out. |
| `content_posting_method` | string | Yes | `DIRECT_POST` publishes the post. `UPLOAD` does not publish: it sends the media to the account's TikTok inbox, where the owner finishes and publishes it in the TikTok app within 24 hours. |
| `privacy_level` | string | Yes | Who can see the post: `PUBLIC_TO_EVERYONE`, `MUTUAL_FOLLOW_FRIENDS`, `FOLLOWER_OF_CREATOR` or `SELF_ONLY`. Only `SELF_ONLY` works until TikTok's audit. Ignored with `UPLOAD`. |
| `comment` | boolean | Yes | Allow comments. Ignored with `UPLOAD`. |
| `duet` | boolean | Yes | Allow Duet. Videos only; ignored on photo posts and with `UPLOAD`. |
| `stitch` | boolean | Yes | Allow Stitch. Videos only; ignored on photo posts and with `UPLOAD`. |
| `autoAddMusic` | string | Yes | `yes` or `no`. `yes` lets TikTok add recommended music. Photo posts only; ignored on videos and with `UPLOAD`. |
| `brand_organic_toggle` | boolean | Yes | Discloses that you promote yourself or your own brand. Ignored with `UPLOAD`. |
| `brand_content_toggle` | boolean | Yes | Discloses a paid partnership with another brand. TikTok does not allow such a post to be private, so it cannot publish while only `SELF_ONLY` works. Ignored with `UPLOAD`. |
| `title` | string | No | The title of a photo post, up to 90 characters. A video has no separate title: its caption is the post text. |
| `video_made_with_ai` | boolean | No | Labels the video as AI-generated. Videos only; ignored with `UPLOAD`. |

The caption is the post text in `value[0].content`, up to 2,000 characters. For a photo post it becomes the description under the title. With `UPLOAD`, TikTok keeps only a photo post's title and caption; a video's caption and the other fields are dropped, and the owner sets them in the TikTok app.

Photos are fetched by TikTok from their PostQueen address. Upload each file with [upload a file](/public-api/uploads/upload-file) first and use the `path` it returns: a photo from anywhere else fails at publish time with "You have to upload the picture/video to PostQueen when sending a URL".

### TikTok Business

The **TikTok Business** tile cannot be connected yet. A channel on it would take `"__type": "tiktok-business"`, the same fields as above, and two optional ones:

| Field | Type | What it does |
|---|---|---|
| `music` | object | A track from TikTok's commercial music list: `{ "id": "...", "audio_volume": 50, "video_volume": 50 }`. Find the id with the `musicSearch` tool. Volumes run `0` to `100`, default `50`, videos only. |
| `location` | object | A location tag: `{ "id": "...", "name": "..." }`, from the `locationSearch` tool. |

On that tile `privacy_level` and `autoAddMusic` apply to photo posts only, `autoAddMusic: "yes"` attaches a random track and overrides `music`, and captions can run to 2,200 characters.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| At least one video or photo | “No video / images selected” |
| A video goes on its own | “Only pictures are supported when selecting multiple items” |
| At most 35 photos | “You can select up to 35 pictures” |
| No BMP photos | “TikTok only accepts JPEG or WebP pictures and BMP files cannot be converted, please use a JPEG or PNG” |
| Photos at most 1,080 px on the shorter side | “Image 2 is 1440x1920, TikTok allows a maximum of 1080px on the shorter side” (with the photo's number and size) |
| Caption up to 2,000 characters | “post is too long, please fix it” |
| Every required field is present, with an allowed value | A validation error naming the field |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "tiktok",
  "name": "Your channel name",
  "message": "You can select up to 35 pictures"
}
```

TikTok's own rules are not checked first: the account's maximum video length, videos at least 360 px on both sides, photos up to 20 MB, about 15 direct posts a day per account, and at most 5 uploads waiting in the inbox in any 24 hours. PNG, WebP, GIF, AVIF and TIFF photos are converted to JPEG when the post is published.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns. Every example uses `SELF_ONLY`, the one level TikTok publishes until its audit of PostQueen's app passes.

<CodeGroup>

```json Video
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Three ways to fold a fitted sheet. #lifehack",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/video.mp4" }]
        }
      ],
      "settings": {
        "__type": "tiktok",
        "content_posting_method": "DIRECT_POST",
        "privacy_level": "SELF_ONLY",
        "comment": true,
        "duet": false,
        "stitch": false,
        "autoAddMusic": "no",
        "brand_organic_toggle": false,
        "brand_content_toggle": false,
        "video_made_with_ai": false
      }
    }
  ]
}
```

```json Photo post
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Our three best-sellers this month, in order.",
          "image": [
            { "id": "MEDIA_ID_1", "path": "https://uploads.postqueen.ai/photo-1.jpg" },
            { "id": "MEDIA_ID_2", "path": "https://uploads.postqueen.ai/photo-2.jpg" },
            { "id": "MEDIA_ID_3", "path": "https://uploads.postqueen.ai/photo-3.jpg" }
          ]
        }
      ],
      "settings": {
        "__type": "tiktok",
        "title": "September best-sellers",
        "content_posting_method": "DIRECT_POST",
        "privacy_level": "SELF_ONLY",

        "autoAddMusic": "yes",
        "brand_organic_toggle": true,
        "brand_content_toggle": false
      }

```

