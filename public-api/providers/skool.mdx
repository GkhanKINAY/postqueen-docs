Every post to Skool carries a `settings` object with `"__type": "skool"`. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"skool"`. PostQueen sets it from the channel you post to, so it can be left out. |
| `group` | string | Yes | The id of the Skool group to post in. |
| `label` | string | Yes | The id of the category the post is filed under. `"none"` posts without a category, and it is the only value the `label` tool offers for a group that has no categories. |
| `title` | string | Yes | The post's title. |

The text is sent as it is, up to 5,000 characters, and each file is uploaded to Skool as an attachment. Each extra entry in `value` is a comment, posted after its `delay` in minutes under the entry before it. Comments can carry files too, and take no title.

### Find the ids

Two tools list the ids. Call them through [trigger a provider tool](/public-api/integrations/trigger):

- `groups` lists your first 30 groups, with no `data`.
- `label` lists a group's categories. Pass the group id as `data.id`.

```bash
curl -X POST "{{apiBase}}/integration-trigger/YOUR_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "methodName": "label", "data": { "id": "GROUP_ID" } }'
```

Both return `{ "output": [ { "id", "name" } ] }`. For a group with no categories, `label` answers `[ { "id": "none", "name": "Default Label" } ]`. Put the group's `id` in `settings.group` and the category's `id` in `settings.label`.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| Each entry up to 5,000 characters | “post is too long, please fix it” |
| `group`, `label` and `title` are set and not empty | A validation error naming the field, such as “posts.0.settings.title should not be null or undefined” |

The error body for a too-long entry names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "skool",
  "name": "Your channel name",
  "message": "post is too long, please fix it"
}
```

A missing or empty field fails the request validation instead, and the body lists every problem under `message`.

After scheduling, Skool can still refuse a post: "You can't post to this channel" when the account's role in the group is below what it requires, and "Cannot post to this label" when the category is restricted.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), `group` and `label` with ids from the tools above, and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Post with a comment
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "This week's call is on Thursday at 17:00. Post your questions below and we will answer them live.",
          "image": []
        },
        {
          "content": "The recording of last week's call is in the Classroom.",
          "image": [],
          "delay": 10
        }
      ],
      "settings": {
        "__type": "skool",
        "group": "GROUP_ID",
        "label": "LABEL_ID",
        "title": "Thursday Q&A"
      }
    }
  ]
}
```

```json Post with an image, no category
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "Here is the checklist from today's lesson.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/checklist.png" }]
        }
      ],
      "settings": {
        "__type": "skool",
        "group": "GROUP_ID",
        "label": "none",
        "title": "Lesson checklist"
      }
    }
  ]
}
```

</CodeGroup>

In the first example, the second entry in `value` is posted 10 minutes after the post, as a comment under it.
