Whop cannot be connected on PostQueen yet, so a post to it has no channel to go to. The settings below are the ones a Whop channel will take.

Every post to Whop carries a `settings` object with `"__type": "whop"`. Read the live schema for your channel with [integration settings](/public-api/integrations/settings).

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | Yes | Always `"whop"`. PostQueen sets it from the channel you post to. |
| `company` | string | Yes | The id of the Whop company the forum belongs to. PostQueen uses it to list the forums; the post goes to `experience`. |
| `experience` | string | Yes | The id of the forum to post in, which Whop calls an experience. |
| `title` | string | No | The post's title. Left out, the post has none. |

The text is sent as Markdown, up to 50,000 characters. Each file is uploaded to Whop and attached to the post. Each extra entry in `value` is a reply, posted after its `delay` in minutes: the first replies to the post, and each later one replies to the one before it. Replies can carry files too, and take no title.

### Find the ids

Two tools list the ids. Call them through [trigger a provider tool](/public-api/integrations/trigger):

- `companies` lists your companies, with no `data`.
- `experiences` lists a company's forums. Pass the company id as `data.id`.

```bash
curl -X POST "{{apiBase}}/integration-trigger/YOUR_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "methodName": "experiences", "data": { "id": "COMPANY_ID" } }'
```

Both return `{ "output": [ { "id", "name" } ] }`, with the first 50 of each. Put the company's `id` in `settings.company` and the forum's `id` in `settings.experience`.

## What PostQueen checks

A post that breaks one of these rules is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| Each entry up to 50,000 characters | “post is too long, please fix it” |
| `company` and `experience` are set and not empty | A validation error naming the field, such as “posts.0.settings.experience should not be null or undefined” |

The error body for a too-long entry names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "whop",
  "name": "Your channel name",
  "message": "post is too long, please fix it"
}
```

A missing or empty field fails the request validation instead, and the body lists every problem under `message`.

After scheduling, a post can still fail at Whop. If Whop has not finished processing a file after about 9 minutes, the post fails with "File upload timed out". A forum that was deleted, or that the account can no longer reach, fails with "Forum or experience not found".

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), `company` and `experience` with ids from the tools above, and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Titled post with a reply
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "## What shipped this week\n\n- Faster checkout\n- A new members page\n\nTell us what you think below.",
          "image": []
        },
        {
          "content": "Next week: the mobile app beta opens to every member.",
          "image": [],
          "delay": 30
        }
      ],
      "settings": {
        "__type": "whop",
        "company": "COMPANY_ID",
        "experience": "EXPERIENCE_ID",
        "title": "Weekly update"
      }
    }
  ]
}
```

```json Post with an image and no title
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "A first look at the new members page.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/members-page.png" }]
        }
      ],
      "settings": {
        "__type": "whop",
        "company": "COMPANY_ID",
        "experience": "EXPERIENCE_ID"
      }
    }
  ]
}
```

</CodeGroup>

In the first example, the second entry in `value` is posted 30 minutes after the forum post, as a reply to it.
