Every post to Nostr carries a `settings` object with `"__type": "nostr"`. Nostr has no other settings. Read the live schema for your channel with [Get a channel's settings](/public-api/integrations/settings).

A Nostr channel connects with a private key, which only the app's connect form takes. [Connect it in the app](/channels/nostr) first, then post to it here.

## Fields

| Field | Type | Required | What it does |
|---|---|---|---|
| `__type` | string | No | Always `"nostr"`. PostQueen sets it from the channel you post to, so it can be left out. |

### Relays

The note is signed with the channel's key and sent to a fixed list of relays: `nos.lol`, `relay.damus.io`, `relay.snort.social`, `temp.iris.to` and `vault.iris.to`. It counts as published when at least one accepts it. There is no setting to choose relays.

### Media

Images and videos are not uploaded. Their `path` addresses are added at the end of the note, each on its own line, and clients that preview links show them.

### Thread replies

Each extra entry in `value` is published as a reply to the entry before it, after its `delay` in minutes. A reply points only at the entry before it, so a client that follows Nostr's threading rules strictly may not show the entries as one thread.

## What PostQueen checks

A post that breaks this rule is refused with `400` before it is scheduled:

| Rule | Message |
|---|---|
| Each entry within 100,000 characters | “post is too long, please fix it” |

The error body names the channel and the rule:

```json
{
  "statusCode": 400,
  "provider": "nostr",
  "name": "Your channel name",
  "message": "post is too long, please fix it"
}
```

Each relay sets its own size limit, and PostQueen does not check it first. When no relay accepts the note, the post fails with “No Nostr relay accepted the note”.

## Examples

Send each body to [create a post](/public-api/posts/create). Replace `YOUR_CHANNEL_ID` with the channel's id from [list channels](/public-api/integrations/list), and each media `id` and `path` with the values [upload a file](/public-api/uploads/upload-file) returns.

<CodeGroup>

```json Text note
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        { "content": "Our relay list and posting schedule for this month are up on the blog.", "image": [] }
      ],
      "settings": { "__type": "nostr" }
    }
  ]
}
```

```json Note with an image
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        {
          "content": "The view from the new studio.",
          "image": [{ "id": "MEDIA_ID", "path": "https://uploads.postqueen.ai/studio.jpg" }]
        }
      ],
      "settings": { "__type": "nostr" }
    }
  ]
}
```

```json Thread
{
  "type": "schedule",
  "date": "2026-10-01T09:00:00.000Z",
  "shortLink": false,
  "tags": [],
  "posts": [
    {
      "integration": { "id": "YOUR_CHANNEL_ID" },
      "value": [
        { "content": "Why we moved our announcements to Nostr, in three notes. 1/3", "image": [] },
        { "content": "No single company can take the account away. 2/3", "image": [], "delay": 2 },
        { "content": "And readers pick the client they like. 3/3", "image": [], "delay": 2 }
      ],
      "settings": { "__type": "nostr" }
    }
  ]
}
```

</CodeGroup>
