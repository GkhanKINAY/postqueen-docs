---
title: "Create a post"
description: "Schedule a post, publish it now or save a draft, on one channel or several, with media and threads."
openapi: "POST /posts"
---

Every request carries the same five fields: `type`, `date`, `shortLink`, `tags` and `posts`. Each entry in `posts` is one channel, and each item in its `value` list is one part of the post: the first is the post, the rest are its thread or comments. The request examples on this page show whole requests for Bluesky, Nostr, WordPress and DEV.

A step-by-step guide, from finding the channel id to checking the result, is [Schedule a post with the API](/public-api/schedule-a-post).

## `type`

| Value | What happens |
|---|---|
| `schedule` | The post goes out at `date`, in UTC. A `date` that has already passed publishes at once. |
| `now` | The post goes out at once. `date` is still required, and PostQueen stamps the current minute instead. |
| `draft` | Saved on the channel's calendar without publishing. Move it to scheduled later with [Change post status](/public-api/posts/change-status). |
| `update` | Changes existing posts in place, named by `value[].id`, without starting a new publish. The first id must be a post of your workspace, or the request is refused: see [Changing or copying a post](#changing-or-copying-a-post). |

<Note>
A draft is checked too: the body, each network's required settings, and that every item has text or media. The network's rules on length and media are checked only when the post is set to go out (`schedule`, `now` and `update`), and again when you move a draft to `schedule` with [Change post status](/public-api/posts/change-status). So a draft that was accepted can still be refused then.
</Note>

## Two fields that are easy to miss

- **`image` is required on every item of `value`.** Send `[]` for text only. Leaving it out answers `400` with `posts.0.value.0.image must be an array`.
- **`group` deletes.** Leave it out for a new post. When it names an existing group, every post of that group that the request does not resend is deleted.
- **`shortLink` changes nothing today.** It is required, but PostQueen has no link shortener set up, so links stay as written with `true` too.

Every field, with its type, is in the body schema on this page.

Media must be uploaded first. A post's media path must end in `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp` or `.mp4`, and a video must be `ready`: see [Upload a file](/public-api/uploads/upload-file).

## Link to another post

Write `(post:ID)` in a `content`, with the id of another post of your workspace, and PostQueen replaces it with that post's address on its network when this post is published. Use it to point a new post or a comment at an earlier one:

```json
{ "content": "Part two of our spring menu. Part one: (post:cmg1p0s7k0001qz0h4yq2a8r1)", "image": [] }
```

The id is a `postId` from this endpoint's answer or an `id` from [List posts](/public-api/posts/list). The address is read at publish time, so the other post has to be published first. When it has no address by then, or the id is not a post of your workspace, the placeholder is removed and the rest of the text goes out.

## Settings by network

`settings.__type` is always set from the channel, so you may leave it out; what matters is the shape of the rest. Networks without required settings need no `settings` at all. Every field of every network, with examples: [Posting settings by network](/public-api/providers/overview).

| Network | Required settings |
|---|---|
| Bluesky, Nostr | None |
| WordPress | `title`, `type` (`posts`, `pages` or another post type from the `postTypes` tool) |
| DEV | `title` |
| Hashnode | `title`, `publication`, at least one `tags` entry |
| Lemmy | `subreddit` list, each with a community and a title |
| Listmonk | `subject`, `preview`, `list` |
| Moltbook | `submolt` |
| X | `who_can_reply_post`, or `article_title` and `article_status` for an article |
| Instagram | `post_type` |
| YouTube | `title`, `type` |
| TikTok | Eight fields, from `privacy_level` to `content_posting_method`: see [TikTok settings](/public-api/providers/tiktok) |
| Facebook, Threads | None |
| Reddit | `subreddit` list, each with a subreddit, title, type and flair choice |
| Pinterest | `board` |
| Dribbble | `title` |
| Discord, Slack | `channel` |
| Skool | `group`, `label`, `title` |
| Whop | `company`, `experience` |
| MeWe | `postType`, and `group` for a group post |
| Farcaster | `subreddit` list of channels |
| Google Business Profile | None; an event or offer needs `eventTitle`, `eventStartDate` and `eventEndDate` |
| LinkedIn, Mastodon, Telegram, VK, Kick, Twitch, Tumblr | None |

## What comes back

A `201` with one row per channel entry. Keep the `postId`s: the other post endpoints take them.

```json
[{ "postId": "cmg1p0s7k0001qz0h4yq2a8r1", "integration": "cmg1ozx2c0000qz0h8c7w5v3n" }]
```

When a part breaks a network's rule, the call answers `400` before anything is saved, naming the network and the channel:

```json
{
  "statusCode": 400,
  "provider": "bluesky",
  "name": "PostQueen",
  "message": "post is too long, please fix it"
}
```

A channel id that is not a channel of your workspace, or a channel that was deleted, answers `400` with `Integration with id <id> not found`, and nothing is saved. Take the ids from [List channels](/public-api/integrations/list).

Every status the endpoint returns, and what to do about it, is on [Limits and errors](/public-api/limits-and-errors).

## Changing or copying a post

- **Change a scheduled post.** Send it again with `value[].id` set to the id of each part you keep, and its `group` from [List posts](/public-api/posts/list) so the parts you leave out are deleted. Use `update` with the post's current `date` to change its text or media without touching the schedule, or `schedule` with a new `date` to move it. To change only its settings, [Update post settings](/public-api/posts/settings) is simpler.
- **`update` needs the id of the main post.** In each entry of `posts`, `value[0].id` must be the id of a post in your workspace, and of the post itself, not of one of its comments. A missing, mistyped or deleted id is refused with `400` before anything is saved:

  ```text
  type 'update' changes an existing post: value[0].id must be the id of a post in this workspace (the main post, not a comment). To create a post, use type 'draft', 'schedule' or 'now'.
  ```

  Take the ids from [List posts](/public-api/posts/list). Later items of `value` with a new id, or none, are added to the post as new comments or thread items.
- **Publish a post again.** `schedule` or `now` with the id of a post that was already published is refused with `400`. Add `"republish": true` if you mean it.
- **Copy a post.** There is no copy endpoint. Read the post with [List posts](/public-api/posts/list), parse its `settings` and `image` (they come back as JSON strings), and send the content as a new post without any post ids or `group`.

## Size and rate limits

<Warning>
Do not put file data in the body. This endpoint takes about 100 kB of JSON, which one base64 image exceeds, and answers `413` before anything is checked. Upload the file first and send its `id` and `path`.
</Warning>

<Note>
A workspace can send 30 `POST /posts` requests an hour, and a request refused with `400` counts too. One request can carry many channels and a whole thread, and it counts once. See [Limits and errors](/public-api/limits-and-errors).
</Note>
