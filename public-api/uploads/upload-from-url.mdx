---
title: "Upload from a URL"
description: "Have PostQueen fetch an image or video from a public HTTPS URL into the media library."
openapi: "POST /upload-from-url"
---

Use this when the file already sits on the web, on a CDN or in public storage, and you do not want to download it and upload it again.

```bash
curl -X POST "{{apiBase}}/upload-from-url" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/launch-banner.png"}'
```

The answer has the same shape as [Upload a file](/public-api/uploads/upload-file): put its `id` and `path` on the post.

## What the URL must be

- A public `https://` URL that needs no sign-in. Plain `http` is refused.
- Its path, without the query string, ends in `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp` or `.mp4`. AVIF, BMP, TIFF and MOV files cannot be fetched this way; send them to [Upload a file](/public-api/uploads/upload-file).
- It does not point at a private, local or internal address. PostQueen checks the address again when it connects.

## How the file is fetched

PostQueen streams the file to storage, up to 1 GB and for at most 5 minutes. A server that declares a larger file is refused before the download starts. Once the file is in, PostQueen reads its type from the bytes, so a `.png` URL that serves an HTML page fails with `Unsupported file type.` A video comes back `processing`, as an upload does: poll [Get media status](/public-api/uploads/media-status) before you post it.

## If it fails

| Answer | What to do |
|---|---|
| `400` with a `message` list | The URL is not https, has another extension, or points at an address PostQueen will not fetch |
| `400 Failed to fetch URL` | The server did not answer with the file in time, or answered with an error. Check that the link opens without signing in |
| `400 File is too large.` | Over 1 GB |
| `400 Unsupported file type.` | The bytes are not an image or video PostQueen accepts |
| `429` | Over 300 uploads from URLs this hour. See [Limits and errors](/public-api/limits-and-errors) |

<Tip>
Use stable links. A signed link that expires before PostQueen fetches it fails with `Failed to fetch URL`.
</Tip>
