---
title: "Upload a file"
description: "Upload an image or video from disk and get the id and path a post's media takes."
openapi: "POST /upload"
---

Send the file as multipart form data in a field named `file`. The answer's `id` and `path` go into a post's `image` array.

<CodeGroup>

```bash curl
curl -X POST "{{apiBase}}/upload" \
  -H "Authorization: YOUR_API_KEY" \
  -F "file=@launch-banner.png"
```

```js Node.js
import { readFile } from "node:fs/promises";

const form = new FormData();
form.append("file", new Blob([await readFile("launch-banner.png")]), "launch-banner.png");

const res = await fetch("{{apiBase}}/upload", {
  method: "POST",
  headers: { Authorization: process.env.POSTQUEEN_API_KEY },
  body: form,
});
const media = await res.json();
```

</CodeGroup>

Then, in the post:

```json
"image": [
  {
    "id": "e639003b-f727-4a1e-87bd-74a2c48ae41e",
    "path": "https://cdn.example.com/a1b2c3d4e5.png"
  }
]
```

## What it accepts

PostQueen reads the type from the file's bytes, not its name, and stores files up to 1 GB. Each network then has its own, much smaller limits when it publishes.

| Type | Stored | Can go on a post |
|---|---|---|
| JPEG, PNG, GIF, WebP | Yes | Yes |
| MP4 | Yes, after processing | Yes, once `ready` |
| MOV | Yes, converted to MP4 | Yes, once `ready` |
| AVIF, BMP, TIFF | Yes | No: a post's media must end in .png, .jpg, .jpeg, .gif, .webp or .mp4 |

## Videos are processed first

A video answers with `"status": "processing"` while PostQueen prepares it for the networks. Poll [Get media status](/public-api/uploads/media-status) until it is `ready`, then use the `path` that call returns: a converted file has a new one. Images are `ready` at once.

<Note>
`POST /upload` allows 300 requests an hour per workspace, counted apart from Upload from a URL and from the posting limit. See [Limits and errors](/public-api/limits-and-errors).
</Note>
