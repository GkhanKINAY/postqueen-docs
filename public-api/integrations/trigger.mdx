---
title: "Trigger a tool"
sidebarTitle: "Trigger a tool"
description: "Run a network's helper tool on a channel, such as listing WordPress post types or Discord channels."
openapi: "POST /integration-trigger/{id}"
---

Some settings take an id you cannot guess: a WordPress post type, a Hashnode publication, a Discord channel. The network's helper tools look them up for you.

<Steps>
  <Step title="Find the tool">
    Call [Get a channel's settings](/public-api/integrations/settings). Its `tools` list gives each tool's `methodName`, what it does, and its inputs in `dataSchema`.
  </Step>
  <Step title="Run it">
    Send `methodName`, and `data` keyed as in `dataSchema`. Send `"data": {}` for a tool with no inputs.
  </Step>
  <Step title="Use the result">
    Put the id you picked into the post's `settings`, such as `"type": "posts"` for WordPress.
  </Step>
</Steps>

```bash
curl -X POST "https://api.postqueen.ai/public/v1/integration-trigger/YOUR_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"methodName": "postTypes", "data": {}}'
```

The tools of every network, and what each returns, are on [Provider tools](/public-api/integrations/provider-tools).

<Note>
When the network refuses the call, the answer is a plain `500 Unexpected error`, without the network's own message. Check `data` against the tool's `dataSchema` first. `401 Channel disconnected due to expired token` means the channel has to be connected again.
</Note>
