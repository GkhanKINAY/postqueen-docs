Some settings need a value you cannot know in advance: which WordPress post type, which Hashnode publication, which Lemmy community. A network's helper tools fetch those values for you, so nobody has to copy an id out of a web page.

The API, the CLI and the MCP server all run the same tools:

<CodeGroup>

```bash API
curl -X POST "{{apiBase}}/integration-trigger/YOUR_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"methodName": "postTypes", "data": {}}'
```

```bash CLI
postqueen integrations:trigger YOUR_CHANNEL_ID postTypes
```

```json MCP (triggerTool)
{
  "integrationId": "YOUR_CHANNEL_ID",
  "methodName": "postTypes",
  "dataSchema": []
}
```

</CodeGroup>

The API takes the inputs as an object in `data`, such as `{"word": "design"}`. The MCP `triggerTool` takes them as a list of `{ key, value }` pairs.

<Note>
This page is the catalog. For the live list on one connected channel, with each tool's inputs, call [Get a channel's settings](/public-api/integrations/settings). Networks marked **Soon** cannot be connected on PostQueen yet; their tools are listed for when they can. Status per network: [Channels](/channels/overview).
</Note>

## Which networks have tools

| Network | Tools |
|---|---|
| [WordPress](#wordpress) | `postTypes`, `categoriesList`, `tagsList` |
| [DEV](#dev) | `tags`, `organizations` |
| [Hashnode](#hashnode) | `tagsList`, `publications` |
| [Lemmy](#lemmy) | `subreddits` |
| [Listmonk](#listmonk) | `list`, `templates` |
| [Instagram](#instagram) (In review) | `audioSearch` |
| [TikTok](#tiktok) (In review) | `creatorInfo` |
| [TikTok Business](#tiktok-business) (In review) | `musicSearch`, `locationSearch` |
| Soon: [Reddit](#reddit), [Pinterest](#pinterest), [Discord](#discord), [Slack](#slack), [Dribbble](#dribbble), [MeWe](#mewe), [Whop](#whop), [Skool](#skool), [Farcaster](#farcaster) | Listed below |

Every other network has no tools: Bluesky, Nostr, Moltbook, X, Threads, Facebook, YouTube, Instagram Standalone, LinkedIn, Mastodon, Telegram, VK, Kick, Twitch, Tumblr and Google Business Profile. Everything they need is in the post's settings.

## WordPress

| Tool | Inputs | Returns |
|---|---|---|
| `postTypes` | none | The post types your site exposes, as `{ id, name }`. The id is the REST base, such as `posts` or `pages`: send it as the `type` setting. |
| `categoriesList` | none | Categories, as `{ id, name }`. Send ids as `categories`. |
| `tagsList` | none | Tags, as `{ id, name }`. Send ids as `tags`. |

## DEV

| Tool | Inputs | Returns |
|---|---|---|
| `tags` | none | DEV tags, as `{ value, label }`: `value` is the tag id and `label` its name, unlike the `{ id, name }` most tools return. They fit the `tags` setting as they are. |
| `organizations` | none | Organizations your existing DEV articles were published under, as `{ id, name, username }`. An organization you have never published under does not appear. |

## Hashnode

| Tool | Inputs | Returns |
|---|---|---|
| `tagsList` | none | Hashnode's tag catalog, 1,000 entries, as `{ name, slug, objectID }`, some with a `logo`. It is a fixed list inside PostQueen, so it answers at once. |
| `publications` | none | The publications you can post to, as `{ id, name }`. Send the id as `publication`. |

## Lemmy

| Tool | Inputs | Returns |
|---|---|---|
| `subreddits` | `word` | Lemmy communities matching the word, as `{ id, title, name }`. The name comes from the Reddit tool it shares a shape with; it searches communities. |

## Listmonk

| Tool | Inputs | Returns |
|---|---|---|
| `list` | none | Mailing lists on your Listmonk instance, as `{ id, name }`. |
| `templates` | none | Email templates, as `{ id, name }`, with `{ id: 0, name: "Default" }` first so there is always one to pick. |

## Instagram

| Tool | Inputs | Returns |
|---|---|---|
| `audioSearch` | `q`, `type` | Audio you can add to a Reel, as `{ id, title, artist, image, duration, previewUrl }`, with `duration` in milliseconds. Leave `q` empty for trending audio. `type` is `music` (the default) or `original_sound`. Facebook-linked Instagram channels only. |

## TikTok

| Tool | Inputs | Returns |
|---|---|---|
| `creatorInfo` | none | What this account may post right now, as `{ privacyLevelOptions, maxDurationSeconds, commentDisabled, duetDisabled, stitchDisabled }`. Pick `privacy_level` from `privacyLevelOptions`; until TikTok audits PostQueen's app it is `["SELF_ONLY"]`. Keep a video within `maxDurationSeconds`, and leave comments, duets or stitches off when the account has them turned off. |

## TikTok Business

| Tool | Inputs | Returns |
|---|---|---|
| `musicSearch` | `genre`, optional, such as `POP`, `ROCK` or `ELECTRONIC` | Tracks from TikTok's commercial music list, as `{ id, title, artist, image, duration, previewUrl }`, with `duration` in milliseconds. There is no text search, so filter the list yourself. Send the id as `music.id` in the [TikTok settings](/public-api/providers/tiktok). |
| `locationSearch` | `q` | Location tags matching the search, as `{ id, name, address }`. An empty `q` returns an empty list. Send `id` and `name` as `location`. |

## Reddit

| Tool | Inputs | Returns |
|---|---|---|
| `subreddits` | `word` | Subreddits matching the word, as `{ id, title, name }`. **`name` is the `/r/...` path**, the form `restrictions` and the `subreddit` setting expect. |
| `restrictions` | `subreddit` | An object, not a list: `{ subreddit, allow, is_flair_required, flairs }`. `allow` says which post types the subreddit accepts, `is_flair_required` whether a flair must be picked, and `flairs` is `{ id, name }`. Send `subreddit` as `/r/name`. |

## Pinterest

| Tool | Inputs | Returns |
|---|---|---|
| `boards` | none | Your boards, as `{ id, name }`. Send the id as `board`. |

## Discord

| Tool | Inputs | Returns |
|---|---|---|
| `channels` | none | Channels in the connected server, as `{ id, name }`. Send the id as `channel`. |

## Slack

| Tool | Inputs | Returns |
|---|---|---|
| `channels` | none | Channels the PostQueen app can post to, as `{ id, name }`. |

## Dribbble

| Tool | Inputs | Returns |
|---|---|---|
| `teams` | none | The teams you belong to, as `{ id, name }`. |

## MeWe

| Tool | Inputs | Returns |
|---|---|---|
| `groups` | none | Groups you can post to, as `{ id, name }`. |

## Whop

| Tool | Inputs | Returns |
|---|---|---|
| `companies` | none | Companies you administer, as `{ id, name }`. |
| `experiences` | `id` | The forums of one company, as `{ id, name }`. Send the company id from `companies`; without it the list is empty. |

## Skool

| Tool | Inputs | Returns |
|---|---|---|
| `groups` | none | Groups you can post to, as `{ id, name }`. |
| `label` | `id` | The post labels of one group, as `{ id, name }`. Send the group id from `groups`. A group without labels returns one `{ id: "none", name: "Default Label" }`. |

## Farcaster

| Tool | Inputs | Returns |
|---|---|---|
| `subreddits` | `word` | Farcaster channels matching the word, as `{ id, title, name }`. The name comes from the Reddit tool it shares a shape with; it searches Farcaster channels. |

## Tools that take another tool's answer

Whop's `experiences` needs a company id from `companies`, Skool's `label` needs a group id from `groups`, and Reddit's `restrictions` needs a `name` from `subreddits`. All three networks are Soon on PostQueen; when they can be connected, call the tools in that order:

```bash
# 1. The companies you administer
curl -X POST "{{apiBase}}/integration-trigger/YOUR_WHOP_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" -H "Content-Type: application/json" \
  -d '{"methodName": "companies", "data": {}}'

# 2. The forums of the company you picked
curl -X POST "{{apiBase}}/integration-trigger/YOUR_WHOP_CHANNEL_ID" \
  -H "Authorization: YOUR_API_KEY" -H "Content-Type: application/json" \
  -d '{"methodName": "experiences", "data": {"id": "COMPANY_ID"}}'
```

<Check>
When the last call returns, you have the ids the post's settings ask for.
</Check>
