openapi: "GET /social/{integration}"
---

This returns a URL and nothing more. The network shows its own consent screen to a person, so a channel cannot be connected without someone clicking through it.

## Which networks it is for

It is for networks that sign in on their own consent page. On PostQueen today those are the networks **In review**: Instagram, Facebook, Threads, X, TikTok and YouTube. Each works with the limit on its [channel page](/channels/overview) until the network approves PostQueen's app.

| How the network connects | Networks | What to do |
|---|---|---|
| Its own consent page | Instagram (`instagram`, `instagram-standalone`), Facebook, Threads, X, TikTok, YouTube | Open the `url` this returns |
| A handle, key or password | Bluesky, DEV, Hashnode, Lemmy, Listmonk, Moltbook, Nostr, WordPress | Connect from **Add Channel** in the app. The `url` returned here is only an internal state value |
| Soon | Every other network | Cannot be connected on PostQueen yet, whatever this returns |

The `{integration}` value is the network's identifier, in lower case: `youtube`, `threads`, `instagram-standalone`. It is not always the display name.

## After the sign-in

The person lands back in the PostQueen app, which finishes the connection. The sign-in state lives for one hour, so generate a new URL for a link that sat unused longer than that.

<Check>
The new channel appears in [List channels](/public-api/integrations/list). Poll that, since this endpoint only hands out a URL.
</Check>

<Tip>
To reconnect a channel whose token expired, pass its id as `refresh`. PostQueen reconnects that channel instead of adding a new one, and a reconnect does not count against the plan's channel limit.
</Tip>
