title: "Get a channel's settings"
sidebarTitle: "Channel settings"
description: "A channel's posting rules, text limit, settings schema and helper tools."
openapi: "GET /integration-settings/{id}"
---

Read this before you build a post for a network you have not posted to yet:

| Field | What it tells you |
|---|---|
| `rules` | The network's media rules in words, such as how many images a post may carry |
| `maxLength` | The longest text PostQueen accepts for this channel |
| `settings` | The JSON schema of the post's `settings` object, or `No additional settings required` |
| `tools` | Helper tools you can run with [Trigger a tool](/public-api/integrations/trigger), each with its `methodName` and inputs |

The same fields, written out for people with examples, are on [Posting settings by network](/public-api/providers/overview). What every network's tools return is on [Provider tools](/public-api/integrations/provider-tools).
