---
title: "Get an access token"
sidebarTitle: "Access token"
description: "Exchange the code from your callback for a pos_ access token."
openapi: "POST /oauth/token"
---

Call it from your server: the request carries your Client Secret, which does not belong in a browser or an app people download. Send the secret in the body, or the Client ID and Secret as HTTP Basic credentials in `Authorization`.

The code works once, for 10 minutes: the exchange spends it. Run the same request twice and the second answers `400 invalid_grant`. A wrong secret and an unknown Client ID both answer `401 invalid_client`, so the answer does not say which one is wrong.

A client that registered itself with `token_endpoint_auth_method: none` sends no secret. It sends the PKCE `code_verifier` and the `redirect_uri` it used on the consent URL instead.

Send the token on `/public/v1` as `Authorization: pos_...`, with no prefix, even though `token_type` says `bearer`. When it stops working is on [OAuth apps](/public-api/oauth#how-long-a-token-lasts).
