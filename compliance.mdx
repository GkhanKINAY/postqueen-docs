Before you connect a real account you want to know what happens to the keys. This is that answer,
in the detail a security or platform review asks for.

## How PostQueen connects

| | |
|---|---|
| **Official OAuth, where the platform offers it** | You log in on the platform's own screen and approve the scopes. PostQueen receives only what you approved |
| **Publishing and analytics APIs** | No headless browser, no crawling, no scraping |
| **A credential, where OAuth does not exist** | Bluesky app password, WordPress application password, DEV API key, Hashnode personal access token, Nostr key. Lemmy takes the account's own username and password, and Listmonk an API user and token from your own server, because that is what those instances accept |
| **One browser-extension exception** | Skool has no public API, so it connects through your own browser session and the PostQueen browser extension. It carries its own terms-of-service warning, and it is marked Soon on PostQueen: it cannot be connected yet |

## Where credentials live

PostQueen keeps the credentials and tokens a channel needs on its servers, so it can publish for
you at the time you picked. A key, app password or private key goes into the channel's connect form
in PostQueen and nowhere else. Nobody from PostQueen will ask you to send one by email or chat.

## When you remove a channel

Deleting a channel replaces the sign-in PostQueen stored for it, so it can no longer publish, and
deletes that channel's posts. Deleting your account does the same for every channel.

Nothing is revoked at the network itself. To cut PostQueen off completely, also remove its access
in the network's own settings, in the list of apps or sessions connected to your account.
