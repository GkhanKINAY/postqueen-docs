**Where:** **Connect PostQueen** at the top of the left rail. It opens **Connections**.

Connections is where anything outside the app plugs into your workspace: AI agents over MCP, automations, the `postqueen` CLI and the public API. The left menu has **Browse**, with a setup card for each agent and tool, and **Account**.

## Connect an agent

<Steps>
  <Step title="Find its card">
    Under **Browse**, choose **All** or a category, or type the name in **Search agents and tools**.
  </Step>
  <Step title="Follow Setup">
    The card opens on **Setup**: numbered steps, with the text to copy and a prompt to try. The key sits in the step that needs it: an admin sees the real key, a member sees where it goes. Some cards let you choose **Sign in, no key** or **Key in the address** first.
  </Step>
  <Step title="Use the other tabs when you need them">
    **Tips and fixes** has what to know and what to do when something fails. **All ways to connect** lists every route, marked **No key** or **API key**.
  </Step>
</Steps>

Only a workspace Admin or Super Admin sees the key. Other members see it masked, and pressing **Reveal** explains that "The API key is managed by admins". Ask an admin to connect the agent, or to share the address with you.

Each agent has a setup guide in these docs: start at [AI agents](/agents/overview).

## What Connections holds

| Menu row | What is in it |
|---|---|
| **All** | Every category on one page. **Assistants and bots** starts with Grok Bot, Muse, OpenClaw and Hermes Agent, each with a prompt to try |
| **Assistants and bots** | Chat assistants and bots such as Claude, ChatGPT and Grok, and a card for asking from WhatsApp, Telegram, Slack or Discord |
| **Coding agents** | Claude Code, Codex, Cursor, Gemini CLI, Grok Build and Paperclip |
| **Editors and other apps** | VS Code, Devin Desktop, Zed, Muse Code and **Any MCP client** |
| **Automations** | n8n; Zapier and Make, marked **Soon**; **Webhooks** and **RSS AutoPost**, marked **In Settings**, which open their tab in Settings |
| **Developer tools** | **Public API**, **Command line**, **Node SDK** and **OAuth apps** |
| **Account** | **API key**, **OAuth apps** and **Approved Apps** |

Social networks such as TikTok are channels, not connections: you add them from **Channels**.

## Rotate the API key

<Steps>
  <Step title="Open API key">
    Choose **Your API key** at the top of Connections, or **API key** in the Account group.
  </Step>
  <Step title="Rotate">
    Choose **Rotate key**, then **Rotate** to confirm "Rotate API Key?". PostQueen makes a new key at once.
  </Step>
  <Step title="Update what used it">
    The old key stops working right away, so paste the new one, or the new MCP address, into every agent, script and n8n credential that used it.
  </Step>
</Steps>

A workspace has one key. Only an admin can reveal or rotate it.

## Your MCP address

Under **API key**, the **Addresses** card lists the **MCP address**, the **Sign-in address** and the **Public API header**. For an admin, **Copy** puts the real key in.

## OAuth apps and Approved Apps

- **OAuth apps** is for building your own product on PostQueen. An admin chooses **Create OAuth App** and fills in **App Name**, **Description**, **Profile Picture** and **Redirect URL**. The **Client Secret** is shown only when the app is created or the secret is rotated, so copy it then. A workspace has one OAuth app. See [OAuth apps](/public-api/oauth).
- **Approved Apps** lists the apps you connected by signing in, with no key, and the date of each. Only an Admin or Super Admin can approve an app, and an approved app can act for the whole workspace. Choose **Revoke** to take its access away. Each person sees and revokes the apps they approved.

## If something goes wrong

| Message | What to do |
|---|---|
| “The API key is managed by admins” | Only an Admin or Super Admin can reveal or rotate the key. Ask one. |
| “OAuth apps are managed by admins” | Only an Admin or Super Admin can create or change the OAuth app. |
